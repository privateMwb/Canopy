Pipelines, $match, $group & $project

An aggregation pipeline passes documents through a series of stages, so you can filter, group, and reshape data inside the database instead of looping in application code.

§1Thinking in Stages

aggregate takes an array of stages. Each stage receives the documents the previous stage produced and outputs new documents for the next one.

db.orders.aggregate([
  { $match:   { status: "paid", placedAt: { $gte: ISODate("2026-01-01") } } },
  { $group:   { _id: "$customerId", orders: { $sum: 1 }, revenue: { $sum: "$total" } } },
  { $sort:    { revenue: -1 } },
  { $limit:   5 }
])
// [ { _id: 42, orders: 9, revenue: 812.5 }, ... ]

This returns the five best customers without moving a single order to the application. A field reference inside an expression is written "$fieldName".

§2$match and $project

$match uses the same filter syntax as find. $project chooses and computes fields, and $addFields adds fields while keeping the rest.

{ $project: { _id: 0, customerId: 1, total: 1,
              totalWithTax: { $multiply: ["$total", 1.2] },
              year: { $year: "$placedAt" } } }
{ $addFields: { itemCount: { $size: "$items" } } }

Expressions use operators such as $multiply, $concat, $cond, $year, and $size, and they can be nested.

§3$group and Accumulators

$group collects documents that share an _id expression and computes values with accumulators.

AccumulatorResult
$sum, $avgtotal, mean
$min, $maxsmallest, largest
$first, $lastfirst or last in the current order
$push, $addToSetarray of values, array of unique values
$count shortcut{ $sum: 1 }
db.orders.aggregate([
  { $group: { _id: { month: { $month: "$placedAt" }, status: "$status" },
              n: { $sum: 1 }, avgTotal: { $avg: "$total" } } }
])

Use _id: null to aggregate across the whole input into a single result.

The key insight Put $match first. Filtering early means later stages handle fewer documents, and a leading $match can use an index.

§4Common Mistakes

MistakeWhat HappensFix
Forgetting the $ in "$total"MongoDB treats it as a literal stringPrefix field paths with $ inside expressions
Placing $match after $group when it could go beforeEvery document is grouped firstFilter as early as possible
$push of whole documents into a groupThe result exceeds the 100 MB stage limit or 16 MB document limitPush only the fields you need, or add $limit
Practice
  1. Compute the total revenue per month for paid orders only, sorted by month.
  2. Rewrite a loop that sums order totals per customer in application code as a pipeline.
Key takeaways
  • A pipeline is an ordered list of stages, each transforming the stream of documents.
  • $match filters, $project and $addFields reshape, and $group aggregates with accumulators.
  • Filter early so later stages work on less data.
