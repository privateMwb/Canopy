Installing MongoDB, mongosh & Atlas

You can run MongoDB on your own machine, in a container, or as a free hosted cluster on Atlas, and you talk to any of them through the shell, mongosh.

§1Three Ways to Get a Server

  • Local install: the Community Edition from the MongoDB site or your package manager. The server process is mongod and it listens on port 27017.
  • Docker: one command, easy to throw away and recreate.
  • Atlas: MongoDB's hosted service, with a free shared tier. There is nothing to install, and you get a connection string.
# Docker: a disposable local server
docker run -d --name mongo -p 27017:27017 -v mongo-data:/data/db mongo:7

# macOS with Homebrew
brew tap mongodb/brew && brew install mongodb-community
brew services start mongodb-community

Without a volume or a data directory, a container loses its data when removed. The -v mongo-data:/data/db part keeps the database files.

§2Meeting mongosh

mongosh is the modern shell: a JavaScript environment with syntax highlighting, history, and helper commands. You pass it a connection string that says where the server is.

mongosh                                      # connects to localhost:27017
mongosh "mongodb://localhost:27017/shop"     # connect and select a database
mongosh "mongodb+srv://cluster0.abc.mongodb.net/shop" --username ada
show dbs                  // list databases that contain data
use shop                  // switch to (or lazily create) the database "shop"
db.getName()              // shop
db.products.insertOne({ sku: "NB-1", name: "Notebook" })
db.products.find()

Because the shell is JavaScript, you can also write loops, define functions, and use variables to generate test data.

§3Setting Up Atlas

  1. Create an account and a free cluster, choosing a cloud provider and region close to you.
  2. Create a database user with a username and password.
  3. Add your IP address to the network access list, or the cluster will refuse your connection.
  4. Copy the mongodb+srv:// connection string and open it with mongosh.
The key insight A fresh Atlas cluster accepts no connections until you add an IP and create a user. If mongosh times out, the cause is almost always the network access list.

§4Common Mistakes

MistakeWhat HappensFix
Running a container with no volumeData disappears when the container is removedMount a volume at /data/db
Skipping the IP access list in AtlasConnection attempts time outAdd your current IP in Network Access
Pasting a password with special characters into a URIThe connection string fails to parseURL-encode the password, for example @ becomes %40
Practice
  1. Start a local MongoDB (Docker or native), connect with mongosh, and insert and read back one document.
  2. Create a free Atlas cluster, add a user and your IP, and connect to it from mongosh.
Key takeaways
  • mongod is the server and mongosh is the shell that connects to it by connection string.
  • Docker is the fastest throwaway setup, and Atlas needs no installation at all.
  • Atlas refuses connections until you create a user and allow your IP address.
