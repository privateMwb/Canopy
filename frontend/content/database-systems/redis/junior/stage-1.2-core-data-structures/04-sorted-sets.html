Sorted Sets

A sorted set keeps every member ordered by a numeric score, so rankings and range queries stay correct as scores change.

§1Scores and Ranks

ZADD board 1500 "alice" 1320 "bob" 1710 "cara"
ZINCRBY board 50 "bob"                 # bob is now 1370
ZRANK board "bob"                      # position, lowest score first (0-based)
ZREVRANK board "bob"                   # position, highest score first
ZSCORE board "cara"                    # 1710

Members are unique, but scores can repeat. Ties are ordered alphabetically by member.

§2Range Queries

ZRANGE board 0 2 REV WITHSCORES        # top 3 with scores
ZRANGE board 1300 1600 BYSCORE         # members with score in a range
ZCOUNT board 1300 1600
ZREM board "bob"
ZREMRANGEBYRANK board 0 -101           # keep only the top 100

ZRANGE takes options in Redis 6.2 and later; older commands such as ZREVRANGE still work.

§3Beyond Leaderboards

Scores do not have to be points. A timestamp as the score makes a time-ordered feed or a delay queue; a priority number makes a priority queue. Range-by-score then answers "what is due now?"

ZADD delayed 1735700000 "job:42"
ZRANGE delayed 0 1735689600 BYSCORE LIMIT 0 10   # jobs due before this time
The key insight Insert and update cost grows slowly with size (logarithmic), so a sorted set can hold millions of members and still answer top-N instantly.

§4Common Mistakes

MistakeWhat HappensFix
Storing score as text in the member nameRedis cannot order or range over itPut the number in the score
Reading all members to find the top 10Slow, large repliesUse ZRANGE ... REV 0 9
Expecting ties to keep insertion orderTies sort by member nameEncode a tiebreaker in the score, such as time
Practice
  1. Build a leaderboard, bump a score, and show a player's rank and the five players around them.
  2. Implement a delay queue that moves due jobs into a ready list.
Key takeaways
  • A sorted set orders unique members by a numeric score.
  • Use rank and range commands for leaderboards and top-N queries.
  • Timestamps and priorities make good scores for feeds and queues.
