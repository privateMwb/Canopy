Type Affinity & Storage Classes

SQLite lets a column hold any type of value, and affinity only nudges values toward the declared type instead of enforcing it.

§1Storage Classes

Every value has one of five storage classes: NULL, INTEGER, REAL, TEXT, or BLOB.

SELECT typeof(1), typeof(1.5), typeof('a'), typeof(x'FF'), typeof(NULL);
-- integer | real | text | blob | null

There is no separate boolean, date, or decimal type. Booleans are stored as 0 and 1, and dates as text, numbers, or Julian days.

§2Type Affinity

A column's declared type gives it an affinity: TEXT, NUMERIC, INTEGER, REAL, or BLOB. When you insert a value, SQLite tries to convert it to the column's affinity but stores it as-is if it cannot.

CREATE TABLE t (n INTEGER, s TEXT);
INSERT INTO t VALUES ('42', 42);      -- stored as integer 42 and text '42'
INSERT INTO t VALUES ('abc', 7);      -- 'abc' stays text in an INTEGER column
SELECT n, typeof(n) FROM t;

Declared names such as VARCHAR(20) or DECIMAL(10,2) map to an affinity by pattern, and the length is not enforced.

§3Surprises

  • A text value in an INTEGER column is allowed, so bad data can sneak in.
  • Comparing values of different classes follows a fixed order: NULL, then numbers, then text, then blobs.
  • DECIMAL is just NUMERIC affinity, so money in floating point can lose precision. Store cents as integers instead.
SELECT 0.1 + 0.2 = 0.3;               -- 0, floating point
SELECT 1 < 'a';                       -- 1, numbers sort before text
The key insight In classic SQLite, the type you declare is a hint, not a rule. If you want enforcement, use CHECK constraints or STRICT tables, covered next.

§4Common Mistakes

MistakeWhat HappensFix
Declaring VARCHAR(10) and expecting a length limitLonger text is stored without errorUse CHECK (length(col) <= 10)
Storing money as REALRounding errors accumulateStore integer cents
Assuming an INTEGER column cannot hold textBad values slip in silentlyUse STRICT tables or CHECK constraints
Practice
  1. Insert the values '7', 7.0, 'seven', and NULL into an INTEGER column and look at typeof for each.
  2. Show that 0.1 + 0.2 = 0.3 is false and convert a price to integer cents.
Key takeaways
  • There are five storage classes: NULL, INTEGER, REAL, TEXT, and BLOB.
  • Affinity converts when it can and otherwise stores the value unchanged.
  • Declared lengths and decimal precision are not enforced, so add constraints.
