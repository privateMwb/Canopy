Date, Time & Text Functions

SQLite has no date type, so you choose a representation and use its date functions consistently.

§1Storing Time

Three common choices: ISO-8601 text ('2025-05-14 10:30:00'), a Unix timestamp integer, or a Julian day number. ISO text sorts correctly and is readable, and Unix integers are compact and easy for arithmetic. Pick one and use it everywhere, and store UTC.

CREATE TABLE event (
  id INTEGER PRIMARY KEY,
  starts_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
);

§2Date Functions

SELECT date('now'), time('now'), datetime('now');
SELECT date('2025-05-14', '+1 month', 'start of month');
SELECT strftime('%Y-%m', starts_at) FROM event;
SELECT unixepoch('2025-05-14 10:30:00');                 -- 3.38+
SELECT datetime(1747218600, 'unixepoch', 'localtime');
SELECT julianday('2025-12-25') - julianday('now');       -- days until

Modifiers such as '+7 days', 'start of month', and 'weekday 1' adjust the date. Without 'localtime' all results are UTC.

§3Text Functions

SELECT length('héllo'), upper('abc'), substr('database', 1, 4), instr('database', 'base');
SELECT replace('a-b-c', '-', '/'), trim('  x  '), 'a' || 'b' AS joined;
SELECT lower(name) FROM product WHERE name LIKE '%pen%';

|| concatenates, substr counts from 1, and length counts characters for text.

The key insight Choose a time format once, store UTC, and convert for display. Mixed formats make comparisons wrong.

§4Common Mistakes

MistakeWhat HappensFix
Mixing '2025-5-4' and '2025-05-04'String comparison and date functions breakAlways zero-pad and use ISO-8601
Storing local time with no zoneDaylight saving and travel cause errorsStore UTC and convert on display
Forgetting that 'now' is UTCResults appear hours offAdd the 'localtime' modifier when displaying
Practice
  1. Store the same event time as ISO text and as a Unix integer, and write queries for "this month" against each.
  2. Compute the number of days between two dates and the first Monday of next month.
Key takeaways
  • SQLite stores time as text, integers, or Julian days, so choose one convention.
  • Date functions and modifiers do the arithmetic, and 'now' is UTC.
  • Use ||, substr, and replace for common text work.
