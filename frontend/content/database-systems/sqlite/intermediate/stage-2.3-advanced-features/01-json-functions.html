JSON Functions

SQLite can store, query, and index JSON documents with built-in functions, so a flexible column does not need a separate document database.

§1Extracting and Querying

JSON is stored as text, and the JSON functions read it.

CREATE TABLE event (id INTEGER PRIMARY KEY, payload TEXT NOT NULL CHECK (json_valid(payload)));
INSERT INTO event (payload) VALUES ('{"type":"click","user":{"id":7,"plan":"pro"},"tags":["a","b"]}');

SELECT json_extract(payload, '$.user.plan') FROM event;
SELECT payload ->> '$.user.id', payload -> '$.tags' FROM event;      -- 3.38+
SELECT * FROM event WHERE payload ->> '$.type' = 'click';

-> returns JSON, and ->> returns an SQL value (text, integer, and so on).

§2Changing and Building JSON

UPDATE event SET payload = json_set(payload, '$.user.plan', 'free');
UPDATE event SET payload = json_insert(payload, '$.seen', 1);
SELECT json_object('id', id, 'type', payload ->> '$.type') FROM event;
SELECT json_group_array(payload ->> '$.type') FROM event;

§3Arrays as Rows

json_each and json_tree turn JSON into rows you can join and filter.

SELECT e.id, t.value FROM event e, json_each(e.payload, '$.tags') AS t;

§4Indexing

A JSON field is not indexed automatically. Add an index on an expression, or a generated column.

CREATE INDEX idx_event_type ON event (payload ->> '$.type');
SELECT * FROM event WHERE payload ->> '$.type' = 'click';     -- same expression, so it can use the index

Recent versions also store JSON in a binary form called JSONB for faster processing, through functions such as jsonb().

The key insight Use JSON for fields that really vary. Fields you filter and join on all day belong in real columns.

§5Common Mistakes

MistakeWhat HappensFix
Querying JSON fields without an index on a big tableEvery row is parsed on each queryAdd an expression index or a generated column
Storing malformed JSONFunctions raise errors laterAdd CHECK (json_valid(col))
Putting all data in one JSON blobYou lose constraints and clear schemasUse columns for core fields and JSON for extras
Practice
  1. Store 1,000 JSON events, query by a nested field, and add an expression index to speed it up.
  2. Use json_each to count how often each tag appears.
Key takeaways
  • json_extract, ->, and ->> read JSON, and json_set changes it.
  • json_each expands arrays into rows.
  • Index JSON fields through expression indexes or generated columns.
