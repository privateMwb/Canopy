Checkpoints are deliberately unscaffolded. If you can finish one without hints, the stage actually landed, not just the following-along.

Levels aren't strict walls. Transactions appear at Junior as grouping writes, return at Intermediate as locking and WAL mode, and come back at Senior as atomic commit and crash recovery. Performance follows the same arc: indexes, then planner and PRAGMAs, then file format and the pager. Revisiting a topic at a harder level is expected.

Senior is about judgment as much as mechanism. Knowing how the B-tree file format or the WAL works is one skill; deciding whether SQLite should hold a workload at all, planning the move to a server database, and writing that down for a skeptical reviewer, is another, and the last stage is built around that gap.
