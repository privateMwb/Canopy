Pattern Matching & Recent Syntax

match statements destructure data by shape, and a few recent additions like the walrus operator make common code shorter and clearer.

§1match / case

Structural pattern matching (Python 3.10+) compares a value against patterns, binding names as it goes. It is more than a switch: it matches sequences, mappings, and class instances.

def describe(command):
    match command:
        case "quit" | "exit":
            return "leaving"
        case ["go", direction]:
            return f"going {direction}"
        case ["pick", "up", *items]:
            return f"picking up {items}"
        case {"type": "move", "x": x, "y": y}:
            return f"moving to {x}, {y}"
        case int(n) if n < 0:
            return "negative number"
        case _:
            return "unknown"

print(describe(["go", "north"]))               # going north
print(describe({"type": "move", "x": 1, "y": 2}))

_ is the catch-all, and a bare name in a pattern captures the value rather than comparing it. To compare against a constant, use a dotted name such as Color.RED or a literal.

§2Matching Classes

from dataclasses import dataclass

@dataclass
class Circle:
    radius: float

@dataclass
class Rect:
    width: float
    height: float

def area(shape):
    match shape:
        case Circle(radius=r):
            return 3.14159 * r * r
        case Rect(width=w, height=h):
            return w * h
        case _:
            raise TypeError("unknown shape")

Dataclasses support positional patterns too: case Rect(w, h).

§3The Walrus Operator

:= assigns inside an expression (Python 3.8+), which avoids computing something twice or writing a loop-and-break pattern.

import re

if (m := re.search(r"\d+", "order 4521")) is not None:
    print(m.group())               # 4521

while (line := input("> ")) != "quit":
    print("you said", line)

big = [y for x in data if (y := expensive(x)) > 10]

Use it when it removes duplication, not to cram logic onto one line.

§4Other Recent Additions

  • f-string improvements (3.12): nested quotes and multi-line expressions work inside {}.
  • **type statement and generic syntax** (3.12): type Vector = list[float] and def f[T](x: T) -> T.
  • Better error messages, with suggestions like "Did you mean...?", since 3.10 and improved since.
  • **tomllib (3.11) reads TOML in the standard library; ExceptionGroup and except*** (3.11) support concurrent errors.
  • Positional-only parameters: def f(a, b, /, c) means a and b can't be passed by keyword (3.8+).

Check the "What's New" page for your version for the full list, and make sure your minimum supported version supports whatever you use.

The key insight match is for shape-based branching, such as parsing commands or walking structured data. For a simple comparison of one value to a few constants, if/elif is still fine.

§5Common Mistakes

Practice
  1. Write a parse_command(text) using match on text.split() that handles "add X", "remove X", and "list".
  2. Rewrite a while True: ... break input loop using the walrus operator.
Key takeaways
  • match destructures sequences, mappings, and class instances, with _ as the default.
  • A bare name in a pattern captures; use dotted names or literals to compare.
  • Check what each Python version adds, but only use features your minimum supported version has.
