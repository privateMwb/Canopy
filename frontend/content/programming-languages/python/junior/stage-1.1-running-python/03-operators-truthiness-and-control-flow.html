Operators, Truthiness & Control Flow

if, for, and while steer your program, and every object in Python can be tested for truth.

§1Conditions and Branches

Comparison operators (==, !=, <, <=, >, >=) return booleans, and you can chain them. Combine conditions with and, or, not, which short-circuit: the right side is evaluated only if needed.

score = 82
if 90 <= score <= 100:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"
print(grade)    # B

§2Truthiness

Any object works in a condition. These are falsy: False, None, 0, 0.0, "", [], {}, (), set(). Almost everything else is truthy. This lets you write if items: instead of if len(items) > 0:.

name = ""
if not name:
    print("name is empty")

user = None
print(user or "guest")      # guest: `or` returns the first truthy operand

§3Loops

for iterates over anything iterable; range(n) yields 0 to n - 1. while repeats while a condition holds. break exits a loop, continue skips to the next pass, and an optional else on a loop runs only if no break happened.

for i in range(3):
    print(i)               # 0 1 2

n = 10
while n > 0:
    n -= 3
print(n)                   # -2

for x in [3, 5, 8]:
    if x % 2 == 0:
        print("found even", x)
        break
else:
    print("no even numbers")
The key insight Prefer for item in collection: over indexing with range(len(...)). Python loops over the things themselves, which is shorter and avoids off-by-one errors.

Key takeaways
  • Empty and zero values are falsy; use if items: instead of checking length.
  • and / or short-circuit and return one of their operands, not necessarily a boolean.
  • Loop over items directly, and use break, continue, and loop else for control.
