Functions

A function packages reusable behavior behind a name, with parameters in and a return value out.

§1Defining and Calling

def creates a function object and binds it to a name. A function with no return returns None. Arguments can be passed by position or by keyword.

def area(width, height=1):
    """Return the area of a rectangle."""
    return width * height

print(area(3, 4))          # 12
print(area(width=5))       # 5, height defaults to 1
print(area(height=2, width=6))   # 12

The string right after the def line is a docstring; help(area) shows it.

§2*args and **kwargs

*args collects extra positional arguments into a tuple, and **kwargs collects extra keyword arguments into a dict. The same symbols at a call site unpack a sequence or mapping.

def total(*nums):
    return sum(nums)

def show(**opts):
    for key, value in opts.items():
        print(key, "=", value)

print(total(1, 2, 3))      # 6
show(color="red", size=3)

values = [4, 5, 6]
print(total(*values))      # 15

A bare * in the signature forces later parameters to be keyword-only: def connect(host, *, timeout=5).

§3Scope

Python looks up names in order: Local, Enclosing function, Global, Built-in. Assigning to a name inside a function makes it local unless you declare it global (or nonlocal for an enclosing function). Reading a global needs no declaration.

count = 0

def bump():
    global count     # without this, `count += 1` raises UnboundLocalError
    count += 1

Prefer passing values in and returning results over mutating globals.

The key insight Functions are objects. You can store them in lists, pass them as arguments, and return them from other functions, which is the foundation of decorators later on.

§4Common Mistakes

MistakeWhat HappensFix
Forgetting returnThe function quietly returns NoneReturn the value explicitly; check with print(f(...))
Assigning to a global inside a functionUnboundLocalError, or a new local that hides the globalReturn the new value, or declare global deliberately
Putting positional args after keyword args in a callSyntaxErrorKeep positional arguments first
Practice
  1. Write describe(name, *, age=None, **extras) that prints the name, the age if given, and every extra key-value pair.
  2. Write a function stats(numbers) that returns the minimum, maximum, and mean, and unpack the result into three variables.
Key takeaways
  • Parameters can have defaults, be collected with *args / **kwargs, or be keyword-only.
  • Name lookup follows Local, Enclosing, Global, Built-in; assignment makes a name local.
  • A function without return returns None; return multiple values as a tuple.
