Dictionaries & Sets

Dictionaries map keys to values and sets store unique items, both with fast hash-based lookup.

§1Dictionaries

A dict maps keys to values. Lookup, insert, and delete are O(1) on average. Keys must be hashable (strings, numbers, tuples of hashables); insertion order is preserved.

ages = {"ana": 31, "bo": 27}
ages["cy"] = 40               # add
ages["bo"] = 28               # update
print(ages["ana"])            # 31
print(ages.get("zed"))        # None  (no KeyError)
print(ages.get("zed", 0))     # 0
del ages["cy"]
print("ana" in ages)          # True  (tests keys)

A missing key with [] raises KeyError; use .get() when absence is normal.

§2Looping and Updating

for name, age in ages.items():    # keys and values
    print(name, age)

for name in ages:                  # keys only
    pass

counts = {}
for ch in "banana":
    counts[ch] = counts.get(ch, 0) + 1
print(counts)                      # {'b': 1, 'a': 3, 'n': 2}

merged = {"a": 1} | {"b": 2}       # Python 3.9+: {'a': 1, 'b': 2}

setdefault and collections.defaultdict handle "create the entry if it's missing" patterns, such as grouping.

§3Sets

A set is an unordered collection of unique hashable items. Membership tests are O(1) on average, and the operators work like math.

seen = {1, 2, 3}
seen.add(2)                  # no effect: already present
print({1, 2, 3} & {2, 3, 4}) # {2, 3}   intersection
print({1, 2, 3} | {2, 3, 4}) # {1, 2, 3, 4}   union
print({1, 2, 3} - {2})       # {1, 3}   difference
print(list(set([3, 1, 3, 2])))   # duplicates removed
empty = set()                # {} would create an empty dict

§4Replacing Loops with Lookups

Checking x in some_list is a linear scan; checking x in some_set is a hash lookup. When you need repeated membership tests or de-duplication, convert to a set once.

banned = {"spam", "scam"}
words = ["hello", "spam", "world"]
clean = [w for w in words if w not in banned]
The key insight If you find yourself writing a loop to search for something, ask whether a dict (key to value) or set (does it exist?) would turn it into one lookup.

§5Common Mistakes

MistakeWhat HappensFix
Using d[key] for optional keysKeyErrorUse d.get(key, default) or test key in d
Using a list as a dict key or set memberTypeError: unhashable typeUse a tuple, or convert to a string
Writing {} for an empty setYou get an empty dictUse set()
Practice
  1. Given a list of words, build a dict mapping each word to how many times it appears.
  2. Given two lists of email addresses, find the ones in both, and the ones in only the first, using sets.
Key takeaways
  • Dicts and sets use hashing, so lookup and membership are fast on average.
  • Use .get() for optional keys; keys and set members must be hashable.
  • Convert a list to a set when you do repeated membership tests or need uniqueness.
