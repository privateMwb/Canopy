Public API Design

A library's public API is a promise to callers you haven't met, so expose a small, clear surface and keep everything else free to change.

§1Decide What Is Public

Python has no enforced privacy, so you declare it by convention and by structure. Everything a user can import and rely on is your API, whether you intended it or not.

# mylib/__init__.py
from ._client import Client
from ._errors import MylibError, RateLimited
from ._version import __version__

__all__ = ["Client", "MylibError", "RateLimited", "__version__"]
  • A leading underscore (_client.py, _helper) means "internal; no promises."
  • __all__ lists what from mylib import * exports, and what documentation tools treat as public.
  • Re-export the supported names from the package root, so users write from mylib import Client and your internal file layout can be reorganized freely.
  • Document the public surface, and state clearly that anything else is internal.

§2Design for the Caller

Write the calling code first. The best APIs make the common case short, the correct way obvious, and the mistake hard.

# Hard to use correctly: positional flags, unclear order
client.send("a@b.co", "Hi", True, False, 30)

# Clear: keyword-only options with defaults
client.send(to="a@b.co", subject="Hi", retries=3, timeout=30.0)

def send(self, *, to: str, subject: str, retries: int = 3, timeout: float = 30.0) -> Receipt:
    ...

Useful habits:

  • Keyword-only parameters (*) for options, which lets you add or reorder them later without breaking positional callers.
  • Sensible defaults so simple use needs few arguments.
  • Consistent naming and parameter order across functions.
  • Type hints and a py.typed marker file so users' checkers can see them.
  • Return well-defined objects (dataclasses, enums), not loosely shaped dicts and magic strings.

§3Errors Are Part of the API

Define a base exception for your library so callers can catch everything you raise with one except, plus specific subclasses for conditions they might handle.

class MylibError(Exception):
    """Base class for all errors raised by mylib."""

class RateLimited(MylibError):
    def __init__(self, retry_after: float):
        super().__init__(f"rate limited; retry in {retry_after:.0f}s")
        self.retry_after = retry_after

Raise library errors with raise ... from original so the cause is preserved, and avoid leaking internals such as a vendored HTTP library's exception types.

§4Keep the Surface Small

Every public name is a maintenance commitment. It's easy to add something later and nearly impossible to remove it. When unsure, leave it private. Prefer functions and plain data over large class hierarchies that users must subclass, since inheritance exposes your internal structure. Accept the most general types (Iterable, Mapping, os.PathLike), and return concrete ones.

The key insight Hyrum's Law: with enough users, every observable behavior of your system will be depended on by somebody. The smaller and more explicit your public API, the less of that behavior you've committed to.

§5Common Mistakes

MistakeWhat HappensFix
Making every module importable and undocumentedUsers depend on internals, and you can't refactorPrefix internals with _, export a deliberate surface via __init__.py and __all__
Boolean flag soup in positional argumentsCalls are unreadable and fragileUse keyword-only parameters with names
Raising built-in Exception or leaking a dependency's errorsCallers can't catch your errors preciselyDefine a library base exception and wrap lower-level errors
Practice
  1. Take a small library or script of yours and write the __init__.py and __all__ that define its public surface, moving everything else behind underscores.
  2. Rewrite a function with four positional parameters to use keyword-only arguments and a return dataclass, and list what callers gain.
Key takeaways
  • Public means "importable and documented"; use _ prefixes, __init__.py, and __all__ to say so.
  • Design from the caller's view: keyword-only options, sensible defaults, typed, consistent.
  • Define a base exception, and keep the public surface as small as you can.
