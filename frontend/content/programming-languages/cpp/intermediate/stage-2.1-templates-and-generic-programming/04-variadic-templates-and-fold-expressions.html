Variadic Templates & Fold Expressions

A parameter pack lets a template accept any number of arguments of any types, and fold expressions combine them in one line.

§1Parameter Packs

A pack is declared with ... before its name and expanded with ... after a pattern.

template <typename... Args>
void countArgs(Args... args) {
    std::cout << sizeof...(Args) << " arguments\n";     // number of elements
}
countArgs(1, "x", 2.5);       // 3 arguments

Args is a pack of types and args is a pack of values. Any pattern containing a pack followed by ... is expanded into a comma-separated list.

template <typename... Args>
void callAll(Args... args) { other(args...); }          // other(a1, a2, a3)
template <typename... Args>
void callTwice(Args... args) { other((args * 2)...); }  // other(a1*2, a2*2, a3*2)

§2Fold Expressions

C++17 folds apply an operator across a whole pack, replacing recursion.

template <typename... Args>
auto sum(Args... args) { return (args + ...); }          // unary right fold
template <typename... Args>
bool allTrue(Args... args) { return (... && args); }     // unary left fold
template <typename... Args>
void printAll(const Args&... args) {
    ((std::cout << args << ' '), ...);                   // comma fold: runs for each
    std::cout << '\n';
}
sum(1, 2, 3);                  // 6
printAll("a", 1, 2.5);         // a 1 2.5

An empty pack is only valid for &&, ||, and ,, and the other operators need an initial value: (0 + ... + args).

§3Recursion, the Pre-C++17 Way

Older code peels one argument at a time with a base case; you will meet it in existing codebases.

void print() {}                                   // base case
template <typename T, typename... Rest>
void print(const T& first, const Rest&... rest) {
    std::cout << first << ' ';
    print(rest...);
}

§4Forwarding Packs

Standard utilities like std::make_unique and emplace_back take a pack and pass it along without copies, using std::forward: new T(std::forward<Args>(args)...). The next stage explains why.

The key insight A pack expansion repeats its pattern once per element. Read f(g(args)...) as "call g on each, then pass all results to f," which is different from f(g(args...)).

§5Common Mistakes

MistakeWhat HappensFix
Folding + over an empty packCompile errorSupply an initial value: (0 + ... + args)
Writing args... where the pattern needs parenthesesExpands a different expression than intendedWrap the pattern: (f(args), ...)
Recursion with no base case for an empty pack"no matching function" at the endAdd a zero-argument overload
Practice
  1. Write minOf(args...) for a pack of arguments using a fold expression with std::min.
  2. Write a log(fmt, args...) helper that prints the format then each argument.
Key takeaways
  • ... after a pattern expands it once per pack element, and sizeof... counts them.
  • Fold expressions replace most recursive variadic code.
  • Empty packs fold only for &&, ||, and ,, otherwise give an init value.
