Checkpoints are deliberately unscaffolded. If you can finish one without hints, the stage actually landed, not just the following-along.

Levels aren't strict walls. Concurrency appears at Intermediate as executors and virtual threads, and returns at Senior as the Java Memory Model and thread dumps. Memory works the same way: references and collections first, then the garbage collector, then sizing a heap inside a container. Revisiting a topic at a harder level is expected.

Senior is about judgment as much as mechanism. Senior is about the JVM and the production environment as much as the language. Knowing how G1 and ZGC differ and being able to read a GC log from a misbehaving service are different skills, and the middle stages are built around that gap.
