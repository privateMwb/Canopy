Checkpoints are deliberately unscaffolded. If you can finish one without hints, the stage actually landed, not just the following-along.

Levels aren't strict walls. Async appears at Intermediate as Task and await, and returns at Senior as state machines, ValueTask, and thread-pool starvation. Memory works the same way: value vs. reference types first, then the garbage collector, then spans and allocation-free code. Revisiting a topic at a harder level is expected.

Senior is about judgment as much as mechanism. Senior is about the runtime and the production environment as much as the language. Knowing how the GC generations work and being able to diagnose a leak from a dump are different skills, and the middle stages are built around that gap.
