Control Flow & Truthiness

Conditionals and loops decide what runs, and JavaScript decides what counts as true using a short list of falsy values.

§1Conditionals and Loops

The basics look like other C-family languages. Prefer for...of for iterating values and for...in only for object keys (it also walks inherited properties, so it is rarely what you want on arrays).

if (score >= 90) grade = "A";
else if (score >= 80) grade = "B";
else grade = "C";

const label = score >= 50 ? "pass" : "fail";

for (const item of ["a", "b"]) console.log(item);
for (const [i, item] of ["a", "b"].entries()) console.log(i, item);

let n = 3;
while (n > 0) { n--; }

switch (day) {
  case "sat":
  case "sun": console.log("weekend"); break;   // break stops fall-through
  default: console.log("weekday");
}

§2Truthy and Falsy

Conditions don't need booleans. Exactly these values are falsy: false, 0, -0, 0n, "", null, undefined, and NaN. Everything else is truthy — including "0", [], and {}.

if ("") {}       // not run
if ("0") {}      // runs — non-empty string
if ([]) {}       // runs — arrays are objects
if (0) {}        // not run — even though 0 may be a valid value!

const name = userInput || "Anonymous";   // || returns the first truthy value
const ok = a && b;                       // && returns the first falsy value

§3Optional Chaining and Nullish Coalescing

?. stops and returns undefined if the value before it is null or undefined, instead of throwing. ?? supplies a default only for null or undefined, unlike ||, which also replaces 0 and "".

const user = { profile: null };
user.profile.name;          // TypeError
user.profile?.name;         // undefined — no error
user.getName?.();           // call only if it exists
user.tags?.[0];             // safe index access

const count = 0;
count || 10;                // 10   (0 is falsy — probably a bug)
count ?? 10;                // 0    (only null/undefined fall back)

let cache = null;
cache ??= new Map();        // assign only if null/undefined
Choose the right default operator Use ?? when 0, false, or an empty string are legitimate values. Use || only when you really want every falsy value replaced.

§4Common Mistakes

MistakeWhat HappensFix
if (count) when 0 is validA count of zero is treated as missingTest explicitly: if (count !== undefined)
Forgetting break in switchExecution falls through into the next caseEnd each case with break, return, or a comment saying it's intentional
value || default for numbers or booleansReplaces valid 0 / falseUse value ?? default
Practice
  1. List all eight falsy values from memory, then verify each with Boolean(x) in the console.
  2. Given settings = { retries: 0 }, write code that reads settings.retries with a default of 3 without overriding the 0.
Key takeaways
  • Eight falsy values; everything else — including "0" and [] — is truthy.
  • ?. safely reads through null/undefined; ?? defaults only for those two.
  • Use for...of for values and break every switch case deliberately.
