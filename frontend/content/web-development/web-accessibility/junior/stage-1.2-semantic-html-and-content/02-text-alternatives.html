Text Alternatives

Every image that carries meaning needs words that carry the same meaning. Good alt text depends less on describing the picture and more on understanding why it is there.

§1Ask What the Image Is For

There is no single right alt text for an image. The right text depends on the purpose the image serves in its context. Start by sorting the image into one of four kinds.

KindExampleAlt text approach
InformativeA photo or chart that adds informationDescribe the information it conveys, briefly
FunctionalA magnifier icon inside a search buttonDescribe the action or destination, not the picture
DecorativeA flourish or purely visual dividerUse an empty alt="" so it is skipped
ComplexA chart, diagram, or infographicGive a short alt, plus a longer text description nearby

§2Writing Good Alt Text

Alt text is read aloud in the flow of the page, so aim for a short, natural phrase that does the same job as the image.

<!-- Informative: say what matters in this context -->
<img src="team.jpg" alt="The five-person support team standing outside the office">

<!-- Functional: a logo that links home describes the destination -->
<a href="/"><img src="logo.svg" alt="Trailhead home"></a>

<!-- Decorative: empty alt tells screen readers to skip it -->
<img src="swirl.svg" alt="">

<!-- Bad: filename or redundant words -->
<img src="IMG_4821.jpg" alt="image of a picture of people">
  • Skip "image of" and "photo of". Screen readers already announce that it is an image.
  • The same photo can need different alt text in different places. A news photo and a product page need different information.
  • If the surrounding text already says everything, use alt="" rather than repeating it.
  • Never leave the alt attribute out entirely. Without it, many screen readers read out the file name.

§3Complex Images, SVG, and Icons

For charts and diagrams, keep the alt short and put the full explanation in text on the page, so everyone can use it.

<figure>
  <img src="sales-chart.png"
       alt="Line chart of monthly sales, rising steadily from January to June">
  <figcaption>
    Sales grew from 120 units in January to 310 in June. The sharpest
    rise was between March and April.
  </figcaption>
</figure>

<!-- Inline SVG that carries meaning -->
<svg role="img" aria-labelledby="t1" viewBox="0 0 24 24">
  <title id="t1">Warning</title>
  ...
</svg>

<!-- Decorative icon next to visible text: hide it from assistive tech -->
<button><svg aria-hidden="true" focusable="false">...</svg> Delete</button>

Avoid images of text. They cannot be resized cleanly, restyled, or translated, and need a perfect alt that matches. Use real text with CSS instead.

The key insight Write alt text for the person who cannot see the image, not for the image itself. The test is simple: if the image failed to load, would your alt text let the reader keep going?

§4Common Mistakes

MistakeWhat HappensFix
Leaving out the alt attributeScreen readers may announce the file name, such as "IMG 4821 dot jpg"Always include alt, using alt="" for decorative images
Starting with "image of" or stuffing keywordsWastes the listener's time and sounds like spamDescribe the purpose in a short, natural phrase
Describing a functional image literallyA magnifier icon reads "magnifying glass" instead of "Search"Use text that describes the action or destination
Practice
  1. Take five images from a page you know. Classify each as informative, functional, decorative, or complex, and write alt text for each (or alt="" where appropriate).
  2. Find an image of text on a real site. Write the HTML and CSS that would present the same words as real text.
Key takeaways
  • Decide alt text by the image's purpose in context: informative, functional, decorative, or complex.
  • Use alt="" for decorative images, and never omit the alt attribute.
  • Put long explanations for charts and diagrams in visible text, with a short alt on the image.
