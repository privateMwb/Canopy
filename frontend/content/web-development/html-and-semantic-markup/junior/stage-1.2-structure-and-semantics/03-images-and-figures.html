Images & Figures

Images need alt text, explicit dimensions, and sometimes a caption; getting those three right serves screen readers, slow connections, and layout stability.

§1The img Element and alt Text

<img> embeds an image. Its alt attribute is the text alternative, read by screen readers and shown if the image fails to load. Write what the image *communicates* in that context, not a literal description of pixels.

<!-- informative -->
<img src="chart.png" alt="Sales rose 40% from Q1 to Q4 2025">

<!-- decorative: empty alt, so screen readers skip it -->
<img src="swirl.svg" alt="">

<!-- functional: describe the action, not the picture -->
<a href="/"><img src="logo.svg" alt="Canopy home"></a>

An empty alt="" is deliberate and correct for decoration. Omitting the attribute is different: screen readers may read out the file name.

§2Sizing and Layout Shift

Add width and height attributes with the image's intrinsic pixel size. The browser uses them to reserve space *before* the file loads, which prevents content from jumping around.

<img src="hero.jpg" alt="Sunrise over a forest canopy"
     width="1200" height="800">

/* CSS keeps it responsive while the ratio is preserved */
img { max-width: 100%; height: auto; }

§3Figures and Captions

When an image, diagram, or code listing is referenced by the text and has a caption, wrap it in <figure> with a <figcaption>. They are linked in the accessibility tree.

<figure>
  <img src="rings.jpg" alt="Cross-section of an oak trunk with 80 visible rings"
       width="800" height="600">
  <figcaption>Figure 1. Each ring marks one year of growth.</figcaption>
</figure>

A caption complements alt text; it does not replace it. alt describes the image for those who cannot see it, and the caption adds context for everyone.

The alt test Imagine reading the page aloud over the phone. Whatever you would say in place of the image is your alt text; if you would say nothing, use alt="".

§4Common Mistakes

MistakeWhat HappensFix
Starting alt text with "image of" or "picture of"Screen readers already announce it as an imageDescribe the content directly
Leaving out width and heightLayout shifts as images load and hurts your Core Web VitalsAdd both attributes and use height: auto in CSS
Writing the same text in alt and figcaptionScreen reader users hear it twiceMake the alt describe the image and the caption add context
Putting meaningful text only inside an imageIt is not searchable or resizablePut the text in HTML and use alt for the rest
Practice
  1. Add suitable alt text to a photo, a decorative divider, and a linked logo, and say which of the three needs alt="".
  2. Wrap a chart in figure with a figcaption and give it explicit dimensions.
Key takeaways
  • Every img needs an alt; use alt="" for decoration only.
  • Set width and height to reserve layout space.
  • Use figure and figcaption for captioned, referenced content.
