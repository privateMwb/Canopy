Links & URLs

The anchor element is what makes the web a web; knowing how URLs resolve keeps your links from breaking when you move files.

§1The Anchor Element

A link is <a> with an href. Its content is the link text, which should still make sense when read out of context, since screen reader users often list all links on a page.

<a href="https://developer.mozilla.org/">MDN Web Docs</a>

<!-- weak link text -->
<a href="/pricing/">Click here</a>

<!-- better -->
<a href="/pricing/">See pricing plans</a>

§2Absolute, Root-Relative, and Relative URLs

An absolute URL has the full scheme and host. A root-relative URL starts with / and is resolved from the site root. A relative URL is resolved from the current page's folder.

FormExampleResolves from
Absolutehttps://example.com/a/b.htmlNowhere; it is complete
Root-relative/img/logo.pngThe site root
Relative../img/logo.pngThe folder of the current file
Same folderteam.htmlThe folder of the current file

On a page at /blog/2026/post.html, the link ../index.html points to /blog/index.html. Each ../ climbs one folder.

§3Fragments, Email, and Opening New Tabs

A fragment like #pricing jumps to the element with id="pricing". The mailto: and tel: schemes open the mail or phone app.

<a href="#pricing">Jump to pricing</a>
<h2 id="pricing">Pricing</h2>

<a href="mailto:hello@example.com">Email us</a>
<a href="tel:+15555550123">Call us</a>

<a href="https://example.org" target="_blank" rel="noopener">Partner site</a>

target="_blank" opens a new tab. Use it sparingly, since it takes control away from the visitor, and warn users when you do. Modern browsers already apply noopener behavior for _blank, but writing rel="noopener" is harmless and explicit.

Links go places, buttons do things If clicking it navigates to a URL, use <a href>. If it triggers an action on the current page, such as opening a menu, use <button>. This matters for keyboards and screen readers.

§4Common Mistakes

MistakeWhat HappensFix
Using "click here" or "read more" as the only link textOut of context, a list of links tells users nothingDescribe the destination: "Read the pricing guide"
Writing href="www.example.com" without a schemeIt is treated as a relative path and 404sInclude https://
Using Windows paths like C:\site\img.pngWorks on your machine onlyUse forward slashes and relative or root-relative paths
Linking to an id that doesn't existThe link silently does nothingCheck that the fragment matches an element's id, case-sensitively
Practice
  1. Create two pages, index.html and about.html, that link to each other with relative links, plus one fragment link within a long page.
  2. Move about.html into a folder and fix the links on both pages.
Key takeaways
  • Write link text that describes the destination.
  • Know the three URL forms and how each resolves; ../ climbs a folder.
  • Use #id fragments for in-page jumps and rel with target when opening a new tab.
