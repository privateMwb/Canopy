The head Element

<head> is invisible to visitors but controls how browsers, search engines, and social apps treat your page.

§1What Belongs in head

Only metadata and resource links belong in <head>: the title, character set, viewport, description, stylesheets, icons, and scripts that must load early.

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Pruning Tomatoes | Canopy Garden</title>
  <meta name="description" content="When and how to prune tomato plants for bigger harvests.">
  <link rel="canonical" href="https://example.com/pruning-tomatoes/">
  <link rel="stylesheet" href="/css/site.css">
  <link rel="icon" href="/favicon.ico" sizes="32x32">
  <link rel="icon" href="/icon.svg" type="image/svg+xml">
  <link rel="apple-touch-icon" href="/apple-touch-icon.png">
</head>

Put charset first, within the first 1024 bytes, so the browser decodes the rest correctly.

§2Title, Description, and Canonical

The <title> is the clickable headline in search results, the tab label, and the bookmark name. Make it unique and descriptive, with the specific part first. The meta description is a summary search engines may show beneath it. The canonical link states the preferred URL when the same content is reachable at several.

ElementGuideline
<title>Unique per page, roughly under 60 characters
meta descriptionOne or two sentences, around 150 characters; not a ranking factor, but it affects clicks
link rel="canonical"Absolute URL of the preferred version

§3Icons and Theme Color

Browsers request /favicon.ico by default, but declaring icons explicitly lets you use SVG and larger touch icons. theme-color tints the browser chrome on some mobile browsers.

<meta name="theme-color" content="#0F766E">
<link rel="manifest" href="/site.webmanifest">

Everything in <head> is document-level information; anything that renders on the page itself goes in <body>.

Check by searching your own title If two pages on a site share the same <title>, search results and browser history can't tell them apart. Give every page its own.

§4Common Mistakes

MistakeWhat HappensFix
Reusing the same <title> on every pageTabs, history, and search results are indistinguishableWrite a unique title per page
Adding meta keywordsSearch engines ignore themSkip it; write a good description instead
Forgetting the canonical on pages with tracking parametersDuplicate URLs split search signalsPoint canonical to the clean URL
Practice
  1. Write the full head for a three-page site, giving each page a unique title and description.
  2. View the head of two sites you use and list which tags each one includes.
Key takeaways
  • head holds metadata, not visible content.
  • A unique title and description on every page is the minimum.
  • Declare charset, viewport, canonical, and icons explicitly.
