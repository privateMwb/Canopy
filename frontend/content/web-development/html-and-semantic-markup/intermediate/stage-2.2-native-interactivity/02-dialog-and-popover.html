dialog & Popover

dialog and the popover attribute give you modals, non-modal panels, focus handling, and light dismiss natively.

§1The dialog Element

Call showModal() to open a modal dialog. The browser traps focus inside, makes the rest of the page inert, closes on Escape, restores focus to the opener, and renders the ::backdrop. show() opens it non-modally.

<button id="open">Delete account</button>

<dialog id="confirm" aria-labelledby="t">
  <h2 id="t">Delete your account?</h2>
  <p>This cannot be undone.</p>
  <form method="dialog">
    <button value="cancel">Cancel</button>
    <button value="delete">Delete</button>
  </form>
</dialog>

<script>
  const d = document.querySelector("#confirm");
  document.querySelector("#open").addEventListener("click", () => d.showModal());
  d.addEventListener("close", () => console.log(d.returnValue));
</script>

A <form method="dialog"> closes the dialog on submit and sets returnValue to the clicked button's value, with no JavaScript for the closing logic.

§2The popover Attribute

popover turns any element into a top-layer, light-dismissable panel. A button with popovertarget toggles it, and the browser handles Escape, clicking outside, and keyboard focus return.

<button popovertarget="tip">Help</button>
<div id="tip" popover>
  <p>Tips and shortcuts live here.</p>
</div>

[popover] { padding: 1rem; border: 1px solid #ccc; }
[popover]::backdrop { background: rgb(0 0 0 / .2); }

popover="manual" disables light dismiss, for panels you control yourself. Use popover for menus, tooltips, and notifications; use dialog when the user must respond before continuing.

§3Choosing Between Them

NeedUse
Block the page until the user respondsdialog with showModal()
Non-blocking panel, menu, or tooltippopover attribute
Inline expand and collapsedetails

Always give a dialog an accessible name (aria-labelledby pointing at its heading) and an obvious way to close it.

Free behavior Focus trapping, Escape handling, inert background, and returning focus are the parts custom modals most often get wrong. The native elements do them correctly.

§4Common Mistakes

MistakeWhat HappensFix
Opening a dialog with the open attribute instead of showModal()No backdrop, no focus trap, page stays interactiveCall showModal() for modal behavior
Building a modal from a positioned divNo focus management or inert backgroundUse dialog
Giving a dialog no way to close it except EscapeMouse and touch users get stuckInclude a visible Close or Cancel button
Practice
  1. Build a delete-confirmation modal using dialog and method="dialog", and read the return value.
  2. Make a help popover with popovertarget and test Escape, outside click, and keyboard focus.
Key takeaways
  • dialog.showModal() gives focus trapping, Escape, and a backdrop for free.
  • popover creates light-dismissable panels with no script.
  • Use a dialog for required responses and a popover for optional panels.
