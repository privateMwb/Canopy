Text-Level Semantics

time, abbr, code, mark, data, and friends add machine-readable meaning inline, and most pages skip them.

§1Dates, Numbers, and Abbreviations

<time> pairs human-readable text with a machine-readable datetime. <data> does the same for other values. <abbr> expands an abbreviation, and <dfn> marks the defining instance of a term.

<p>Posted <time datetime="2026-03-14">14 March 2026</time>.</p>
<p>The talk starts at <time datetime="19:30">7:30 pm</time>.</p>
<p>Price: <data value="1499">$14.99</data></p>
<p><abbr title="Web Content Accessibility Guidelines">WCAG</abbr> sets the bar.</p>
<p>A <dfn>landmark</dfn> is a region of the page users can jump to.</p>

title on <abbr> appears only on hover, which excludes touch and keyboard users. Spell terms out on first use and use abbr afterward as an enhancement.

§2Code, Keyboard, and Quotes

<code> for code fragments, <pre> for preformatted blocks, <kbd> for keys the user presses, <samp> for program output, <var> for variables, and <cite> for the title of a creative work.

<p>Press <kbd>Ctrl</kbd> + <kbd>S</kbd> to save.</p>
<pre><code>npm install
npm test</code></pre>
<p>The tool printed <samp>Build complete</samp>.</p>

§3Highlights, Changes, and Small Print

<mark> highlights text that is relevant in the current context, such as a search match. <ins> and <del> mark insertions and deletions. <s> marks content that is no longer accurate, and <small> marks side comments such as legal text. <sub> and <sup> are for subscripts and superscripts.

<p>Results for <mark>tomato</mark>: 12 matches.</p>
<p>Was <s>$20</s> now $15. H<sub>2</sub>O, x<sup>2</sup></p>
<p><del datetime="2026-01-02">old text</del> <ins>new text</ins></p>

Choose by meaning: <strong> for importance, <mark> for relevance, <em> for emphasis.

Why bother Machine-readable values help search engines, reader modes, calendars, and extensions. <time datetime> is what lets a browser or assistant offer "add to calendar" for you.

§4Common Mistakes

MistakeWhat HappensFix
Using <i> or <b> out of habitNo meaning conveyedUse em, strong, cite, or mark when they fit
Using <abbr title> as the only explanationNot available to touch or keyboard usersExpand on first use in the text
Skipping the datetime formatTools can't parse itUse ISO 8601 such as 2026-03-14 or 2026-03-14T19:30
Practice
  1. Mark up a blog post header with an author line, a published date using time, and a reading time.
  2. Rewrite a paragraph about a keyboard shortcut using kbd, code, and samp where they apply.
Key takeaways
  • Small inline elements add meaning: time, abbr, code, kbd, mark.
  • Use ISO 8601 for datetime values.
  • Choose inline tags by what the text means, not how it looks.
