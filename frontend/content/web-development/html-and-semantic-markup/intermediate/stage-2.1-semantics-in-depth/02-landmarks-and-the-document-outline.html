Landmarks & the Document Outline

Landmarks, skip links, and a clean heading hierarchy are three ways users jump around a page without reading all of it.

§1Landmarks as Shortcuts

Landmark elements map to ARIA roles that screen readers list and jump between. Use them once or label them when repeated.

ElementLandmark roleNotes
<header> (top level)bannerOnce per page
<nav>navigationLabel if more than one
<main>mainOne per page
<aside>complementaryTangential content
<footer> (top level)contentinfoOnce per page
<section> with a nameregionOnly if it has an accessible name
<form> with a nameformOnly if named
<search>searchWraps a site search; newer element
<nav aria-label="Primary">...</nav>
<nav aria-label="Breadcrumb">...</nav>
<nav aria-label="Pagination">...</nav>

When two landmarks of the same type exist, give each a distinct aria-label so users can tell them apart.

§2Skip Links

Keyboard users otherwise tab through every navigation link on every page. A skip link is the first focusable element and jumps straight to <main>.

<body>
  <a class="skip" href="#main">Skip to main content</a>
  <header>...</header>
  <main id="main" tabindex="-1">...</main>
</body>

.skip { position: absolute; left: -9999px; }
.skip:focus { left: 8px; top: 8px; background: #fff; padding: 8px; }

Hide it visually until it receives focus, never with display: none, which removes it from the tab order.

§3Headings as Navigation

Screen reader users list headings the way sighted users scan them. Keep one h1, don't skip levels, and write headings that make sense alone. Prefer heading levels over the old HTML5 "outline algorithm", which browsers never implemented; only the level numbers count.

<main>
  <h1>Garden Planner</h1>
  <h2>Vegetables</h2>
    <h3>Tomatoes</h3>
  <h2>Herbs</h2>
</main>
Landmarks, not decoration Every landmark is an announcement in a screen reader's list. A page with 25 unlabeled regions is as unhelpful as one with none.

§4Common Mistakes

MistakeWhat HappensFix
Several <nav> elements with no labelsUsers hear "navigation" repeatedly and can't distinguish themAdd aria-label to each
Hiding the skip link with display: noneIt can never receive focusMove it off-screen and reveal on :focus
Relying on nested <h1>s per sectionBrowsers ignore the outline algorithmUse one h1 and numbered levels that reflect the hierarchy
Practice
  1. Add a working skip link and test it by pressing Tab as the first action on a page.
  2. List a page's headings using a browser extension or DevTools and rewrite any that don't make sense out of context.
Key takeaways
  • Use landmark elements once, and label repeats.
  • Add a skip link that appears on focus and targets main.
  • Heading level numbers define the outline; keep them sequential.
