Styling in the Framework

CSS Modules, Tailwind, and global styles.

§1Your Styling Options

The framework doesn't force a styling approach. The common choices are global CSS, CSS Modules, and Tailwind CSS. All three work with Server Components because they produce plain CSS at build time. Runtime CSS-in-JS libraries need extra setup because they rely on React context and client-side behaviour.

ApproachScopeBest for
Global CSSWhole appResets, design tokens, base typography
CSS ModulesOne component (class names are hashed)Component-specific styles without collisions
Tailwind CSSUtility classes in markupFast iteration and a consistent design system

§2Global Styles and CSS Modules

Import global CSS once, in the root layout. A file named *.module.css exports an object of generated class names, so .card in two modules never collides.

// app/layout.tsx
import "./globals.css";            // global styles, imported once

// app/card.tsx
import styles from "./card.module.css";
export function Card() {
  return <div className={styles.card}>…</div>;   // becomes card_card__x7Ab
}

§3Tailwind in the Framework

create-next-app can set up Tailwind for you. You write utility classes directly on elements, and the build step emits only the CSS you actually use, so the stylesheet stays small.

<button className="rounded-lg bg-emerald-600 px-4 py-2 text-white hover:bg-emerald-700">
  Save
</button>

Extract repeated class lists into a component rather than copying them, so each design decision lives in one place.

Pick one primary approach Mixing all three is possible but invites confusion about where a style lives. Choose one as the default for components, and keep global CSS for tokens and resets.

§4Common Mistakes

MistakeWhat HappensFix
Importing global CSS in many componentsStyles leak across the app and ordering becomes unpredictableImport global CSS once in the root layout
Building class names dynamically in Tailwind (bg-${color}-500)The class is never generated, so no style is appliedUse complete class names or a lookup map of full strings
Using a runtime CSS-in-JS library in Server ComponentsErrors, or styles that flash on loadPrefer build-time CSS, or isolate the library in client components
Practice
  1. Style one component three ways (global CSS, a CSS Module, Tailwind) and note which you'd prefer to maintain.
  2. Create a Button component with primary and secondary variants using full Tailwind class names in a lookup object.
Key takeaways
  • Global CSS, CSS Modules, and Tailwind all work cleanly with Server Components.
  • CSS Modules scope class names to a component; Tailwind composes utility classes.
  • Pick one default approach and extract repeated styling into components.
