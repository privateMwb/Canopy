Custom Properties

Custom properties are live, inheritable variables, which makes them the foundation for theming, spacing scales, and component APIs.

§1Declaring and Using

A custom property starts with --. Declare it on a selector, usually :root, and read it with var(), which accepts a fallback.

:root {
  --accent: #15803d;
  --space: 1rem;
  --radius: 8px;
}
.btn {
  background: var(--accent);
  padding: calc(var(--space) / 2) var(--space);
  border-radius: var(--radius);
  color: var(--btn-ink, white);    /* fallback if --btn-ink is not set */
}

Unlike Sass variables, custom properties exist at runtime: they follow the cascade and inheritance, and JavaScript can change them.

§2Scoping and Theming

Because they inherit, redefining a variable on an element changes it for everything inside. This is how themes and variants work.

:root { --bg: #fff; --ink: #1c1f26; }

@media (prefers-color-scheme: dark) {
  :root { --bg: #15171c; --ink: #edebe4; }
}
[data-theme="dark"] { --bg: #15171c; --ink: #edebe4; }

body { background: var(--bg); color: var(--ink); }

.card.warning { --accent: #a16207; }   /* a local override */

A component can expose a few custom properties as its public API, such as --card-pad or --card-bg, and keep everything else private.

§3Gotchas

  • Custom properties hold tokens, so the value is substituted before use. --x: 10 and width: var(--x) is invalid; include the unit.
  • Invalid values at *use* time make the property guaranteed-invalid, so it falls back to its inherited or initial value, not to your fallback.
  • Animating a custom property needs @property to give it a type; otherwise it flips instantly.
  • You can't use var() in media query conditions.
@property --angle {
  syntax: "<angle>";
  initial-value: 0deg;
  inherits: false;
}
.dial { transform: rotate(var(--angle)); transition: --angle .4s; }
.dial:hover { --angle: 90deg; }

Set them from JavaScript with el.style.setProperty("--progress", "40%"), which is a clean way to pass data into CSS.

Tokens, not magic numbers Define colors, spacing, radii, and type sizes once as custom properties and refer to them everywhere. A redesign becomes a handful of edits.

§4Common Mistakes

MistakeWhat HappensFix
Forgetting units in the valuecalc(var(--x) * 1) or width fails or is ignoredStore the value with its unit, or multiply by 1px
Defining everything on *Wasteful and unclear scopingDefine globals on :root and component values on the component
Expecting a fallback for an invalid valueThe fallback only applies for an *undefined* variableValidate token values and use @property for typed ones
Practice
  1. Convert a stylesheet's colors and spacing into custom properties on :root, then add a dark theme by redefining only the properties.
  2. Update a custom property from JavaScript to drive a progress bar's width.
Key takeaways
  • Define with --name, read with var(--name, fallback).
  • They inherit and follow the cascade, so they work for themes and variants.
  • Use @property to give them types and make them animatable.
