Fluid Type & Space Systems

A fluid system defines type and spacing as clamp() ranges between two viewport widths, so everything scales smoothly and consistently without breakpoints.

§1Fluid Values with clamp()

A fluid value scales linearly between a minimum at a small viewport and a maximum at a large one. The clamp() formula pins it at both ends.

/* scale from 1rem at 20rem viewport to 1.25rem at 80rem viewport */
:root {
  --step-0: clamp(1rem, 0.9167rem + 0.4167vw, 1.25rem);
}
/* general form:
   slope = (max - min) / (maxViewport - minViewport)
   intercept = min - slope * minViewport
   value = clamp(min, intercept + slope * 100vw, max) */

The rem part in the middle keeps the value responsive to the user's font settings. Generate these numbers with a calculator or build tool rather than by hand.

§2A Scale of Steps

Define a type scale as a ratio, a different one for small and large screens, and generate each step.

StepMin (320px)Max (1280px)Typical use
--step--10.83rem0.88remCaptions, small print

h1 { font-size: var(--step-5); line-height: 1.1; }

§3Fluid Space and Containers

Apply the same idea to spacing, so gaps and padding grow with the page and stay in proportion to the text.

:root {
  --space-s: clamp(0.75rem, 0.69rem + 0.29vw, 0.94rem);
  --space-m: clamp(1.5rem, 1.38rem + 0.58vw, 1.88rem);
  --space-l: clamp(2.25rem, 2.07rem + 0.87vw, 2.81rem);
}
.section { padding-block: var(--space-l); }
.stack > * + * { margin-block-start: var(--space-m); }

Always test at 200% browser zoom. Because the middle term uses rem, text that is vw-driven alone would fail to grow, so confirm the final value is larger at the zoomed viewport.

Zoom is the accessibility test WCAG requires text to resize to 200% without loss of content. A clamp() with a rem component scales correctly, but a pure vw size does not.

§4Common Mistakes

MistakeWhat HappensFix
Using vw alone for font sizesZooming doesn't enlarge text, which is an accessibility failureAdd a rem term in the preferred value
Hand-calculating every clamp()Typos and inconsistencyGenerate the scale from a script or tool
Making scales so steep that text is huge on wide screensPoor readabilityKeep the max value bounded
Practice
  1. Generate a fluid type scale for 320px to 1440px and apply it to a content page.
  2. Zoom the page to 200% and confirm body text grows, and nothing overlaps.
Key takeaways
  • Fluid values are clamp(min, rem + vw, max) ranges between two viewport widths.
  • Define type and space as scales of steps using custom properties.
  • Always include a rem term and test with browser zoom.
