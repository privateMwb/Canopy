Typography Basics

A few properties, font family, size, line height, weight, and measure, account for most of what makes text pleasant to read.

§1Font Stacks and Sizing

A font stack lists fonts in preference order, ending with a generic family as the fallback. System fonts are fast and need no download.

body {
  font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
  font-size: 1rem;      /* 16px by default */
  line-height: 1.6;
}
code { font-family: ui-monospace, "SF Mono", Menlo, monospace; }

Quote font names that contain spaces. Leave body text at 1rem or larger, and size headings relative to it.

§2Line Height, Measure, and Alignment

PropertyGood starting point
line-height for body1.5 to 1.7, unitless
line-height for headings1.1 to 1.3
Line length (measure)45 to 75 characters: max-width: 65ch
text-alignstart for paragraphs; avoid justify on narrow columns
font-weight400 body, 600 to 700 for emphasis
.prose { max-width: 65ch; }
.prose p { margin-block: 0 1em; }

§3Web Fonts

Load custom fonts with @font-face, ideally as WOFF2, and tell the browser how to behave while they load.

@font-face {
  font-family: "Inter";
  src: url("/fonts/inter-var.woff2") format("woff2");
  font-weight: 100 900;      /* variable font range */
  font-display: swap;        /* show fallback text immediately, swap when ready */
}
body { font-family: "Inter", system-ui, sans-serif; }

font-display: swap avoids invisible text, at the cost of a small layout shift. Pick a fallback with similar metrics, and load only the weights you use. Variable fonts pack many weights into one file.

Readability first Before choosing a font, fix size, line-height, and line length. A system font at 1rem with line-height: 1.6 and a 65ch measure beats a fancy font set badly.

§4Common Mistakes

MistakeWhat HappensFix
Setting line-height in px or remChildren inherit a fixed length that breaks at other sizesUse a unitless number
Letting lines run the full width of a wide screenHard to track from line to lineLimit the measure with ch
Loading six font weightsSlow page, flash of changing textLoad the weights you use, or a variable font
Using font-weight: bold to fake headings in divsNo semantic headingsUse real heading elements and style them
Practice
  1. Style an article with a system font stack, line-height: 1.6, and max-width: 65ch, then compare it with the unstyled page.
  2. Add one web font with @font-face and font-display: swap, and watch it load with a throttled network.
Key takeaways
  • Use font stacks ending in a generic family, and rem sizes.
  • Unitless line-height near 1.6 and a measure near 65ch make body text readable.
  • Load fonts as WOFF2 with font-display, and only what you need.
