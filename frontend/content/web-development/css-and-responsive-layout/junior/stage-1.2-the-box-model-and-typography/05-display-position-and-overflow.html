Display, Position & Overflow

display sets how a box participates in layout, position takes it out of normal flow when needed, and overflow decides what happens when content doesn't fit.

§1The display Property

ValueBehavior
blockStarts on a new line, fills available width
inlineFlows within text; ignores width and height
inline-blockFlows within text but accepts width and height
flex / gridMakes the element a layout container for its children
noneRemoves the element from layout and the accessibility tree

visibility: hidden hides an element but keeps its space; display: none removes it completely. Both hide it from assistive technology.

§2Positioning

.parent { position: relative; }          /* anchor for absolute children */
.badge  { position: absolute; top: 8px; right: 8px; }

.header { position: sticky; top: 0; z-index: 10; }   /* sticks when scrolled to top */
.modal  { position: fixed; inset: 0; }               /* relative to the viewport */
ValuePositioned relative toIn flow?
static(default)Yes
relativeIts normal position (offsets nudge it)Yes, space stays reserved
absoluteNearest positioned ancestorNo
fixedThe viewportNo
stickyIts scroll container, after a thresholdYes, until it sticks

§3Overflow

When content is larger than its box, overflow controls the result.

.box { overflow: visible; }   /* default: spills out */
.box { overflow: hidden; }    /* clips */
.box { overflow: auto; }      /* scrollbars only when needed */
.box { overflow-x: auto; }    /* e.g. wide tables or code blocks */

.truncate {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

Prefer auto over scroll. Be careful with overflow: hidden: it can clip focus rings, shadows, and sticky children.

Absolute needs an anchor An absolutely positioned element positions itself against the nearest ancestor that is itself positioned. If none is, it uses the page. Set position: relative on the intended parent.

§4Common Mistakes

MistakeWhat HappensFix
Using position: absolute for general layoutOverlaps and breaks when content changes sizeUse Flexbox or Grid for layout
Forgetting top: 0 on position: stickyIt never sticksSet a threshold such as top: 0
Hiding clipped content with overflow: hidden everywhereCuts off focus outlines and dropdownsFix the cause of the overflow instead
Practice
  1. Add a notification badge to the corner of an icon with relative and absolute.
  2. Make a header that stays visible with position: sticky, and find an ancestor overflow that breaks it.
Key takeaways
  • display controls the box type; none removes the element.
  • relative anchors, absolute places, sticky pins after scrolling.
  • Use overflow: auto for scrollable regions and avoid clipping by default.
