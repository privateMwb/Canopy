The Box Model

Every element is a rectangular box made of content, padding, border, and margin, and box-sizing: border-box makes the sizes behave the way you expect.

§1Four Layers

From the inside out: content (text or children), padding (space inside the border), border, and margin (space outside, between boxes). Padding shows the element's background; margin is always transparent.

.card {
  width: 300px;
  padding: 16px;
  border: 2px solid #ccc;
  margin: 24px auto;
}

Shorthands take values clockwise from the top: padding: 10px 20px 30px 40px is top, right, bottom, left. Two values are vertical then horizontal, and one value applies to all four sides.

§2box-sizing: border-box

By default (content-box), width sets only the content width, so padding and border are added on top. The .card above would take up 300 + 32 + 4 = 336px. With border-box, width includes padding and border, so it takes up exactly 300px.

*, *::before, *::after {
  box-sizing: border-box;
}

This one rule, placed at the top of nearly every stylesheet, removes most width arithmetic. Padding changes no longer break a layout.

§3Block vs. Inline Sizing

Block elements such as div and p fill the available width by default and can have width, height, and vertical margins. Inline elements such as span and a flow with text, ignore width and height, and only respect horizontal margin and padding for layout.

.badge {
  display: inline-block;   /* flows with text but accepts width, height, and vertical padding */
  padding: 2px 8px;
}

Use max-width with margin-inline: auto to center a block with a limit: max-width: 60rem; margin-inline: auto;.

Draw the box In DevTools, hover an element and look at the colored overlay: blue is content, green is padding, orange is margin. Seeing the boxes answers most "where is this space coming from?" questions.

§4Common Mistakes

MistakeWhat HappensFix
Leaving content-box as the defaultA 100% width element with padding overflows its parentApply box-sizing: border-box globally
Setting width on an inline elementNo effectUse display: inline-block or block
Using margin: auto without a widthNo visible centering; a block already fills its parentSet a width or max-width
Confusing padding with marginBackgrounds and click areas behave unexpectedlyPadding is inside the box, margin is outside
Practice
  1. Make a card with width: 300px, padding, and border, and measure its rendered width with and without border-box.
  2. Center a 40rem-wide article in the viewport using max-width and margin-inline: auto.
Key takeaways
  • Boxes are content, padding, border, and margin.
  • Use box-sizing: border-box everywhere.
  • Block elements accept width and height; inline elements don't.
