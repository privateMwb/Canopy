Flex Container Basics

display: flex turns an element into a one-dimensional layout container whose children line up along a main axis.

§1Container and Items

Setting display: flex on a parent makes it a flex container and its direct children flex items. By default the items sit in a row, side by side, and stretch to the container's height.

<ul class="nav">
  <li>Home</li>
  <li>Learn</li>
  <li>About</li>
</ul>

.nav {
  display: flex;
  gap: 1rem;
}

Only direct children become flex items. Grandchildren are laid out normally unless their parent is also a flex container.

§2Main Axis and Cross Axis

Flexbox thinks in two axes. The main axis is the direction items flow, and the cross axis is perpendicular to it. flex-direction picks the main axis.

flex-directionMain axisCross axis
row (default)Left to right (in LTR)Top to bottom
row-reverseRight to leftTop to bottom
columnTop to bottomLeft to right
column-reverseBottom to topLeft to right

Every alignment property depends on the axes: justify-content works on the main axis and align-items on the cross axis, so they swap roles when you switch to column.

§3Wrapping

By default, items squeeze onto one line, even if they have to shrink. Add flex-wrap: wrap to let them flow onto new lines.

.tags {
  display: flex;
  flex-wrap: wrap;
  gap: .5rem;
}
/* shorthand: flex-flow: row wrap; */

Each wrapped line becomes its own flex line, and items on one line are not aligned with items on another.

Order follows the source order and the -reverse directions change only the visual order. Keyboard focus and screen readers still follow the HTML order, so don't use them to reorder meaningful content.

§4Common Mistakes

MistakeWhat HappensFix
Applying display: flex to the items instead of the parentNothing lines upPut it on the container
Using margins to space itemsEdge cases and extra rules for first and last itemsUse gap
Forgetting flex-wrapItems shrink or overflow on small screensAdd flex-wrap: wrap where wrapping is wanted
Practice
  1. Turn a list of links into a horizontal nav with display: flex and gap.
  2. Switch the same list to flex-direction: column and note which alignment properties change meaning.
Key takeaways
  • display: flex on the parent makes its children flex items.
  • flex-direction chooses the main axis; the cross axis is perpendicular.
  • Use flex-wrap and gap for wrapping and spacing.
