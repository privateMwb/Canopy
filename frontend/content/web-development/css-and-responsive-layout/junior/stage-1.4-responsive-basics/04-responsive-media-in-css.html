Responsive Media in CSS

max-width: 100%, aspect-ratio, and object-fit keep images and video from overflowing, distorting, or causing layout shift.

§1Never Overflow the Container

A raster image has an intrinsic size, and a wide image will happily spill out of a narrow column. A short reset fixes this for all media.

img, video, svg, canvas {
  max-width: 100%;
  height: auto;
  display: block;   /* removes the small inline gap below images */
}

Keep width and height attributes in the HTML as well. The browser uses them to compute an aspect ratio before the file loads, and height: auto then keeps that ratio.

§2aspect-ratio

aspect-ratio reserves a box with a given proportion, which is useful for embeds, cards, and placeholders.

.thumb  { aspect-ratio: 4 / 3; }
.video  { aspect-ratio: 16 / 9; width: 100%; }
.avatar { aspect-ratio: 1; border-radius: 50%; }

It replaces the old padding-hack for responsive video wrappers, and prevents cumulative layout shift while the content loads.

§3object-fit and object-position

When an image's ratio doesn't match its box, object-fit decides how it fills the box, much like background-size.

.thumb img {
  width: 100%;
  height: 100%;
  object-fit: cover;          /* fill and crop */
  object-position: 50% 30%;   /* which part to keep visible */
}
.logo img { object-fit: contain; }   /* fit entirely, with spare space */
ValueBehavior
coverFills the box, cropping the overflow, no distortion
containFits inside the box, no cropping, may leave gaps
fill (default)Stretches to fill, which distorts
none / scale-downNatural size, or the smaller of natural and contain
Reserve space before it loads Between width/height attributes and aspect-ratio, a page should never jump as media arrives. Layout shift is something users feel, and Core Web Vitals measure.

§4Common Mistakes

MistakeWhat HappensFix
Leaving images at their natural widthOverflow and horizontal scrollingApply max-width: 100%; height: auto
Setting both width and height in CSS to force a cropDistorted imagesUse object-fit: cover
Using the padding hack for aspect ratiosExtra markup and obscure CSSUse aspect-ratio
Practice
  1. Create a grid of thumbnails with different source ratios that all display as uniform 4:3 boxes without distortion.
  2. Make a responsive 16:9 video embed using aspect-ratio.
Key takeaways
  • Apply max-width: 100% and height: auto to all media.
  • aspect-ratio reserves space and prevents layout shift.
  • object-fit: cover crops to fill; contain fits fully.
