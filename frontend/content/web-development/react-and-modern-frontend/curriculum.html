Checkpoints are deliberately unscaffolded. If you can finish one without hints, the stage actually landed, not just the following-along.

Levels aren't strict walls. State arrives at Junior as useState, returns at Intermediate as reducers, context, and server-state caches, and comes back at Senior as how React schedules and commits updates. Revisiting a topic at a harder level is expected.

Senior is about judgment as much as mechanism. Knowing how reconciliation works is one skill; deciding where each kind of state lives, how a codebase is organized, and whether React is the right tool at all is another, and the last stage is built around that gap.
