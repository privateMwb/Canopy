Route 53, DNS & TLS Certificates

Route 53 hosts your DNS records, and ACM issues the certificates that make your site HTTPS.

§1DNS Basics on Route 53

A hosted zone holds the records for a domain. You can register domains with Route 53 or point a domain registered elsewhere at its name servers.

RecordPurpose
A / AAAAName to IPv4 / IPv6 address
CNAMEName to another name (not allowed at the zone apex)
AliasAWS-specific: point a name, including the apex, at an AWS resource such as CloudFront or a load balancer
MX / TXTMail routing and verification

Prefer alias records for AWS targets: they work at the apex, follow the target's addresses, and DNS queries to them are not charged.

§2Certificates with ACM

AWS Certificate Manager issues free public certificates for use with CloudFront, load balancers, and API Gateway, and renews them automatically when validated by DNS.

aws acm request-certificate \
  --domain-name www.example.com \
  --validation-method DNS \
  --region us-east-1   # CloudFront requires certificates in us-east-1

Add the CNAME that ACM gives you to your hosted zone; once it validates, the certificate is ready. ACM public certificates cannot be exported to install on your own servers.

§3Routing Policies

Beyond simple records, Route 53 can use weighted, latency-based, failover, and geolocation routing, with health checks to take unhealthy endpoints out of DNS answers. DNS caching means changes take as long as the record's TTL to spread, so lower it before a planned cutover.

TTL is a promise to caches Resolvers keep an answer for the full TTL. If you need a fast cutover, lower the TTL well in advance, then change the record.

§4Common Mistakes

MistakeWhat HappensFix
Using a CNAME at the zone apexNot allowed; the domain breaksUse an alias record
Requesting a CloudFront certificate in the wrong regionIt can't be selectedRequest it in us-east-1
Not adding the DNS validation recordCertificate stays pendingCreate the CNAME ACM shows you
Practice
  1. Create a hosted zone for a domain you own and add an alias record to a test resource.
  2. Request an ACM certificate with DNS validation and wait for it to become issued.
Key takeaways
  • Route 53 hosts DNS; use alias records for AWS resources, especially at the apex.
  • ACM provides free, auto-renewing certificates for supported AWS services.
  • TTLs control how fast changes propagate, so plan cutovers.
