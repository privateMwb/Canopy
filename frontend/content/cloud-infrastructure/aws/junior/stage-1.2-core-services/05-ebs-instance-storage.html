EBS & Instance Storage

EBS provides persistent disks for EC2, while instance store is fast but temporary, so you must know which one holds your data.

§1EBS Volumes

An EBS volume is a network-attached block device in a single AZ, attached to one instance at a time (multi-attach is possible on some types). It persists independently of the instance's lifecycle.

TypeGood for
gp3General purpose SSD; the usual default, with IOPS and throughput set independently
io2High-performance, latency-sensitive databases
st1 / sc1Throughput-oriented or cold HDD workloads

§2Snapshots

A snapshot is a point-in-time backup of a volume stored in S3-backed storage managed by AWS. After the first full copy, later snapshots store only changed blocks. You can create a new volume from a snapshot in any AZ in the region, or copy it to another region.

aws ec2 create-snapshot --volume-id vol-0123456789abcdef0 \
  --description "before upgrade"
aws ec2 create-volume --snapshot-id snap-0123456789abcdef0 \
  --availability-zone eu-west-1b --volume-type gp3

§3What Survives a Stop

EventEBS root volumeInstance store
RebootKeptKept
Stop / startKeptLost
TerminateDeleted by default (DeleteOnTermination)Lost
Hardware failureKeptLost

Use instance store only for caches and scratch data that can be rebuilt. Data volumes can be set to survive termination, and encryption can be turned on by default for the whole account.

EBS lives in one AZ A volume cannot be attached to an instance in another AZ. Moving across AZs means taking a snapshot and creating a new volume from it.

§4Common Mistakes

MistakeWhat HappensFix
Keeping important data on instance storeData lost on stop or failureUse EBS (or S3/managed databases) for anything durable
Never taking snapshotsOne mistake or failure means permanent lossSchedule snapshots, ideally with AWS Backup
Leaving unattached volumesQuietly billed per GB-monthReview and delete orphaned volumes
Practice
  1. Attach a second gp3 volume to an instance, format it, write a file, snapshot it, and restore into a new volume.
  2. Check which instance types in your region come with instance store.
Key takeaways
  • EBS volumes are persistent, AZ-bound disks; instance store is temporary.
  • Snapshots are incremental backups that can recreate volumes elsewhere.
  • Know what a stop, terminate, or failure does to each storage type.
