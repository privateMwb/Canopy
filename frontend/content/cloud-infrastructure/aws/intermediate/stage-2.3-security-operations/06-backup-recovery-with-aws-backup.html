Backup & Recovery With AWS Backup

AWS Backup centralizes backup policies across services, but a backup you have never restored is only a theory.

§1Plans, Vaults, and Selections

A backup plan defines schedule, retention, and lifecycle; a resource selection chooses what to protect, typically by tag; recovery points are stored in a backup vault. It covers EC2/EBS, RDS, Aurora, DynamoDB, EFS, S3, and more.

{
  "BackupPlanName": "daily-35d",
  "Rules": [{
    "RuleName": "daily",
    "TargetBackupVaultName": "main",
    "ScheduleExpression": "cron(0 3 * * ? *)",
    "Lifecycle": {"DeleteAfterDays": 35}
  }]
}

§2Protecting the Backups Themselves

  • Vault Lock makes backups immutable for a retention period, resisting ransomware and mistakes.
  • Copy backups to a second account and, where needed, a second region.
  • Encrypt with KMS keys that the production workload cannot delete.
  • Select resources by tag so new resources are covered automatically.

§3Prove the Restore

Restoring is the only test that matters. Schedule restore tests and measure how long they take; that duration is your real recovery time, not the number in a document.

aws backup start-restore-job --recovery-point-arn $ARN \
  --iam-role-arn $ROLE --metadata file://restore-metadata.json

AWS Backup also offers restore testing plans to automate this and report results.

Backups you can't restore don't exist Missing permissions, wrong keys, and untested procedures are discovered during an incident unless a drill discovers them first.

§4Common Mistakes

MistakeWhat HappensFix
Backups only in the same account and regionOne compromise or disaster removes everythingCopy to a separate account and region
No restore testsUnknown recovery time and hidden failuresSchedule regular restore tests
Retention too shortCorruption found after backups age outMatch retention to detection time and compliance
Practice
  1. Create a plan that backs up all resources tagged Backup=daily and run an on-demand job.
  2. Restore a recovery point to a new resource and time how long it takes.
Key takeaways
  • AWS Backup applies tag-driven policies across services.
  • Make backups immutable and copy them out of the account.
  • Test restores and record the real recovery time.
