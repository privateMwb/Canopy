SQS, SNS & EventBridge

SQS queues work, SNS fans messages out, and EventBridge routes events by rules, three tools for decoupling producers from consumers.

§1SQS: Queues

SQS holds messages until a consumer processes them. Producers and consumers run at their own pace, so a spike in traffic fills the queue instead of crashing the worker.

StandardFIFO
OrderingBest-effortStrict within a message group
DeliveryAt least once (duplicates possible)Exactly-once processing via deduplication
ThroughputVery high, nearly unlimitedLower; scales with message groups

When a consumer receives a message, it becomes invisible for the visibility timeout. If the consumer does not delete it in time, it reappears. Always delete after successful processing, and set the timeout longer than your processing time.

§2SNS: Pub/Sub

SNS publishes one message to many subscribers: SQS queues, Lambda functions, HTTP endpoints, email, or SMS. The common fan-out pattern is an SNS topic with several SQS queues subscribed, so each downstream system gets its own copy and its own backlog.

§3EventBridge: Event Routing

EventBridge receives events from AWS services, your apps, and SaaS partners, and sends them to targets based on rules matching event content.

{
  "source": ["app.orders"],
  "detail-type": ["OrderPlaced"],
  "detail": {"total": [{"numeric": [">", 1000]}]}
}
NeedUse
Buffer work for one consumer poolSQS
Broadcast the same message to many subscribersSNS (often with SQS)
Content-based routing, schemas, scheduling, many sourcesEventBridge
Queues absorb, topics broadcast If you need work to wait until something is ready, use a queue. If many systems should hear about the same thing, use a topic or event bus. Combine them: fan out to queues so each consumer is isolated.

§4Common Mistakes

No dead-letter queuePoison messages loop foreverConfigure a DLQ with a max receive count
Practice
  1. Create an SNS topic with two SQS queues subscribed and publish one message.
  2. Write an EventBridge rule that matches one event pattern and sends it to a Lambda function.
Key takeaways
  • SQS buffers work, SNS broadcasts, and EventBridge routes by content.
  • Standard queues deliver at least once, so consumers must be idempotent.
  • Combine topics with queues to give each consumer its own backlog.
