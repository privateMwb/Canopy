Viewing History & Changes

status, log, diff, and show let you see exactly what changed, what is staged, and what happened before.

§1Looking at the Present

git status                     # what is changed or staged
git status -s                  # short form
git diff                       # working tree vs. staging area
git diff --staged              # staging area vs. last commit

git diff alone shows only unstaged changes. After git add, use --staged.

§2Looking at the Past

git log                        # full history, newest first
git log --oneline --graph --decorate --all   # compact picture of branches
git log -n 5 --stat            # last five commits with changed files
git log -- path/to/file        # history of one file
git show a1b2c3d               # one commit: message and diff
git show HEAD~2                # two commits before the latest

Commits are identified by a hash. You can abbreviate it to the first 7 or so characters, as long as it is unique.

§3Comparing Any Two Points

git diff a1b2c3d b4e5f6a       # between two commits
git diff main feature          # between two branches
git diff HEAD~3 -- app.py      # one file against three commits ago

§4Finding Your Way

HEAD means "the commit you are on", HEAD~1 is its parent, and HEAD~3 is three back. These names work in almost every command.

The key insight When confused, run git status and git log --oneline --graph --all. Together they show where you are and how history is shaped.

§5Common Mistakes

MistakeWhat HappensFix
Expecting git diff to show staged changesIt appears empty after git addUse git diff --staged
Scrolling the full log for a fileHard to find what you needUse git log -- file or git log --oneline
Copying long hashes by handTypos and wasted timeUse the first 7 characters or HEAD~n
Practice
  1. Make five commits, then show the diff between the first and the last, and the history of one file.
  2. Create an alias git config --global alias.lg "log --oneline --graph --decorate --all" and use it.
Key takeaways
  • git status and git diff describe the present, git log and git show the past.
  • --staged shows what the next commit will contain.
  • HEAD~n names commits relative to where you are.
