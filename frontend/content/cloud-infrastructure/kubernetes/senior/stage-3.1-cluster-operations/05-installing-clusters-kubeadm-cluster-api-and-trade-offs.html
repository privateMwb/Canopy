Installing Clusters: kubeadm, Cluster API & Trade-Offs

You can build and manage clusters yourself with kubeadm or Cluster API, but the real question is which parts are worth owning.

§1What You Take On

Self-managing a cluster means you own the control plane lifecycle: provisioning, certificates, etcd, upgrades, and recovery, plus the node and add-on lifecycle. Reasons teams do it: on-premises or air-gapped requirements, control over versions and configuration, specialized hardware, or avoiding provider limits. The cost is on-call responsibility for components a provider would otherwise run.

§2kubeadm

kubeadm bootstraps a conformant cluster. It does not provision machines or install a network plugin; those are your job.

# On the first control plane node
kubeadm init --control-plane-endpoint "k8s-api.example.com:6443" \
             --pod-network-cidr=10.244.0.0/16 --upload-certs
# install a CNI (Cilium, Calico, ...)
# On additional nodes, using the join command printed by init
kubeadm join k8s-api.example.com:6443 --token <token> \
  --discovery-token-ca-cert-hash sha256:<hash>

Key decisions kubeadm leaves to you: a stable control plane endpoint (a load balancer or virtual IP in front of the API servers), a stacked or external etcd topology, the CNI, the container runtime, certificate renewal, and automation for upgrades.

etcd topologyTrade-off
Stacked (etcd on control plane nodes)Fewer machines, simpler; losing a node loses a control plane and an etcd member together
External (separate etcd cluster)More machines to run, but control plane and datastore fail independently

§3Cluster API

Cluster API (CAPI) manages clusters declaratively, using Kubernetes itself. A management cluster runs controllers that create workload clusters from objects such as Cluster, MachineDeployment, and MachineHealthCheck, through provider plugins for AWS, Azure, vSphere, and others.

kubectl apply -f my-cluster.yaml     # creates a Cluster, control plane, and worker MachineDeployment
kubectl get clusters,machines
# edit spec.version on the control plane object to trigger a rolling upgrade

Upgrading becomes editing a version field. Machines are replaced, not patched, and a MachineHealthCheck automatically replaces broken nodes. The price is operating the management cluster, which becomes critical infrastructure itself.

§4Other Options

  • Distributions: k3s and RKE2 (simplified, single-binary or hardened distributions), Talos Linux (an immutable, API-managed OS), OpenShift (a full platform with opinionated defaults).
  • Managed: EKS, GKE, AKS, or a managed service from a platform vendor, where the control plane is not your problem.

§5When Not To Self-Manage

Ask what advantage you actually get over a managed control plane. If there is no hard requirement, running one yourself trades engineer time and risk for little gain. If you must self-manage, automate everything, standardize on one installer, and treat cluster rebuilds as routine.

Pets versus cattle for clusters A cluster you cannot rebuild from code is a pet. Aim for clusters that can be recreated from automation and Git, so replacing a broken one is faster than repairing it.

§6Common Mistakes

MistakeWhat HappensFix
No stable control plane endpointNodes and users point at one API server that can failPut a load balancer or virtual IP in front
Hand-built clusters that cannot be recreatedRecovery depends on one person's memoryUse automation such as Cluster API or infrastructure as code
Self-managing without a strong reasonYou inherit on-call for the control planeUse a managed service unless a requirement forces otherwise
Practice
  1. Create a multi-node cluster with kubeadm in virtual machines, then add a node with kubeadm join.
  2. Write down three requirements that would justify self-managing instead of using a managed service.
Key takeaways
  • kubeadm bootstraps clusters but leaves endpoint, CNI, upgrades, and etcd topology to you.
  • Cluster API manages cluster lifecycles declaratively through a management cluster.
  • Self-manage only when a requirement demands it, and automate completely if you do.
