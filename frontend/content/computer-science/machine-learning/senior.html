Senior

Architecture mastery, research, systems, leadership.

This is a compiled overview — stage and lesson titles with short descriptions, pulled straight from the curriculum. Full written lessons for this level haven't been built yet (the way Junior's Stage 1.1 has).

3.1 — Deep Architecture Mastery

  • Transformer Architecture — Multi-head attention, positional encoding, layer norm.
  • Distributed Training — Mixed precision, gradient accumulation, distributed training.
  • Generative Models — Generative models: diffusion and autoregressive generation.
  • Reinforcement Learning Fundamentals — Reinforcement learning fundamentals.
  • RLHF & Preference Tuning — RLHF and preference tuning.
  • 🏁 Checkpoint — Implement a transformer block from scratch and verify it trains.

3.2 — Research and Experimentation

  • Reading Research Papers — Reading papers efficiently: abstract → figures → method → results.
  • Reproducing Research Results — Reproducing a paper's core result at a small scale.
  • Ablation Studies — Ablation studies.
  • Statistical Rigor in ML — Statistical rigor: significance, variance across runs, avoiding p-hacking.
  • 🏁 Checkpoint — Reproduce a recent paper's key experiment and write up what did and didn't hold.

3.3 — Systems and Scale

  • Model Compression — Quantization, pruning, distillation.
  • Retrieval-Augmented Generation (RAG) — Vector databases and retrieval-augmented generation (RAG).
  • Cost & Latency Tradeoffs — Cost and latency tradeoffs in production systems.
  • Fault-Tolerant System Design — Fallbacks, guardrails, graceful degradation.
  • 🏁 Checkpoint — Design a production system for a model with real latency/cost constraints.

3.4 — Technical Leadership

  • Scoping ML Problems — Scoping problems: deciding if ML is the right tool at all.
  • Communicating Model Limitations — Communicating limitations and uncertainty to non-technical stakeholders.
  • Code & Model Review — What to look for in code and model review.
  • Mentoring Engineers — Mentoring: finding why someone is stuck.
  • 🏁 Checkpoint — Write a structured critique of a peer's, or your own past, ML project.
