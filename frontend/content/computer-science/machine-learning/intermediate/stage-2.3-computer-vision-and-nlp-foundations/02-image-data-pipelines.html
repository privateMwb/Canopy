Image Data Pipelines

Augmentation, normalization, and batching — the preprocessing steps every image model depends on.

§1Normalization

from torchvision import transforms

transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])

Pixel values (0–255) get scaled to a consistent numeric range, exactly the same "why scaling matters" idea from feature engineering, applied to images. Pretrained models often expect the specific mean/std they were originally trained with.

§2Augmentation — Synthetic Variety From Real Data

transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),
    transforms.RandomRotation(15),
    transforms.ColorJitter(brightness=0.2),
    transforms.ToTensor(),
])

Augmentation randomly flips, rotates, or recolors training images each time they're loaded, effectively creating new training examples from existing ones. This is one of the most effective, cheapest ways to reduce overfitting on limited image data — the regularization lessons' ideas, applied specifically to vision.

§3Batching

from torch.utils.data import DataLoader

loader = DataLoader(dataset, batch_size=32, shuffle=True)

Images are processed in batches rather than one at a time, both for GPU efficiency (parallel matrix operations, as covered earlier) and because gradient estimates from a batch tend to be more stable than from a single example.

§4Common Mistakes

MistakeWhat HappensFix
Augmenting the validation/test setEvaluation no longer reflects real-world performanceOnly apply augmentation to the training set
Using the wrong normalization stats for a pretrained modelDegraded performance, since the model expects a specific input distributionMatch the normalization used during the pretrained model's original training
Practice
  1. Write a transforms.Compose pipeline with normalization and two augmentation steps for a training set.
  2. Write a separate, simpler pipeline (normalization only) for the validation set, and explain why they differ.
Key takeaways
  • Normalization scales pixel values to a consistent range, matching what the model (especially a pretrained one) expects.
  • Augmentation creates synthetic variety from existing images — cheap, effective regularization for vision tasks.
  • Augmentation belongs only on the training set, never on validation or test data.
