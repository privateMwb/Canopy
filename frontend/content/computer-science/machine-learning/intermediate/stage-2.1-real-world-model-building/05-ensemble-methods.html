Ensemble Methods

Random forests and gradient boosting — combining many weak models into one strong one.

§1The Core Idea

A single decision tree overfits easily. Ensembles combine many trees so their individual mistakes average out — the group is more reliable than any one member, the same reason a crowd's average guess often beats most individual guesses.

§2Random Forests — Combining Independent Trees

from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(n_estimators=200, max_depth=8)
model.fit(X_train, y_train)

A random forest trains many trees independently, each on a random subset of the data and features, then averages their predictions (or takes a majority vote, for classification). The randomness means individual trees make different mistakes, which cancel out on average.

§3Gradient Boosting — Combining Sequential Trees

from sklearn.ensemble import GradientBoostingClassifier
# or, more commonly in practice: XGBoost / LightGBM

model = GradientBoostingClassifier(n_estimators=200, learning_rate=0.1)
model.fit(X_train, y_train)

Unlike random forests, boosting trains trees sequentially — each new tree focuses specifically on correcting the previous trees' mistakes. This usually achieves higher accuracy than random forests, but is more sensitive to hyperparameters and more prone to overfitting if left unchecked.

§4Choosing Between Them

Random ForestGradient Boosting
TrainingTrees trained independently (parallel)Trees trained sequentially, each correcting the last
Typical accuracyStrong, reliable baselineOften higher, with more tuning effort
Overfitting riskLower, fairly forgiving defaultsHigher — needs careful tuning (learning rate, tree count)

§5Common Mistakes

MistakeWhat HappensFix
Using too high a learning rate with too many boosting roundsSevere overfittingLower the learning rate as you increase n_estimators
Assuming ensembles can't overfit because they're "robust"They absolutely can, especially boostingStill check train vs. test performance, same as any model
Practice
  1. Train a RandomForestClassifier and a GradientBoostingClassifier on the same dataset.
  2. Compare their cross-validated scores.
  3. In one or two sentences, describe a scenario where you'd prefer the more "forgiving" model over the higher-accuracy one.
Key takeaways
  • Ensembles combine many trees so individual mistakes average out.
  • Random forests train trees independently and average them; boosting trains sequentially, each tree fixing the last's errors.
  • Boosting often wins on accuracy but needs more careful tuning to avoid overfitting.
