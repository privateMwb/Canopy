Backpropagation

What's actually happening when a neural network "learns" — computing how much each weight contributed to the error, and nudging it accordingly.

§1The Two Passes

Training a neural network alternates between two steps: a forward pass (compute a prediction from the current weights) and a backward pass (compute how much each weight should change to reduce the error).

§2Forward Pass

prediction = network(input)
loss = loss_function(prediction, true_label)

Data flows through the layers in order, producing a prediction, then the loss function measures how wrong that prediction was.

§3Backward Pass — the Chain Rule, Applied Layer by Layer

Backpropagation uses calculus's chain rule to work backward from the loss, computing how much each weight in each layer contributed to the error — its gradient. A weight with a large gradient had a large effect on the error; a weight with a near-zero gradient barely mattered.

loss.backward()   # computes gradients for every weight in the network, automatically

Modern frameworks (PyTorch, TensorFlow) handle this calculus automatically — you almost never compute gradients by hand, but understanding what's happening explains why training sometimes behaves strangely (vanishing gradients, exploding gradients, learning rate sensitivity).

§4Then the Optimizer Updates the Weights

optimizer.step()   # nudges every weight slightly in the direction that reduces the loss

Backpropagation computes how to adjust each weight; the optimizer (covered next lesson) actually applies that adjustment, scaled by a learning rate.

§5Common Mistakes

MistakeWhat HappensFix
Forgetting to zero gradients between training stepsGradients accumulate across steps, corrupting the updateCall optimizer.zero_grad() before each .backward()
Treating backprop as a black box you never need to understandHard to debug training problems like vanishing gradientsKnow at least the forward/backward/update cycle at a conceptual level
Practice
  1. In your own words, describe what a "gradient" represents for a single weight.
  2. Explain, in one or two sentences, why forward and backward passes must happen in opposite directions through the network's layers.
Key takeaways
  • Forward pass: compute a prediction. Backward pass: compute how much each weight contributed to the error.
  • Backpropagation applies the chain rule layer by layer, working backward from the loss.
  • Frameworks automate the calculus — .backward() computes every gradient in one call.
