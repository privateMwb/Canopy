Generative Models

Diffusion models and autoregressive generation — two different approaches to generating new, realistic data.

§1Autoregressive Generation — One Piece at a Time

# generating text one token at a time, each conditioned on everything before it
for step in range(max_length):
    next_token_probs = model(generated_so_far)
    next_token = sample(next_token_probs)
    generated_so_far.append(next_token)

Autoregressive models (the approach behind most large language models) generate output sequentially — each new piece is predicted conditioned on everything generated so far. This is exactly how a language model produces text: one token at a time, each choice influenced by all the previous ones.

§2Diffusion Models — Starting From Noise

Diffusion models (common in image generation) work very differently: they learn to reverse a gradual noising process. Training shows the model images with progressively more noise added; generation starts from pure random noise and repeatedly asks the model to remove a little noise, step by step, until a coherent image emerges.

# conceptual generation loop
x = random_noise()
for t in reversed(range(num_steps)):
    x = denoise_step(model, x, t)
# x is now a generated image

§3Why the Approaches Differ

AutoregressiveDiffusion
Generation processSequential, one piece at a timeIterative denoising, whole output refined together
Common domainText, codeImages, audio
Generation speedScales with output lengthScales with number of denoising steps

Practice
  1. In your own words, describe the difference between generating "one token conditioned on the past" and "denoising an image step by step."
  2. Explain why autoregressive generation speed scales with output length, while diffusion's scales with the number of denoising steps.
Key takeaways
  • Autoregressive models generate sequentially, each piece conditioned on everything before it — the basis of most language models.
  • Diffusion models learn to reverse a noising process, generating by iteratively denoising from random noise.
  • The two approaches suit different domains and have very different generation-time computational patterns.
