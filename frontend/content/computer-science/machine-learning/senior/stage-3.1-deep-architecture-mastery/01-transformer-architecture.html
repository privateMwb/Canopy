Transformer Architecture

Inside the block: multi-head attention, positional encoding, and layer normalization — the pieces that make a transformer work.

§1Multi-Head Attention

A single attention mechanism learns one way of relating positions to each other. Multi-head attention runs several attention computations in parallel, each with its own learned weights — one head might learn to track grammatical relationships, another might track topical similarity. Their outputs are concatenated and combined.

# conceptually, for h heads:
head_i = Attention(Q @ W_q_i, K @ W_k_i, V @ W_v_i)
output = Concat(head_1, ..., head_h) @ W_o

Each head operates on a smaller dimension than the full model, so multi-head attention costs roughly the same compute as one large attention head, while letting the model attend to several different kinds of relationships simultaneously.

§2Positional Encoding — Giving Attention a Sense of Order

Attention itself has no inherent notion of sequence order — swapping two tokens' positions wouldn't change attention's output on its own. Positional encodings inject order information directly into each token's representation before attention is applied, often using fixed sine/cosine patterns or learned position embeddings.

x = token_embedding(tokens) + positional_encoding(positions)

§3Layer Normalization — Keeping Training Stable

x = layer_norm(x + sublayer(x))   # a "residual connection" plus normalization, repeated after every sublayer

Layer norm rescales activations within each layer to have a consistent distribution, which substantially stabilizes training in deep networks. The residual connection (adding the input back to the sublayer's output) helps gradients flow through very deep stacks of transformer blocks without vanishing.

§4Putting the Block Together

x = x + MultiHeadAttention(x)
x = LayerNorm(x)
x = x + FeedForward(x)
x = LayerNorm(x)

A full transformer stacks many of these blocks — each one refining the representation further, with attention mixing information across positions and the feed-forward layer processing each position independently.

§5Common Mistakes

MistakeWhat HappensFix
Omitting positional encodingThe model can't distinguish "dog bites man" from "man bites dog"Always inject positional information before attention
Treating multi-head attention as just "attention but bigger"Misses that heads can specialize in different relationship typesUnderstand heads as parallel, independently-learned attention patterns
Practice
  1. In your own words, explain why attention alone can't distinguish word order without positional encoding.
  2. Describe what a residual connection does, and why it helps very deep networks train.
Key takeaways
  • Multi-head attention runs several attention patterns in parallel, letting the model capture different kinds of relationships at once.
  • Positional encoding injects sequence order, which attention itself doesn't inherently have.
  • Layer normalization and residual connections keep very deep transformer stacks trainable.
