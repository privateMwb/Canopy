Model Compression

Quantization, pruning, and distillation — making a trained model smaller and faster without starting over.

§1Why Compress a Model That Already Works

A model that performs well in training might be too large or too slow to actually deploy — too much memory for a mobile device, too much latency for a real-time application. Compression trades a small amount of accuracy for significant gains in size and speed.

§2Quantization — Fewer Bits Per Number

# converting 32-bit weights to 8-bit integers
import torch.quantization as quant

quantized_model = quant.quantize_dynamic(model, dtype=torch.qint8)

Quantization reduces the numeric precision used to store weights (and sometimes activations) — from 32-bit floats down to 8-bit integers, for example. This can shrink model size by roughly 4x and speed up inference, with often-surprisingly-small accuracy loss.

§3Pruning — Removing Unnecessary Weights

# removing weights below a magnitude threshold
import torch.nn.utils.prune as prune

prune.l1_unstructured(layer, name="weight", amount=0.3)   # prune the smallest 30% of weights

Many trained networks have weights that contribute very little to the final output. Pruning removes these (setting them to zero, or removing them structurally), shrinking the effective model size — often with minimal accuracy impact, since those weights weren't doing much anyway.

§4Knowledge Distillation — Training a Smaller "Student"

# a small student model learns to mimic a large teacher model's outputs,
# not just the ground-truth labels
loss = distillation_loss(student_output, teacher_output, true_labels)

Distillation trains a smaller "student" model to match a larger "teacher" model's predictions (not just the original labels). The teacher's output probabilities carry more nuanced information than hard labels alone — often letting a much smaller student approach the teacher's accuracy.

§5Common Mistakes

MistakeWhat HappensFix
Quantizing without checking accuracy afterwardSilent, sometimes significant accuracy loss goes unnoticedAlways re-evaluate on a held-out set after any compression step
Pruning too aggressively in one stepAccuracy collapsesPrune gradually, with fine-tuning steps in between
Practice
  1. In your own words, explain the tradeoff compression makes, and when it's worth accepting.
  2. Describe the key difference between pruning and distillation as compression strategies.
Key takeaways
  • Compression trades a small accuracy cost for significant gains in size and inference speed.
  • Quantization reduces numeric precision; pruning removes low-impact weights; distillation trains a smaller model to mimic a larger one.
  • Always re-evaluate accuracy after compression — the impact isn't always negligible.
