Logistic Regression

How a model turns a continuous score into a probability, and a probability into a class prediction.

§1From Line to Probability

Despite the name, logistic regression is a classification model. It computes a continuous score (like linear regression), then squashes it through a function that maps any number into the range 0 to 1 — a probability.

from sklearn.linear_model import LogisticRegression

model = LogisticRegression()
model.fit(X_train, y_train)

model.predict(X_test)           # class labels: 0 or 1
model.predict_proba(X_test)     # probabilities for each class

§2Reading predict_proba

model.predict_proba(X_test)
# [[0.82, 0.18],
#  [0.35, 0.65]]
# columns: [P(class 0), P(class 1)]

.predict() is really just .predict_proba() with a threshold applied — by default, whichever class has probability > 0.5 wins.

§3Why the Threshold Matters

0.5 isn't always the right cutoff. For a medical test, you might lower the threshold to catch more true positives, accepting more false alarms in exchange. The probability is the real output — the 0.5 default is just one choice of where to draw the line.

§4Common Mistakes

MistakeWhat HappensFix
Assuming the name means it's a regression modelUsing it on the wrong kind of problemIt's a classifier — the name is historical, not descriptive of its output
Treating 0.5 as the only valid thresholdMissing better trade-offs for the specific problemUse predict_proba and choose a threshold deliberately
Practice
  1. Fit a LogisticRegression on a small binary classification dataset.
  2. Print predict_proba for the test set.
  3. Manually apply a 0.7 threshold instead of the default 0.5, and compare the resulting predictions to .predict()'s.
Key takeaways
  • Logistic regression outputs a probability, then applies a threshold to get a class label.
  • predict_proba shows the underlying probabilities; .predict() is that plus a 0.5 cutoff by default.
  • The right threshold depends on the problem — 0.5 is a default, not a rule.
