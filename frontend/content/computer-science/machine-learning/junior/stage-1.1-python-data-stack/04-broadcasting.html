Broadcasting

Broadcasting: how NumPy combines arrays of different shapes, and why it's the engine behind feature scaling.

§1The Problem Broadcasting Solves

You often need to combine a 2D array with a 1D array — for example, subtracting each column's mean from every row in that column. Looping through rows manually would work, but NumPy can do it directly.

import numpy as np
data = np.array([
    [1, 100],
    [2, 200],
    [3, 300],
])

col_means = data.mean(axis=0)   # shape (2,) -> [2. 200.]
centered = data - col_means
# [[-1. -100.]
#  [ 0.    0.]
#  [ 1.  100.]]

data has shape (3, 2) and col_means has shape (2,). NumPy automatically "stretches" col_means across all 3 rows — this is broadcasting.

§2The Broadcasting Rule

Two shapes are compatible if, comparing from the right, each dimension either matches or one of them is 1 (or missing). A shape (2,) lines up against the last dimension of (3, 2) because 2 == 2.

(3, 2)  +  (2,)    # OK — last dims match (2 == 2)
(3, 2)  +  (3,)    # ERROR — last dims don't match (2 != 3)

§3Feature Scaling — the Real-World Use

Features on very different scales (like 1–3 vs. 100–300) can hurt many ML models. Standardizing rescales every column to mean 0, standard deviation 1 — and it's just broadcasting:

standardized = (data - data.mean(axis=0)) / data.std(axis=0)

Both the subtraction and the division broadcast across every row automatically. This single line is doing, in effect, a full loop over every row and column — with no loop written.

§4Worked Example

scores = np.array([
    [90, 85, 70],
    [60, 75, 80],
    [95, 90, 100],
    [50, 65, 55],
])

standardized = (scores - scores.mean(axis=0)) / scores.std(axis=0)
standardized.mean(axis=0)   # ~[0. 0. 0.] — standardizing always re-centers to 0

Tiny values like 1e-16 instead of an exact 0 are floating-point noise, not a bug.

§5Common Mistakes

MistakeWhat HappensFix
Shapes don't align on the last dimensionValueError: operands could not be broadcastCheck shapes align from the right; reshape if needed
Assuming broadcasting averages or combines valuesMisreading what the operation doesBroadcasting only repeats the smaller array — it never changes values on its own
Practice
  1. Create a 4×2 array of made-up height/weight pairs.
  2. Standardize both columns using the formula above.
  3. Print the result, and confirm each column's mean is ~0 and std is ~1.
Key takeaways
  • Broadcasting lets NumPy combine arrays of different (but compatible) shapes without an explicit loop.
  • Shapes align from the right; each dimension must match or be 1.
  • Standardization — (data - mean) / std — is broadcasting applied to feature scaling, a step you'll use in nearly every ML pipeline.
