Groupby vs. value_counts

groupby for aggregating a different column, value_counts for just counting rows — the distinction that takes the most reps to stick.

§1Two Different Jobs

These two tools get confused constantly because they both involve "categories," but they answer different questions:

ToolQuestion it answers
value_counts()"How many rows are in each category?"
groupby(...)[...].agg()"What's the [mean/sum/max] of a different column, per category?"

§2value_counts — Pure Counting

import pandas as pd
df = pd.DataFrame({"city": ["NYC", "LA", "NYC", "Chicago", "LA", "NYC"]})

df["city"].value_counts()
# NYC        3
# LA         2
# Chicago    1

Needs only one column — it counts how many times each value appears.

§3groupby — Aggregating a Second Column

df2 = pd.DataFrame({
    "month": ["Jan", "Jan", "Feb"],
    "temp": [40, 50, 60],
})

df2.groupby("month")["temp"].mean()
# Feb    60.0
# Jan    45.0   — the two Jan rows got averaged into one

Needs two columns — one to group by, one to aggregate. Nothing is counted; values are combined (mean, sum, max, etc.).

§4The Mistake That Happens Most Often

# WRONG — tries to do both jobs in one confused call
df.groupby("store")["day"].value_counts()
# gives counts PER (store, day) combo — not what "orders per store" asked for

# RIGHT — just counting rows per store, no second column needed
df["store"].value_counts()

If you only need a count, reach for value_counts() directly. Only bring in groupby when you're computing a statistic on a separate column.

§5Worked Example

orders = pd.DataFrame({
    "store": ["NYC", "LA", "NYC", "Chicago"],
    "amount": [25, 40, 30, 15],
})

orders["store"].value_counts()                 # count of orders per store
orders.groupby("store")["amount"].mean()         # average amount per store

§6Common Mistakes

MistakeWhat HappensFix
Using groupby just to count rowsOvercomplicated, often wrong shape of resultUse value_counts() directly
Using value_counts() on an aggregate question ("average X per Y")No way to compute an average with itUse groupby("Y")["X"].mean()
Practice
  1. Create a DataFrame of 8 orders with store, amount, and day.
  2. Print how many orders came from each store (one column needed).
  3. Print the average amount per day (two columns needed).
  4. In one sentence, explain why each step used the tool it did.
Key takeaways
  • value_counts() → counting rows per category, one column.
  • groupby(...)[...].agg() → combining a different column's values per category, two columns.
  • Ask: "am I counting rows, or combining a different column's values?" before picking a tool.
