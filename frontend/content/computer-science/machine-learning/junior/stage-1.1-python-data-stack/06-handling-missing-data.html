Handling Missing Data

Handling missing data with fillna and dropna, and the reassignment rule that trips up nearly everyone at first.

§1Why Missing Data Matters

Real datasets are full of gaps — a sensor failed, a form field was skipped. Most models can't handle NaN directly, so every gap needs a deliberate decision before training.

import pandas as pd
df = pd.DataFrame({
    "name": ["Ann", "Ben", "Cara", "Dev"],
    "age": [23, None, 29, 41],
    "city": ["Paris", "Oslo", None, "Berlin"],
})

df.isna().sum()
# name    0
# age     1
# city    1

§2The Reassignment Rule

The single most common bug at this stage fillna() and dropna() return a new Series or DataFrame — they do not modify the original in place. If you don't assign the result back, the fix silently never happens. 
# WRONG — computed, then thrown away
df["age"].fillna(df["age"].median())

# RIGHT — reassigned
df["age"] = df["age"].fillna(df["age"].median())

§3Choosing a Fill Strategy

df["age"] = df["age"].fillna(df["age"].median())     # numeric, possible outliers
df["city"] = df["city"].fillna("Unknown")              # categorical
df.dropna()                                              # or: drop rows with any gap

Median vs. mean: median resists being skewed by outliers. If one value is far from the rest, the mean gets dragged toward it; the median doesn't.

values = [40, 42, 45, 41, 500]   # one outlier
mean   = 133.6    # dragged far from "typical"
median = 42       # still represents a typical value

Rule of thumb: check whether mean and median are close. If they're far apart, you have outliers — use median. If they're close, either works.

§4Worked Example

df["age"] = df["age"].fillna(df["age"].median())
df["city"] = df["city"].fillna("Unknown")
print(df)
#   name   age     city
# 0  Ann  23.0    Paris
# 1  Ben  29.0     Oslo
# 2 Cara  29.0  Unknown
# 3  Dev  41.0   Berlin

Known ages were 23, 29, 41 — sorted, the middle value (median) is 29, which fills Ben's gap.

§5Common Mistakes

MistakeWhat HappensFix
Calling .fillna() without reassigningOriginal column still has gapsdf["col"] = df["col"].fillna(...)
Using mean on skewed dataFill value doesn't represent a "typical" rowCheck mean vs. median first; prefer median if they differ a lot
Filling a categorical column with a number (e.g. 0)Misleading — looks like a real categoryUse an explicit label like "Unknown"
Practice
  1. Create a DataFrame with 5 rows, a numeric column with 2 gaps, and a text column with 1 gap.
  2. Fill the numeric gaps with the median — predict the value first.
  3. Fill the text gaps with "Unknown".
  4. Print isna().sum() again to confirm zero gaps remain.
Key takeaways
  • fillna/dropna return a new object — always reassign to keep the change.
  • Median resists outliers; mean doesn't. Check which fits your data before choosing.
  • Fill categorical gaps with an explicit label, not a stand-in number.
