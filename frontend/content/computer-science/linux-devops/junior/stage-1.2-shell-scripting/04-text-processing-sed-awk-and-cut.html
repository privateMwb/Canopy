Text Processing: sed, awk & cut

cut, sed, and awk are the standard tools for pulling fields out of text and rewriting it line by line.

§1cut and sort: Simple Columns

cut extracts fields by delimiter or character position. Combined with sort and uniq, it handles most quick summaries of delimited data.

cut -d: -f1,7 /etc/passwd            # username and shell
cut -c1-10 file.txt                  # first 10 characters of each line
cut -d, -f2 data.csv | sort | uniq -c | sort -rn

cut is strict: one delimiter character and no regex. For whitespace-aligned output such as ps or df, where the number of spaces varies, awk is the better tool.

§2sed: Stream Editing

sed applies editing commands to each line. The one you will use most is substitute, s/old/new/. Add g to replace every occurrence on a line, and -i to edit a file in place.

sed 's/foo/bar/' file.txt            # first match per line
sed 's/foo/bar/g' file.txt           # every match
sed -i.bak 's/localhost/db.internal/' app.conf   # in place, keeping a backup
sed -n '10,20p' file.txt             # print only lines 10 to 20
sed '/^#/d;/^$/d' config.conf        # delete comments and blank lines

§3awk: Fields and Logic

awk splits each line into fields ($1, $2, ...) on whitespace by default and runs a small program over every line. NR is the line number and NF the field count. It handles conditions and arithmetic too.

df -h | awk 'NR>1 {print $6, $5}'            # mount point and use%
awk -F: '$3 >= 1000 {print $1}' /etc/passwd  # regular users
awk '{sum += $2} END {print sum}' sales.txt  # total of column 2
awk '/ERROR/ {n++} END {print n+0}' app.log  # count matches
Which tool when? Use cut for fixed delimiters, sed for rewriting text, and awk when you need columns plus logic or math. If a one-liner grows beyond a screen, move it to a real script in a language like Python.

§4Common Mistakes

MistakeWhat HappensFix
Using sed -i without a backupA bad pattern overwrites the file with no way backUse -i.bak, or commit the file to Git first
Using cut on space-aligned outputRepeated spaces create empty fieldsUse awk, which splits on runs of whitespace
Writing a regex that matches too muchs/a.*b/X/ swallows everything between the first a and the last bAnchor patterns and test on sample data
Practice
  1. From /etc/passwd, print each username and its home directory with awk -F:.
  2. Use sed to replace a port number in a config file, and confirm the result with diff against the backup.
Key takeaways
  • cut pulls delimited columns, sed rewrites lines, and awk adds fields, conditions, and arithmetic.
  • sed -i edits files in place, so keep a backup or use version control.
  • Choose the simplest tool that works, and move to a script when a one-liner gets unreadable.
