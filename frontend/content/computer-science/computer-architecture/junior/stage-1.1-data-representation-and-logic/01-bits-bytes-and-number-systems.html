Bits, Bytes & Number Systems

Everything a computer stores, numbers, text, images, and instructions, is a pattern of bits, and what the pattern means depends entirely on how the program interprets it.

§1Bits, Bytes, and Powers of Two

A bit holds one of two values, 0 or 1, because a transistor can be reliably on or off. A byte is 8 bits and is the smallest unit most computers can address. With n bits you can represent 2^n different patterns.

BitsPatternsExample use
8256One byte; a character in ASCII
1665,536A short integer
324,294,967,296A typical int; an IPv4 address
64About 1.8 × 10^19A pointer on a 64-bit machine

Memory sizes use powers of two: 1 KiB is 2^10 = 1,024 bytes, 1 MiB is 2^20, and 1 GiB is 2^30. The names KiB, MiB, and GiB are the binary units, while KB, MB, and GB conventionally mean powers of ten (1,000 bytes and so on), and mixing them up produces the familiar gap between a disk's advertised and reported size.

§2Binary and Hexadecimal

Binary is positional like decimal, but each place is worth a power of two rather than a power of ten. Reading from the right, the places are 1, 2, 4, 8, 16, and so on.

0b1011 = 1*8 + 0*4 + 1*2 + 1*1 = 11

# Hexadecimal packs 4 bits into one digit (0-9, then A=10 ... F=15)
0xFF   = 1111 1111 = 255
0x3F   = 0011 1111 = 63
0xA5   = 1010 0101 = 165

# Quick conversion in Python
bin(165)        # '0b10100101'
hex(165)        # '0xa5'
int("a5", 16)   # 165

Hex is used because one byte is exactly two hex digits, which makes long bit patterns readable. Machine addresses, color values like #FF8800, and memory dumps are all written in hex.

§3Meaning Comes From Interpretation

The same 32 bits can be an integer, a floating-point number, four ASCII characters, or a machine instruction. The hardware doesn't tag them; the program decides. The bytes 0x41 0x42 0x43 are the text ABC in ASCII and the integer 4,276,803 if read as one value.

Byte order matters when a value spans several bytes. A little-endian machine, which includes x86-64 and most ARM systems, stores the least significant byte first. The 32-bit value 0x12345678 is laid out in memory as the bytes 78 56 34 12. Network protocols use big-endian ('network byte order'), so data crossing a network is converted.

#include <stdio.h>
#include <stdint.h>
int main(void) {
    uint32_t v = 0x12345678;
    unsigned char *p = (unsigned char *)&v;
    printf("%02x %02x %02x %02x\n", p[0], p[1], p[2], p[3]);   // little-endian: 78 56 34 12
}
The key insight A bit pattern has no meaning on its own. Every bug where 'the number is wrong' or 'the text is garbled' is a mismatch between how data was written and how it was read.

§4Common Mistakes

MistakeWhat HappensFix
Confusing KB with KiBCapacity numbers disagree by about 2.4% at KB/KiB and 7% at GB/GiBUse the binary units (KiB, MiB, GiB) when you mean powers of two
Ignoring byte order when reading binary dataMulti-byte values come out reversedConvert explicitly, such as with ntohl or a defined file format
Assuming a value has a fixed meaning independent of its typeThe same bytes print as different numbers or textTrack the type and width of every value you read or write
Practice
  1. Convert 0xC3 to binary and decimal, and 200 to binary and hex, by hand.
  2. Run the byte-order program on your machine. Does it print 78 56 34 12? Predict the output on a big-endian machine.
Key takeaways
  • n bits give 2^n patterns, and hex writes four bits per digit.
  • KiB, MiB, and GiB are powers of two, unlike KB, MB, and GB.
  • Meaning depends on interpretation, and byte order matters for multi-byte values.
