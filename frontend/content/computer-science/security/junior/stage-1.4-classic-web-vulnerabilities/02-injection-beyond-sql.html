Injection Beyond SQL

SQL injection is one member of a larger family: whenever user data is spliced into a command or path, an attacker can change what it means.

§1The Pattern

The SQL track showed how parameterized queries separate data from SQL. The same bug appears wherever a string is built and handed to an interpreter: operating-system shells, file paths, LDAP and NoSQL queries, and template engines. The cause and the cure are the same each time.

§2Command Injection

If an application builds a shell command from input, shell metacharacters (;, |, &&, backticks, $()) let the attacker append their own commands.

# Vulnerable: the shell parses the whole string
os.system("ping -c 1 " + host)       # host = "8.8.8.8; cat /etc/passwd"

# Safer: no shell, arguments passed as a list
subprocess.run(["ping", "-c", "1", host], shell=False)

Avoiding the shell entirely is the real fix. Allow-list the value as well (a valid hostname or IP), and prefer a library over shelling out at all.

§3Path Traversal

If a filename from the user is joined onto a directory, ../ sequences can climb out of it and read arbitrary files.

# Vulnerable
open("/srv/uploads/" + name)          # name = "../../etc/passwd"

# Safer: resolve, then verify the result stays inside the base directory
base = Path("/srv/uploads").resolve()
target = (base / name).resolve()
if not target.is_relative_to(base):
    abort(400)

Canonicalize first, then check. Filtering for ../ strings alone is easy to bypass with encodings and alternate separators.

One idea, many costumes Parameterized queries, argument arrays, and path containment all do the same job: keep user data in the data slot and out of the structure the interpreter parses.

§4Common Mistakes

MistakeWhat HappensFix
Building shell commands with string concatenationAttackers run arbitrary commands on the serverPass an argument list without a shell, or use a library
Blocklisting dangerous charactersNew tricks and encodings slip past the listAllow-list valid values and avoid the interpreter
Checking the filename string for ../ onlyEncoded or normalized variants escape the directoryResolve the full path and verify it's inside the base
Practice
  1. Rewrite a function that calls os.system with user input to use an argument list.
  2. Write a path-containment check and test it with ../x, an absolute path, and a symlink.
Key takeaways
  • Injection is data being parsed as commands, in SQL, shells, paths, and more.
  • Avoid the interpreter or pass arguments separately instead of concatenating strings.
  • Resolve paths before checking containment; don't just search for ../.
