Tries

A tree built specifically for prefixes — the structure behind autocomplete and dictionary lookups.

§1What Makes a Trie Different

A trie (pronounced "try," from retrieval) is a tree where each path from the root spells out a prefix — not of two children like a binary tree, but of as many children as there are possible next characters. Each node represents one character; a path from the root to a marked node spells a complete word.

class TrieNode:
    def __init__(self):
        self.children = {{}}    # character -> TrieNode
        self.is_word = False

§2Inserting a Word

def insert(root, word):
    node = root
    for char in word:
        if char not in node.children:
            node.children[char] = TrieNode()
        node = node.children[char]
    node.is_word = True

Each character walks (or creates) one more level down the trie. Words sharing a common prefix share the same path through the tree up to where they diverge — "cat" and "car" share the "ca" path, splitting only at the third character.

§3Searching and Prefix Checking

def search(root, word):
    node = root
    for char in word:
        if char not in node.children:
            return False
        node = node.children[char]
    return node.is_word

def starts_with(root, prefix):
    node = root
    for char in prefix:
        if char not in node.children:
            return False
        node = node.children[char]
    return True   # don't need is_word — just confirming the prefix path exists

Both operations are O(k), where k is the length of the word/prefix — independent of how many total words are stored, which is the trie's key advantage over, say, scanning a list of strings.

§4Why This Beats a Hash Set for Prefix Problems

The specific advantage A hash set can tell you if an exact word exists in O(1), but has no efficient way to answer "what words start with this prefix" — it would need to check every stored word. A trie answers that in O(k), which is exactly why autocomplete and spell-check systems use tries rather than hash sets.

Key takeaways
  • A trie is a tree where each path from the root spells out a prefix, with words sharing prefixes sharing paths.
  • Insert, search, and prefix-check are all O(k), where k is the word/prefix length.
  • Tries specifically excel at prefix queries, which hash sets can't answer efficiently.
