2D Dynamic Programming

Grid and string DP problems — edit distance and longest common subsequence, where state needs two indices.

§1When One Index Isn't Enough

Some problems compare or combine two sequences — two strings, or a 2D grid — and the state genuinely needs two indices to describe: "considering the first i characters of string A and the first j characters of string B." This is 2D DP.

§2Longest Common Subsequence

def lcs(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]

dp[i][j] represents the longest common subsequence of the first i characters of s1 and the first j characters of s2. If the current characters match, extend the diagonal's answer by 1; otherwise, take the best of skipping a character from either string.

§3Edit Distance

def edit_distance(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
    return dp[m][n]

Minimum number of insertions, deletions, or substitutions to turn one string into another. The base cases (dp[i][0] = i, dp[0][j] = j) represent "turning a string into empty" or "building a string from empty," each costing one operation per character.

§4Reading the 2D Table

Visualizing the grid A 2D DP table is literally a grid — rows for one sequence, columns for the other. Filling it row by row (or column by column) and tracing how each cell depends on its neighbors (left, up, diagonal) is the most reliable way to actually understand a new 2D DP recurrence, rather than just memorizing the code.

§5Common Mistakes

Getting the base case row/column wrongEntire table fills with incorrect valuesCarefully reason through what dp[i][0] and dp[0][j] represent before coding
Confusing LCS and edit distance's recurrencesApplying the wrong transition ruleLCS only rewards matches; edit distance costs every mismatch — keep the goals distinct
Practice
  1. By hand, fill in the DP table for the longest common subsequence of "ABCBDAB" and "BDCABA" (or a smaller example if preferred).
  2. Explain, in one or two sentences, why edit distance's base case row/column counts up linearly.
Key takeaways
  • 2D DP problems need two indices of state, often comparing two sequences or navigating a grid.
  • LCS rewards matching characters; edit distance costs every insertion, deletion, or substitution.
  • Visualizing the DP table as a grid, cell by cell, is the most reliable way to understand a new recurrence.
