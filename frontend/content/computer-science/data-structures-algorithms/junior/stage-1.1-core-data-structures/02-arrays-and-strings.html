Arrays & Strings

Contiguous memory, indexing, and which operations are cheap versus expensive.

§1Why Arrays Are Fast to Index

An array stores its elements in one contiguous block of memory. Because every element is the same size, the computer can jump directly to index i with simple arithmetic — no searching required. This is why array[i] is O(1), regardless of array size.

§2What's Cheap, What's Expensive

OperationComplexityWhy
Read by indexO(1)Direct memory address calculation
Append to the endO(1) amortizedUsually just writes to the next free slot
Insert at the start/middleO(n)Every later element must shift over by one
Search for a valueO(n)No shortcuts without extra structure (sorting, hashing)

§3Strings Are Arrays of Characters

s = "hello"
s[0]          # 'h' — O(1), same as array indexing
s + "!"       # creates a NEW string — most languages treat strings as immutable

Many languages treat strings as immutable — every "modification" actually builds a new string. Repeatedly concatenating in a loop can silently turn an O(n) operation into O(n²), since each concatenation copies everything built so far.

# O(n²) — each += copies the growing string so far
result = ""
for char in long_list:
    result += char

# O(n) — build a list, join once at the end
result = "".join(long_list)

§4Common Mistakes

MistakeWhat HappensFix
Repeated string concatenation in a loopSilent O(n²) blowup on large inputsBuild a list and join once, instead of concatenating repeatedly
Assuming insert-at-start is O(1) like appendUnexpectedly slow code on large arraysRemember inserting anywhere but the end requires shifting elements
Practice
  1. Explain why array.append(x) is typically O(1) while array.insert(0, x) is O(n).
  2. Rewrite a loop that builds a string with repeated += to instead use a list and a single join.
Key takeaways
  • Arrays support O(1) indexed access because elements sit in contiguous, equally-sized memory slots.
  • Appending is cheap; inserting or deleting anywhere else requires shifting elements, costing O(n).
  • Strings are often immutable — repeated concatenation in a loop can silently become O(n²).
