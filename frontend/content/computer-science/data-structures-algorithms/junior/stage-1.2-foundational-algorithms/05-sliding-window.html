Sliding Window

Tracking a moving subrange of an array efficiently, instead of recomputing it from scratch every time.

§1The Problem It Solves

Many problems ask about every contiguous subarray of a fixed (or variable) size — "the maximum sum of any 3 consecutive elements," for example. Recomputing the sum from scratch for every possible window is O(n·k); a sliding window does it in O(n) total.

§2Fixed-Size Window

def max_sum_subarray(arr, k):
    window_sum = sum(arr[:k])
    max_sum = window_sum
    for i in range(k, len(arr)):
        window_sum += arr[i] - arr[i - k]   # add new element, remove the one sliding out
        max_sum = max(max_sum, window_sum)
    return max_sum

Instead of resumming the whole window each time, the window just adds the new element entering and subtracts the one leaving — turning an O(k) per-step update into O(1).

§3Variable-Size Window

# smallest subarray with sum >= target
def min_subarray_len(arr, target):
    left = 0
    current_sum = 0
    min_len = float("inf")
    for right in range(len(arr)):
        current_sum += arr[right]
        while current_sum >= target:
            min_len = min(min_len, right - left + 1)
            current_sum -= arr[left]
            left += 1
    return min_len if min_len != float("inf") else 0

Here the window grows by moving right forward, and shrinks by moving left forward whenever the condition is satisfied — expanding and contracting as needed, still touching each element a bounded number of times, still O(n) overall.

§4Recognizing When This Pattern Applies

The signal to look for "Contiguous subarray," "substring," or "window of size k" in a problem statement is usually a strong hint that sliding window applies — especially combined with wanting a sum, average, count, or some other property of that contiguous range.

§5Common Mistakes

MistakeWhat HappensFix
Recomputing the window sum from scratch each stepDefeats the purpose — back to O(n·k)Update incrementally: add the entering element, remove the exiting one
Forgetting to shrink the window when the condition is metVariable window never actually finds the minimumShrink from the left whenever the current window satisfies the condition

  1. Write a sliding-window function that finds the maximum average of any 4 consecutive elements in an array.

Key takeaways
  • Sliding window tracks a moving subrange incrementally instead of recomputing it from scratch each time.
  • Fixed windows slide by one; variable windows expand and contract based on a condition.
  • "Contiguous subarray/substring" problems are the strongest signal this pattern applies.
