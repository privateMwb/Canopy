Bitmask DP

Using a bitmask as DP state to efficiently track which elements of a small set have been used.

§1The Problem: Tracking a Subset Efficiently

Some DP problems need state like "which of these n items have I already used" — a subset of a small set. Representing that subset as a single integer, where bit i indicates whether item i is included, is dramatically more efficient than any other representation.

§2Bitmask Basics

mask = 0b0101   # items 0 and 2 are included (bits set from the right, 0-indexed)

mask | (1 << i)      # set bit i (include item i)
mask & (1 << i)       # check if bit i is set
mask & ~(1 << i)      # clear bit i (exclude item i)
bin(mask).count("1")  # how many items are included

A single integer can represent any subset of up to ~20-25 items (the practical limit, since 2^n states grow fast) — far more compact than a set or list, and comparisons/updates are simple bitwise operations.

§3A Worked Example: Traveling Salesman (Small n)

# dp[mask][i] = shortest path visiting exactly the cities in `mask`, ending at city i
def tsp(dist, n):
    dp = [[float("inf")] * n for _ in range(1 << n)]
    dp[1][0] = 0   # start at city 0, only city 0 visited
    for mask in range(1 << n):
        for i in range(n):
            if not (mask & (1 << i)) or dp[mask][i] == float("inf"):
                continue
            for j in range(n):
                if mask & (1 << j):
                    continue
                new_mask = mask | (1 << j)
                dp[new_mask][j] = min(dp[new_mask][j], dp[mask][i] + dist[i][j])
    return min(dp[(1 << n) - 1][i] + dist[i][0] for i in range(n))

The DP state is "which cities have I visited, and where am I now" — exactly what a bitmask plus a current-node index captures. This turns an O(n!) brute-force tour-checking problem into O(2ⁿ · n²), still exponential but dramatically better for n up to about 20.

§4When Bitmask DP Applies

The signal to look for "Visit all," "use each item exactly once," or "subset of a small set (n ≤ ~20)" in a problem statement, combined with needing to track which specific elements have been used — that combination is the strongest signal bitmask DP is the right tool.

§5Common Mistakes

MistakeWhat HappensFix
Using bitmask DP when n is too large (> ~25)2ⁿ states become computationally infeasibleBitmask DP only works for small n — look for other approaches on larger inputs
Off-by-one errors with bit indicesWrong item gets toggledBe explicit and consistent about 0-indexing bits

Key takeaways
  • Bitmask DP represents a subset of a small set as a single integer, enabling efficient state tracking.
  • This is the standard approach for "visit all / use each exactly once" problems with small n.
  • It only scales to roughly n ≤ 20-25, since the state space grows as 2ⁿ.
