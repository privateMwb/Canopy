Strongly Connected Components

Finding tightly-linked clusters in a directed graph, where every node can reach every other.

§1What a Strongly Connected Component Is

In a directed graph, a strongly connected component (SCC) is a maximal group of nodes where every node can reach every other node in the group, following directed edges. A graph can be broken into several SCCs, each one internally tightly connected.

§2Kosaraju's Algorithm — Two DFS Passes

# Step 1: DFS the original graph, record finish order (like topological sort)
# Step 2: reverse all edges
# Step 3: DFS the reversed graph in REVERSE finish order — each new tree is one SCC
def kosaraju(graph, reversed_graph, n):
    finish_order = topological_sort_style_dfs(graph, n)
    visited = set()
    sccs = []
    for node in reversed(finish_order):
        if node not in visited:
            component = dfs_collect(reversed_graph, node, visited)
            sccs.append(component)
    return sccs

The key insight: running DFS on the reversed graph, in the reverse order nodes finished in the original graph's DFS, naturally groups each SCC together — a clever reuse of the same finish-order idea from topological sort, applied twice with a reversal in between.

§3Why This Matters

SCCs reveal structure that isn't obvious from the raw edge list: in a dependency graph, an SCC means a genuine cycle of mutual dependencies (A needs B, B needs A, directly or indirectly) — exactly the kind of structural problem topological sort alone can only detect, not fully characterize.

§4Condensing a Graph by Its SCCs

A useful technique Once you've found a graph's SCCs, collapsing each one into a single "super-node" produces a new graph that's guaranteed to be a DAG — no cycles remain, since any cycle would have been absorbed into an SCC. This is a common first step before applying DAG-only techniques (like topological sort or DAG-based DP) to a graph that originally had cycles.

Key takeaways
  • A strongly connected component is a maximal group of nodes that can all reach each other via directed paths.
  • Kosaraju's algorithm finds SCCs using two DFS passes — one on the original graph, one on the reversed graph in reverse finish order.
  • Condensing a graph by its SCCs always produces a DAG, useful before applying DAG-only techniques.
