Minimum Spanning Tree

Kruskal's and Prim's algorithms — connecting every node for the least total edge cost.

§1What a Spanning Tree Is

A spanning tree of a connected graph touches every node using exactly n-1 edges, with no cycles — the minimal set of edges that keeps everything connected. A minimum spanning tree (MST) is the spanning tree with the lowest total edge weight.

§2Kruskal's Algorithm — Sort Edges, Add Greedily

# using Union-Find from the Intermediate level
def kruskal(edges, n):   # edges = [(weight, u, v), ...]
    edges.sort()
    parent = list(range(n))
    mst_weight = 0
    for weight, u, v in edges:
        if find(parent, u) != find(parent, v):
            union(parent, u, v)
            mst_weight += weight
    return mst_weight

Sort all edges by weight, then greedily add each edge unless it would create a cycle (checked via Union-Find — exactly the structure covered at the Intermediate level, now put to direct use). Each accepted edge connects two previously-separate components.

§3Prim's Algorithm — Grow One Tree

import heapq

def prim(graph, start, n):   # graph[node] = [(weight, neighbor), ...]
    visited = {{start}}
    edges = graph[start][:]
    heapq.heapify(edges)
    mst_weight = 0
    while edges and len(visited) < n:
        weight, node = heapq.heappop(edges)
        if node in visited:
            continue
        visited.add(node)
        mst_weight += weight
        for next_weight, neighbor in graph[node]:
            if neighbor not in visited:
                heapq.heappush(edges, (next_weight, neighbor))
    return mst_weight

Start from one node and grow the tree outward, always adding the cheapest edge that connects a new node — the same priority-queue pattern as Dijkstra, applied to a different goal.

§4Choosing Between Them

Kruskal'sPrim's
ApproachSort all edges, add greedily with cycle checksGrow one tree outward from a start node
Best forSparse graphs (few edges)Dense graphs (many edges)
Key structureUnion-FindPriority queue (min-heap)

§5Why Greedy Works Here

The cut property Both algorithms rely on a provable fact: for any way of splitting the graph's nodes into two groups, the cheapest edge crossing that split is guaranteed to be in some MST. This is what justifies always greedily picking the cheapest available valid edge — the same "prove the greedy choice is globally optimal" idea from the earlier greedy lesson, now with a concrete proof technique.

Key takeaways
  • A minimum spanning tree connects every node with the lowest total edge weight, using exactly n-1 edges.
  • Kruskal's sorts edges and adds greedily with Union-Find cycle checks; Prim's grows one tree using a priority queue.
  • Both rely on the cut property to guarantee their greedy choices are globally optimal.
