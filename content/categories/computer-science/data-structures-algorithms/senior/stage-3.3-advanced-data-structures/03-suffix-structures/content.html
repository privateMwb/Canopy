Suffix Structures

Suffix arrays and suffix tries — fast substring search at scale.

§1The Problem: Fast Substring Search

Checking if a substring exists in a text naively takes O(n·m) (scanning for an m-length pattern across an n-length text). If you need to answer many substring queries against the same text, preprocessing it into a suffix structure makes each query dramatically faster.

§2Suffix Array — All Suffixes, Sorted

def build_suffix_array(s):
    suffixes = sorted(range(len(s)), key=lambda i: s[i:])
    return suffixes

s = "banana"
# suffixes sorted: "a", "ana", "anana", "banana", "na", "nana"
# suffix array: [5, 3, 1, 0, 4, 2]

A suffix array stores the starting indices of every suffix of a string, sorted alphabetically. Once built, binary search over this sorted array finds any substring in O(m log n) — since any occurrence of a substring is a prefix of some suffix, and sorted suffixes group matching prefixes together.

§3Suffix Trie — Every Suffix, As a Trie

A suffix trie inserts every suffix of a string into a trie (from the Intermediate trie lesson) — every substring of the original string then corresponds to some path from the root. This gives O(m) substring search (just walk the trie), but at a steep memory cost: O(n²) in the worst case, since there are n suffixes each up to length n.

§4The Tradeoff

Suffix ArraySuffix Trie
MemoryO(n)O(n²) worst case
Substring searchO(m log n)O(m)
Common in practiceYes — the memory efficiency usually winsRare at scale, due to memory cost

§5Real-World Use

Where this actually shows up Suffix structures underlie genome sequence search (finding a DNA pattern within a massive genome), plagiarism detection, and full-text search engines — anywhere "find all occurrences of this pattern in a huge, fixed body of text" needs to happen fast, repeatedly.

§6Common Mistakes

MistakeWhat HappensFix
Building a suffix trie for a very large textMemory usage explodes (O(n²))Use a suffix array for large texts — far more memory-efficient
Rebuilding the suffix structure for every single queryDefeats the entire purpose of preprocessingBuild once, reuse for all queries against the same text
Practice
  1. Build the suffix array for the string "mississippi" by hand (list and sort the suffixes).
  2. Explain, in one or two sentences, why a suffix trie's memory usage can reach O(n²) in the worst case.
Key takeaways
  • Suffix structures preprocess a text once to make many subsequent substring queries fast.
  • Suffix arrays use O(n) memory with O(m log n) search; suffix tries use O(n²) memory with O(m) search.
  • Suffix arrays are far more common in practice due to their memory efficiency at scale.
