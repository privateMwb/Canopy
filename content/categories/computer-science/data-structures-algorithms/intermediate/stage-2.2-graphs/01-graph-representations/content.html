Graph Representations

Adjacency lists vs. adjacency matrices, and the tradeoffs between them.

§1What a Graph Is

A graph generalizes a tree — nodes (vertices) connected by edges, but without a tree's restriction to one parent per node or no cycles. Graphs can represent networks, dependencies, maps, relationships — anything where things connect to other things.

§2Adjacency List

graph = {{
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A"],
    "D": ["B"],
}}

Each node maps to a list of its neighbors. Space-efficient for sparse graphs (few edges relative to possible edges), and checking "what are this node's neighbors" is fast — just read the list.

§3Adjacency Matrix

#     A  B  C  D
# A   0  1  1  0
# B   1  0  0  1
# C   1  0  0  0
# D   0  1  0  0
matrix[i][j] = 1 if edge exists else 0

A 2D grid where matrix[i][j] indicates whether an edge exists between node i and node j. Checking "does this specific edge exist" is O(1) — just one lookup — but the matrix uses O(n²) space regardless of how many edges actually exist.

§4Choosing Between Them

Adjacency ListAdjacency Matrix
SpaceO(V + E) — efficient for sparse graphsO(V²) — regardless of edge count
"Does edge (i,j) exist?"O(degree of i)O(1)
"What are i's neighbors?"O(degree of i) — just read the listO(V) — must scan the whole row
Best forSparse graphs (most real-world graphs)Dense graphs, or frequent specific-edge checks

§5Directed vs. Undirected, Weighted vs. Unweighted

Edges can be one-directional (directed, like "follows" on social media) or bidirectional (undirected, like "friends with"). Edges can also carry a weight (a cost or distance) rather than just existing or not — both representations above extend naturally to store weights instead of just 0/1 or neighbor lists.

§6Common Mistakes

MistakeWhat HappensFix
Using an adjacency matrix for a large, sparse graphWastes enormous amounts of memory on mostly-empty cellsUse an adjacency list for sparse graphs — nearly always the right default
Forgetting to add both directions for an undirected edgeTraversal misses valid connectionsFor undirected graphs, add the edge to both nodes' neighbor lists
Practice
  1. Represent a 4-node graph (your choice of edges) as both an adjacency list and an adjacency matrix.
  2. Explain, in one or two sentences, why adjacency lists are the more common default choice in practice.
Key takeaways
  • Adjacency lists are space-efficient for sparse graphs and fast at listing a node's neighbors.
  • Adjacency matrices give O(1) specific-edge checks but use O(V²) space regardless of edge count.
  • Most real-world graphs are sparse, making adjacency lists the common default.
