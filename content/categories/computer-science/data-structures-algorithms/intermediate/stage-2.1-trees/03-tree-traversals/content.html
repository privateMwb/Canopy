Tree Traversals

In-order, pre-order, post-order, and BFS level-order — four different ways to walk the same tree.

§1Depth-First Traversals — Three Orders, One Idea

def inorder(node):     # left, node, right
    if node:
        inorder(node.left)
        visit(node.value)
        inorder(node.right)

def preorder(node):    # node, left, right
    if node:
        visit(node.value)
        preorder(node.left)
        preorder(node.right)

def postorder(node):   # left, right, node
    if node:
        postorder(node.left)
        postorder(node.right)
        visit(node.value)

All three are depth-first — they go as deep as possible before backtracking. They differ only in when the current node gets visited relative to its children.

§2Why In-Order Matters Specifically for BSTs

A useful fact In-order traversal of a binary search tree visits every value in sorted order, automatically — a direct consequence of the BST ordering rule. This is a common way to verify a tree is a valid BST, or to extract its contents sorted.

§3Breadth-First Traversal — Level by Level

from collections import deque

def level_order(root):
    if not root:
        return []
    result = []
    queue = deque([root])
    while queue:
        node = queue.popleft()
        result.append(node.value)
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)
    return result

Unlike the depth-first orders, level-order visits nodes level by level, left to right — and it uses a queue, not recursion, which directly connects back to the Stacks & Queues lesson: BFS naturally pairs with a queue, DFS naturally pairs with a stack (or recursion, which uses the call stack implicitly).

§4Choosing the Right Traversal

GoalTraversal
Get BST values in sorted orderIn-order
Copy/serialize a tree (reconstruct the structure later)Pre-order
Delete a tree safely (children before parent)Post-order
Process level by level (e.g. find the widest level)Level-order (BFS)

§5Common Mistakes

MistakeWhat HappensFix
Using recursion for level-order traversalMuch harder to track "which level am I on" correctlyUse an explicit queue for BFS-style level-order traversal
Mixing up pre-order and post-order visit timingWrong output order for tasks like tree deletion or serializationRemember: pre = node first, post = node last

Key takeaways
  • In-order, pre-order, and post-order are all depth-first, differing only in when the node itself is visited.
  • In-order traversal of a BST yields values in sorted order.
  • Level-order (BFS) traversal uses a queue, not recursion, and visits level by level.
