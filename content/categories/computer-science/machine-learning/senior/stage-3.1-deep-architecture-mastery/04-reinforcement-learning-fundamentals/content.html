Reinforcement Learning Fundamentals

Reward, policy, and value — the core vocabulary of learning through trial and error instead of labeled examples.

§1A Different Kind of Learning

Supervised learning (everything covered so far) learns from labeled examples: here's an input, here's the correct output. Reinforcement learning (RL) learns from consequences instead: an agent takes actions in an environment, receives rewards (or penalties), and learns which actions tend to lead to better outcomes over time.

§2The Core Loop

state = env.reset()
for step in range(max_steps):
    action = agent.choose_action(state)
    next_state, reward, done = env.step(action)
    agent.learn(state, action, reward, next_state)
    state = next_state
    if done:
        break

An agent observes the current state, chooses an action, receives a reward and a new state, and uses that experience to improve future decisions — repeated over many episodes.

§3Policy — the Decision-Making Strategy

A policy is the agent's strategy for choosing actions given a state — it can be as simple as a lookup table or as complex as a neural network. Learning in RL largely means improving this policy so it consistently picks actions leading to higher long-term reward.

§4Value — Estimating Long-Term Payoff

A value function estimates how good a given state (or state-action pair) is in terms of expected future reward, not just immediate reward. This matters because the best immediate action isn't always the best long-term one — sacrificing a short-term reward for a much larger later payoff is a core RL challenge, and value functions are how that tradeoff gets evaluated.

§5Exploration vs. Exploitation

The central tension Should the agent repeat actions it already knows work well (exploit), or try something new that might work even better (explore)? Too much exploitation gets stuck in a mediocre strategy; too much exploration never settles into using what it's learned. Most RL algorithms explicitly balance the two.

§6Common Mistakes

MistakeWhat HappensFix
Designing a reward that's easy to "hack"The agent finds an unintended shortcut that technically maximizes rewardCarefully design rewards to match the actual intended behavior
No exploration at allThe agent gets stuck repeating a suboptimal strategyBuild in deliberate exploration (e.g. occasionally trying random actions)
Practice
  1. For a simple maze-navigation agent, describe what the state, action, and reward might be.
  2. In one or two sentences, explain why a value function needs to consider future reward, not just immediate reward.
Key takeaways
  • RL learns from consequences (rewards) through trial and error, not from labeled examples.
  • A policy is the agent's action-choosing strategy; a value function estimates long-term expected reward.
  • Balancing exploration (trying new things) against exploitation (using what's known to work) is central to RL.
