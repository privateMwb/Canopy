NumPy Arrays & Vectorized Operations

NumPy arrays and the operations that apply to a whole array at once — the foundation every later lesson builds on.

§1Why This Matters

Almost everything in machine learning is math performed on large grids of numbers: features, weights, predictions, gradients. Python's built-in list was never built for that kind of math. NumPy's array was. Learning to think in arrays instead of loops is the first real shift from "writing Python" to "writing ML code."

§2Core Concept: Vectorization

A regular Python loop processes one number at a time:

# the loop version
prices = [10, 20, 30]
doubled = []
for p in prices:
    doubled.append(p * 2)
# [20, 40, 60]

A NumPy array applies the operation to every element at once, with no explicit loop:

import numpy as np

prices = np.array([10, 20, 30])
doubled = prices * 2
# [20 40 60]

This is called vectorization. NumPy runs the loop in compiled C code instead of interpreted Python — shorter to write, and significantly faster on real-sized data.

§3Creating Arrays

np.array([1, 2, 3])        # from a list
np.arange(5)                # [0 1 2 3 4]
np.arange(1, 11)            # [1 2 ... 10] — end is exclusive
np.zeros(4)                 # [0. 0. 0. 0.]
np.ones(4)                  # [1. 1. 1. 1.]
np.linspace(0, 1, 5)        # 5 evenly spaced points, 0 to 1
Watch for np.arange(1, 11) gives 1 through 10, not 1 through 11. The end value is always exclusive — this causes off-by-one errors constantly.

§4Element-Wise Arithmetic

a = np.array([1, 2, 3])

a + 5        # [6 7 8]
a * 2        # [2 4 6]
a ** 2       # [1 4 9]

b = np.array([10, 20, 30])
a + b        # [11 22 33] — same-shape arrays combine element-by-element

§5Aggregate Functions

Instead of looping to compute a sum or average, call a method directly on the array:

nums = np.array([4, 8, 15, 16, 23, 42])

nums.sum()     # 108
nums.mean()    # 18.0
nums.max()     # 42
nums.std()     # standard deviation

§6Boolean Masking

Comparing an array to a value produces an array of True/False, a mask:

nums > 15          # [False False False True True True]
nums[nums > 15]    # [16 23 42] — use the mask to filter

This "build a mask, then index with it" pattern is one of the most common things you'll do in both NumPy and pandas. It replaces a loop with an if inside it:

# the loop version, for comparison
result = []
for n in nums:
    if n > 15:
        result.append(n)

Combine conditions with & and | — never Python's and/or, which don't work element-wise. Wrap each condition in its own parentheses:

nums[(nums > 10) & (nums < 30)]    # [15 16 23]

§7Worked Example

Problem: given hourly temperatures (°F), find the average temperature on hours that were above freezing.

temps = np.array([28, 35, 40, 31, 45, 29, 50])

above_freezing = temps[temps > 32]
# [35 40 45 50]

average = above_freezing.mean()
# 42.5

No loop, no manual counting — the mask filters, and .mean() does the math.

§8Common Mistakes

MistakeWhat HappensFix
Using and/or on array conditionsValueError: truth value ambiguousUse & / | with parentheses around each condition
Forgetting arange's end is exclusiveOff-by-one errorsnp.arange(1, 11) for 1–10
Computing a mask but never applying itThe filter silently never happensAlways index with it: arr[mask]
Mixing mismatched array shapesValueError: could not be broadcastKeep shapes matched (Lesson 4 covers exceptions)
Practice
  1. Create an array of the numbers 1 to 20 (inclusive).
  2. Compute the square of every number.
  3. Keep only the squares divisible by 3.
  4. Print how many there are, and their sum.
Key takeaways
  • NumPy arrays apply operations to every element at once — no explicit loop.
  • np.arange(start, end) excludes end.
  • Build a mask (arr > x), then filter with it: arr[mask].
  • Combine conditions with & / |, each in parentheses — never and/or.
  • This pattern reappears constantly in pandas, starting next lesson.
