Boolean Masking & Filtering

Boolean masking, in depth: combining conditions, flipping them, and swapping values with np.where.

§1Beyond a Single Condition

Lesson 1 introduced the basic mask: arr[arr > 15]. Real filtering usually needs more than one condition at once.

import numpy as np
scores = np.array([55, 72, 88, 40, 91, 67])

mask = (scores >= 60) & (scores < 90)
scores[mask]        # [72 88 67]

Always wrap each condition in its own parentheses when combining with & or | — Python's operator precedence will otherwise group things incorrectly and raise an error.

§2Flipping a Mask

The ~ operator inverts a boolean mask — everywhere True becomes False and vice versa. This is the standard way to drop missing values:

vals = np.array([1.0, np.nan, 3.0, np.nan, 5.0])

np.isnan(vals)          # [False True False True False]
vals[~np.isnan(vals)]   # [1. 3. 5.] — keep everywhere NOT nan

§3np.where — Choosing a Value, Not Just Filtering

Sometimes you don't want to drop non-matching elements, you want to replace them. np.where(condition, if_true, if_false) does that element-wise:

temps = np.array([28, 35, 40, 31, 45])

np.where(temps > 32, "warm", "freezing")
# ['freezing' 'warm' 'warm' 'freezing' 'warm']

Unlike arr[mask], which shrinks the array to only matching elements, np.where keeps the array the same length — it just swaps in a different value at each position.

Filter vs. Replace arr[mask] returns fewer elements (only the matches). np.where(mask, a, b) returns the same number of elements, with values swapped in. Pick based on whether you want to discard or relabel.

§4Worked Example

Problem: given exam scores, label each one "pass" (≥60) or "fail", without removing any students.

scores = np.array([55, 72, 88, 40, 91])
labels = np.where(scores >= 60, "pass", "fail")
# ['fail' 'pass' 'pass' 'fail' 'pass']

§5Common Mistakes

MistakeWhat HappensFix
Combining conditions without parentheses: scores >= 60 & scores < 90TypeError, precedence mismatch(scores >= 60) & (scores < 90)
Using not to invert a maskFails on arrays with >1 elementUse ~mask
Expecting np.where to shrink the arrayConfusing output lengthUse arr[mask] instead if you want fewer elements
Practice
  1. Create an array of 15 random-looking integers between 1 and 100 (just type them in).
  2. Build a mask for values between 20 and 80 inclusive.
  3. Print the filtered result using the mask.
  4. Separately, use np.where to label every value "low" or "high" relative to 50, without removing any.
Key takeaways
  • Combine masks with & / |, each condition in its own parentheses.
  • ~mask inverts a boolean mask — the standard way to drop NaNs.
  • arr[mask] filters (shrinks); np.where(mask, a, b) relabels (same length).
