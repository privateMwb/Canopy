Sorting & Ranking

Sorting a DataFrame and pulling out the top (or bottom) N rows — a small tool used constantly in real analysis.

§1Basic Sorting

import pandas as pd
sales = pd.DataFrame({
    "product": ["A", "B", "C", "D", "E"],
    "units": [150, 190, 300, 90, 220],
})

sales.sort_values("units")                  # ascending by default
sales.sort_values("units", ascending=False) # descending

Like most pandas methods, sort_values returns a new DataFrame rather than sorting in place — reassign it if you want to keep the sorted order: sales = sales.sort_values(...).

§2Top-N and Bottom-N

sales.sort_values("units", ascending=False).head(2)   # top 2 sellers
sales.sort_values("units").head(2)                      # bottom 2 sellers
sales.sort_values("units", ascending=False).tail(2)     # the 2 lowest, after a descending sort

.head(n) takes the first n rows, .tail(n) the last n. Combined with a descending sort, .head() gives you a "top N" in one line — one of the most common analysis patterns there is.

§3Selecting Just the Columns You Need

sales.sort_values("units", ascending=False).head(2)[["product", "units"]]

Chaining like this — sort, then take the top rows, then select columns — is normal and common. Read it left to right: sort first, slice second, select columns last.

§4Worked Example

sales = pd.DataFrame({
    "product": ["A", "B", "C", "D", "E"],
    "units": [150, None, 300, 90, 220],
})
sales["units"] = sales["units"].fillna(sales["units"].mean())   # 190.0

top2 = sales.sort_values("units", ascending=False).head(2)
print(top2[["product", "units"]])
# product  units
#    C      300.0
#    E      220.0

§5Common Mistakes

MistakeWhat HappensFix
Expecting sort_values to sort in placeOriginal order unchanged if not reassigneddf = df.sort_values(...)
Using .head() without sorting firstReturns the first N rows in whatever order they already were, not the "top" NSort descending before calling .head()
Forgetting ascending=False for "top" resultsGets the smallest values instead of the largestSet ascending=False explicitly
Practice
  1. Create a DataFrame of 6 products with a revenue column.
  2. Sort it ascending and print the result.
  3. Print the top 3 products by revenue, showing only product and revenue.
  4. Print the single lowest-revenue product's name using idxmin() and .loc.
Key takeaways
  • sort_values returns a new DataFrame — reassign to keep the order.
  • "Top N" = sort descending, then .head(n).
  • Chain sort → slice → column selection, read left to right.
