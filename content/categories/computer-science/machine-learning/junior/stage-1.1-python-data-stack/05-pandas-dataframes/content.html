Pandas DataFrames

pandas DataFrames: the structure that holds real-world data, with named columns and mixed types.

§1Why pandas, Not Just NumPy

NumPy arrays hold only numbers, and every element must be the same type. Real data has names, categories, dates, and gaps. A pandas DataFrame is a table built for exactly that.

import pandas as pd

df = pd.DataFrame({
    "name": ["Ann", "Ben", "Cara", "Dev"],
    "age": [23, 35, 29, 41],
    "city": ["Paris", "Oslo", "Paris", "Berlin"],
    "salary": [3000, 5200, 4100, 6100],
})

§2Selecting Columns and Rows

df["age"]              # one column, as a Series
df[["name", "age"]]    # multiple columns, as a DataFrame
df.loc[0]               # row by label
df.loc[0, "name"]       # single value

§3Filtering — Same Mask Idea as NumPy

df[df["age"] > 30]            # rows where age > 30
df[(df["age"] > 25) & (df["salary"] > 4000)]   # combined conditions

Exactly the same pattern as Lesson 1-2: build a boolean mask, then index with it. The &/| + parentheses rules apply here too.

§4Adding and Computing Columns

df["bonus"] = df["salary"] * 0.1
df["salary_k"] = df["salary"] / 1000

§5groupby — Summarizing by Category

df.groupby("city")["salary"].mean()
# Berlin    6100.0
# Oslo      5200.0
# Paris     3550.0

groupby splits rows into groups by a shared value, then applies a function to each group. You'll use this constantly — it's covered in full in Lesson 8.

§6Worked Example

Problem: find the name of the highest-paid person.

label = df["salary"].idxmax()   # row label of the max value
df.loc[label, "name"]            # 'Dev'

Key takeaways
  • A DataFrame is a named, typed table — the structure most real data arrives in.
  • Filtering reuses the exact mask pattern from NumPy: build the condition, then index with it.
  • groupby summarizes by category; it's the single most-used pandas tool in practice.
