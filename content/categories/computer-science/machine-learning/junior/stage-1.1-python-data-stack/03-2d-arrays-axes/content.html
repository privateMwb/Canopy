2D Arrays & Axes

2D arrays, shapes, and the axis=0 vs. axis=1 distinction that trips up almost everyone at first.

§1From 1D to 2D

Real data is a table: rows are examples, columns are features. In NumPy that's a 2D array.

import numpy as np
data = np.array([
    [170, 65],   # person 1: height, weight
    [180, 80],   # person 2
    [160, 55],   # person 3
])

data.shape    # (3, 2) — 3 rows, 2 columns

§2Indexing Rows and Columns

data[0]        # first row: [170 65]
data[:, 1]     # all rows, column 1: [65 80 55]
data[0, 1]     # single cell: 65

[:, 1] reads as "every row, then just column 1." The colon alone means "take everything along this axis."

§3axis=0 vs. axis=1

Aggregate functions on a 2D array need to know which direction to collapse:

data.mean(axis=0)   # mean of each COLUMN: [170. 66.67] — collapses rows
data.mean(axis=1)   # mean of each ROW: [117.5 130. 107.5] — collapses columns
The rule that actually sticks axis=0 collapses rows, giving one result per column. axis=1 collapses columns, giving one result per row. If your result has one number per feature, you used axis=0. One number per example, axis=1.

§4Worked Example

Problem: given 4 students' scores across 3 exams, find each student's average and each exam's average.

scores = np.array([
    [90, 85, 70],
    [60, 75, 80],
    [95, 90, 100],
    [50, 65, 55],
])

scores.mean(axis=1)   # per-student average: [81.67 71.67 95. 56.67]
scores.mean(axis=0)   # per-exam average:    [73.75 78.75 76.25]

To then filter rows by a per-row statistic, build the mask from the aggregated result, not the raw grid:

passing = scores.mean(axis=1) > 75
scores[passing]
# [[ 90  85  70]
#  [ 95  90 100]]

§5Common Mistakes

MistakeWhat HappensFix
Mixing up axis=0 and axis=1Averages come out per-example instead of per-feature (or vice versa)Ask: "do I want one number per column or per row?"
Filtering rows with a mask shaped like the whole gridShape mismatch or wrong selectionBuild the mask from a per-row aggregate first: scores.mean(axis=1) > x
Practice
  1. Create a 5×3 array of any numbers you like (5 "people", 3 "features").
  2. Print its shape.
  3. Compute the mean of each column.
  4. Compute the mean of each row, then print only the rows whose mean is above the overall mean of all values.
Key takeaways
  • A 2D array's shape is (rows, columns).
  • axis=0 → one result per column. axis=1 → one result per row.
  • To filter rows by a computed statistic, build the mask from the aggregated (1D) result, not the raw 2D grid.
