Data Visualization with Matplotlib

Plotting with matplotlib: line, bar, and histogram charts, and what bins actually controls.

§1The Basic Pattern

import matplotlib.pyplot as plt

df_indexed = df.set_index("student")
df_indexed["score"].plot(kind="bar")
plt.title("Score by student")
plt.xlabel("Student")
plt.ylabel("Score")
plt.show()

Every chart needs its own plt.show() — without it, the next chart you draw gets layered onto the same figure instead of starting fresh.

§2Choosing a Chart Type

TypeUse for
kind="line"Trends over an ordered sequence (time, days, months)
kind="bar"Comparing categories (cities, products, students)
kind="hist"The distribution of one numeric column

A histogram only works on numbers — it buckets values into ranges. For a categorical column (city, product), count rows first with value_counts(), then plot that as a bar chart.

§3What bins Controls

data.plot(kind="hist", bins=3)    # 3 wide buckets — smoother, less detail
data.plot(kind="hist", bins=10)   # 10 narrow buckets — more detail, can look noisy

Rule of thumb: small dataset (under ~30 values) → 3-5 bins. Larger dataset → 10-20 bins is common.

§4Labeling by Category — set_index

df_indexed = df.set_index("student")
df_indexed["score"].plot(kind="bar")   # x-axis now shows student names

x= inside .plot() only works when called on the whole DataFrame, not a single column. The reliable way to label a chart by category is set_index first.

§5Worked Example — Full Chart Set

sales_indexed = sales.set_index("month")

sales_indexed["revenue"].plot(kind="line")
plt.title("Revenue per month"); plt.xlabel("Month"); plt.ylabel("Revenue")
plt.show()

sales["city"].value_counts().plot(kind="bar")   # categorical -> value_counts first
plt.title("Orders per city"); plt.xlabel("City"); plt.ylabel("Orders")
plt.show()

sales["revenue"].plot(kind="hist", bins=4)
plt.title("Revenue distribution"); plt.xlabel("Revenue"); plt.ylabel("Count")
plt.show()

§6Common Mistakes

MistakeWhat HappensFix
No plt.show() between chartsCharts overlap in one figureCall plt.show() after each chart
kind="hist" on a text columnError — can't bucket non-numeric dataUse value_counts().plot(kind="bar") instead
A histogram y-axis labeled with the measured unitMisleading — y-axis is always a countLabel it "Count" or "Number of ___"
Practice
  1. Using any small DataFrame with a category column and a numeric column, make a line chart of the numeric column over an ordered category (e.g. month).
  2. Make a bar chart of counts per category.
  3. Make a histogram of the numeric column with a bin count you justify in one sentence.
  4. Title and label the axes of all three.
Key takeaways
  • line → trend, bar → category comparison, hist → numeric distribution.
  • Categorical "distribution" needs value_counts() first; histograms are numeric-only.
  • Each chart needs its own plt.show(), and a histogram's y-axis is always a count.
