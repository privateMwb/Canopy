Regression Evaluation Metrics

MAE, MSE, and R² — three ways to measure how wrong a regression model's predictions are, and what each one emphasizes.

§1Why One Metric Isn't Enough

"How good is this model?" needs a number. Different metrics answer slightly different versions of that question — some care more about big mistakes than small ones, some are easier to interpret in plain units.

§2MAE — Mean Absolute Error

from sklearn.metrics import mean_absolute_error
mean_absolute_error(y_test, predictions)

The average size of the error, in the same units as your target. An MAE of 5 on exam-score predictions means predictions are off by 5 points on average. Easy to interpret, treats all errors proportionally.

§3MSE — Mean Squared Error

from sklearn.metrics import mean_squared_error
mean_squared_error(y_test, predictions)

Squares each error before averaging, so large errors are penalized disproportionately more than small ones. Harder to interpret directly (units are squared), but useful when big mistakes are especially costly.

§4R² — Coefficient of Determination

model.score(X_test, y_test)   # this IS R² for a regression model

Roughly: "what fraction of the variation in y does the model explain?" 1.0 is a perfect fit, 0 means the model does no better than just predicting the average every time, negative means it does worse than that.

Picking one MAE when you want an intuitive, interpretable number in real units. MSE/RMSE when large errors matter disproportionately. R² when you want a scale-free sense of "how much of the pattern did this capture."

§5Common Mistakes

MistakeWhat HappensFix
Comparing MAE across datasets with different units/scalesMisleading comparisonMAE is only comparable within the same target scale
Treating R² as "percent correct"Misinterprets what it measuresR² measures explained variance, not classification-style accuracy
Using only one metricMissing part of the picture (e.g. a few huge errors hidden in a good MAE)Check at least two metrics together
Practice
  1. Fit a LinearRegression on a small dataset and get predictions on a test set.
  2. Compute MAE, MSE, and R² for it.
  3. In one or two sentences, describe what each number tells you about the model.
Key takeaways
  • MAE: average error, in real units, easy to interpret.
  • MSE: penalizes large errors more heavily than small ones.
  • R²: fraction of variance explained, scale-free, 1.0 is perfect.
