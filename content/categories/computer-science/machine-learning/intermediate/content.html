  • Data Leakage — Data leakage: what it is, and how it quietly sneaks into pipelines.
  • Feature Engineering — Encoding categories, scaling numerics.

  • Hyperparameter Tuning — Hyperparameter tuning: grid search vs. random search.

  • Handling Imbalanced Data — Handling imbalanced data: resampling, class weights.

  • Regularization Techniques — Dropout, early stopping, weight decay.
  • GPU Acceleration — GPUs and why they accelerate training.
  • 🏁 Checkpoint — Train a feedforward network on tabular data and compare it to Stage 2.1's models.
