Tokenization & Embeddings

How text becomes numbers a model can actually process.

§1Tokenization — Splitting Text Into Pieces

from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
tokens = tokenizer("I love machine learning")
# token ids: [101, 1045, 2293, 3698, 4083, 102]

Text gets split into tokens — not always whole words. Modern tokenizers often use subword units (so "unhappiness" might split into "un", "happi", "ness"), which handles rare and made-up words far better than whole-word splitting, with a much smaller vocabulary.

§2From Tokens to IDs

Each unique token maps to an integer ID via the tokenizer's vocabulary — a fixed lookup table built when the tokenizer itself was trained. The model never sees raw text, only these integer sequences.

§3Embeddings — Turning IDs Into Meaningful Vectors

embedding_layer = nn.Embedding(vocab_size, embedding_dim=300)
vector = embedding_layer(token_id)   # a dense vector of 300 numbers

A raw token ID (like 4083) carries no meaning on its own — ID 4083 isn't "related to" ID 4084 in any semantic sense. Embeddings map each ID to a learned vector, positioned in space such that semantically similar words end up near each other. After training, "happy" and "joyful" end up with similar embedding vectors even though their token IDs might be numerically unrelated.

§4Why This Matters

This is the same "how do I turn raw input into features a model can use" problem from feature engineering, solved for text: tokenization is the encoding step, embeddings are the learned, meaning-preserving representation.

§5Common Mistakes

MistakeWhat HappensFix
Using a different tokenizer than the one a pretrained model expectsToken IDs don't match the model's vocabulary, garbage resultsAlways use the matching tokenizer for a given pretrained model
Treating token IDs as if their numeric value carries meaningMisunderstanding how the model actually represents wordsRemember IDs are arbitrary lookup keys — meaning comes from the embedding, not the ID
Practice
  1. Tokenize a short sentence using a pretrained tokenizer and print the resulting token IDs.
  2. In one or two sentences, explain why subword tokenization handles an unfamiliar word better than whole-word tokenization.
Key takeaways
  • Tokenization splits text into pieces (often subwords) and maps each to an integer ID.
  • Embeddings turn those arbitrary IDs into dense vectors where semantic similarity becomes spatial closeness.
  • A pretrained model's tokenizer and vocabulary must always be used together, never mixed with a different one.
