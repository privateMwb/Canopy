PyTorch Fundamentals

Tensors, autograd, and the standard training loop — the pieces every PyTorch model is built from.

§1Tensors — PyTorch's Arrays

import torch

x = torch.tensor([1.0, 2.0, 3.0])
x.shape          # torch.Size([3])
x.to("cuda")     # moves the tensor to a GPU, if available

A tensor is PyTorch's version of a NumPy array, with one crucial addition: it can track the operations performed on it, enabling automatic differentiation.

§2Autograd — Automatic Gradients

x = torch.tensor(2.0, requires_grad=True)
y = x ** 2
y.backward()
x.grad   # 4.0 — dy/dx at x=2, computed automatically

requires_grad=True tells PyTorch to track this tensor's operations. Calling .backward() computes gradients for every tracked tensor involved, exactly the mechanism underlying backpropagation from the previous lesson.

§3Defining a Model

import torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(10, 32)
        self.layer2 = nn.Linear(32, 1)

    def forward(self, x):
        x = torch.relu(self.layer1(x))
        return self.layer2(x)

model = Net()

§4The Standard Training Loop

optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
loss_fn = nn.MSELoss()

for epoch in range(num_epochs):
    optimizer.zero_grad()           # clear old gradients
    predictions = model(X_train)    # forward pass
    loss = loss_fn(predictions, y_train)
    loss.backward()                  # backward pass — compute gradients
    optimizer.step()                 # update weights

Every PyTorch training loop follows this same four-step rhythm: zero gradients, forward pass, backward pass, optimizer step. Once this pattern is familiar, most model code reads the same way regardless of architecture.

§5Common Mistakes

MistakeWhat HappensFix
Forgetting optimizer.zero_grad()Gradients accumulate across epochs, corrupting trainingAlways zero gradients at the start of each loop iteration
Forgetting model.eval() during evaluationLayers like dropout stay active during evaluation, adding noiseCall model.eval() before evaluating, model.train() before resuming training
Practice
  1. Define a small two-layer PyTorch network for a regression task with 5 input features.
  2. Write a training loop that runs for 50 epochs, printing the loss every 10.
Key takeaways
  • Tensors are PyTorch's arrays, with built-in gradient tracking via autograd.
  • Models are defined as classes with layers in __init__ and the forward computation in forward().
  • Every training loop follows the same rhythm: zero gradients, forward, backward, step.
