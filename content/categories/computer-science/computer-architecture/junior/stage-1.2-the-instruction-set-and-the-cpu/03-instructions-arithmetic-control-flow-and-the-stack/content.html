Instructions: Arithmetic, Control Flow & the Stack

A small set of instruction kinds, arithmetic, memory access, branches, and calls, is enough to express any program, and reading them is a skill that pays off throughout this course.

A shift left by 2 multiplies by 4, which is how an array index becomes a byte offset for 4-byte elements.

§2A Loop in Assembly

Here is a function that sums an array. The argument a0 is the array address and a1 the length, and the result returns in a0.

sum:
    li   t0, 0            # total = 0
    li   t1, 0            # i = 0
loop:
    bge  t1, a1, done     # if i >= n, leave the loop
    slli t2, t1, 2        # t2 = i * 4  (byte offset)
    add  t2, a0, t2       # t2 = address of a[i]
    lw   t3, 0(t2)        # t3 = a[i]
    add  t0, t0, t3       # total += a[i]
    addi t1, t1, 1        # i++
    j    loop
done:
    mv   a0, t0           # return total
    ret

This is the C loop for (i = 0; i < n; i++) total += a[i];. A branch at the top tests the exit condition, and a jump at the bottom goes back. Seven instructions run each iteration.

§3Calls and the Stack

A function call stores the return address and jumps. jal writes the address of the next instruction into ra and jumps to the target, and ret jumps back to ra. A function that calls another one must save its own ra first, since the nested call overwrites it. The stack is a region of memory used for this, growing toward lower addresses, with sp pointing at its top.

func:
    addi sp, sp, -16      # make room for 16 bytes of stack
    sw   ra, 12(sp)       # save the return address
    sw   s0, 8(sp)        # save a callee-saved register we will use
    # ... body, may call other functions ...
    lw   s0, 8(sp)        # restore
    lw   ra, 12(sp)
    addi sp, sp, 16       # release the stack space
    ret

The calling convention, which registers carry arguments and which a function must preserve, is what lets separately compiled code work together. It's also the mechanism behind stack frames from the OS course, and the reason an overflowing local buffer can overwrite a saved return address.

The key insight High-level constructs all reduce to a few patterns: loops are a compare and a branch, array access is a shift and an add, and function calls are save, jump, and restore.

§4Common Mistakes

Forgetting to save ra in a function that calls anotherThe function returns to the wrong placeSave and restore ra in non-leaf functions
Using a byte offset for an array index without scalingReading the wrong element, e.g. a[i] at offset i instead of 4iShift by log2(element size) before adding to the base

Practice
  1. Write RISC-V assembly for a function that finds the maximum of an int array.
  2. Hand-trace the sum loop for the array {3, 5, 7}, showing t0, t1, and the branch decisions at each iteration.
Key takeaways
  • Instructions fall into arithmetic, memory, branch, and jump/call families.
  • Array loops combine a compare-and-branch, a shifted index, a load, and an accumulate.
  • Calls save the return address, usually on the stack, and the convention says which registers must be preserved.
