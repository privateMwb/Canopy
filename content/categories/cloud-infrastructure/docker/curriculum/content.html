Checkpoints are deliberately unscaffolded. If you can finish one without hints, the stage actually landed, not just the following-along.

Levels aren't strict walls. Images appear at Junior as a Dockerfile, return at Intermediate as multi-stage builds and base-image choices, and come back at Senior as layers, provenance, and golden base images. Security follows the same arc: non-root users, then scanning, then the limits of a shared kernel. Revisiting a topic at a harder level is expected.

Senior is about judgment as much as mechanism. Knowing how namespaces and cgroups create isolation is one skill; deciding what a company's base images, runtime limits, and exceptions should be, and whether a single host is enough, is another, and the last stage is built around that gap.
