Installing Docker & Running Your First Container

Five commands cover the basic life of a container, from starting it to cleaning it up.

§1Installing

Install Docker Desktop (Mac, Windows) or Docker Engine (Linux), then verify.

docker --version
docker run hello-world          # pulls a tiny image and prints a message

§2Running Containers

docker run nginx                              # runs in the foreground, Ctrl-C to stop
docker run -d --name web -p 8080:80 nginx     # detached, named, host 8080 -> container 80
docker ps                                     # running containers
docker ps -a                                  # include stopped ones
docker logs web                               # output of the main process
docker logs -f --tail 50 web                  # follow the latest lines
docker stop web                               # graceful stop (SIGTERM, then SIGKILL)
docker start web                              # start it again
docker rm web                                 # delete the stopped container
docker rm -f web                              # stop and delete

Open http://localhost:8080 to see the page nginx serves.

§3Interactive Containers

docker run -it --rm ubuntu bash               # a shell in a throwaway container

-it attaches your terminal, and --rm deletes the container when it exits, which keeps your machine tidy.

§4A Container Lives as Long as Its Main Process

When the process ends, the container stops. If a container exits immediately, check docker logs and docker ps -a for the exit code.

The key insight docker run creates and starts a new container each time. To get an old one back, use docker start, not docker run.

§5Common Mistakes

MistakeWhat HappensFix
Running docker run again and expecting the same containerYou get a brand-new one each timeUse docker start name for an existing one
Forgetting -d and blocking your terminalThe container runs in the foregroundAdd -d, or open another terminal
Leaving stopped containers piled upDisk and name clutterUse --rm or run docker container prune
Practice
  1. Run nginx on port 8080, view it in your browser, read its logs, and remove it.
  2. Start an Ubuntu container with -it --rm, create a file, exit, and confirm the file is gone in a fresh one.
Key takeaways
  • run, ps, logs, stop, and rm cover everyday work.
  • -d, --name, -p, and --rm are the options you will use constantly.
  • A container stops when its main process exits.
