Data Sources

Not everything is yours to create. Data sources let a configuration read what already exists and build on it.

§1Reading, Not Creating

A data source is a data block that looks something up each time Terraform runs. It never creates or changes anything. Use one when infrastructure is owned elsewhere, such as an existing network, a machine image, or the current account.

data "aws_caller_identity" "current" {}

data "aws_availability_zones" "available" {
  state = "available"
}

output "account_id" {
  value = data.aws_caller_identity.current.account_id
}

You reference one as data.TYPE.NAME.attribute, and a resource block as TYPE.NAME.attribute. The data. prefix is the difference.

§2Looking Up an Existing Resource

Data sources accept filters, which keeps you from hard-coding IDs that differ per account or region.

data "aws_ami" "al2023" {
  most_recent = true
  owners      = ["amazon"]
  filter {
    name   = "name"
    values = ["al2023-ami-*-x86_64"]
  }
}

data "aws_vpc" "shared" {
  tags = { Name = "shared-network" }
}

data "aws_subnets" "shared" {
  filter {
    name   = "vpc-id"
    values = [data.aws_vpc.shared.id]
  }
}

resource "aws_instance" "web" {
  ami           = data.aws_ami.al2023.id
  instance_type = "t3.micro"
  subnet_id     = data.aws_subnets.shared.ids[0]
}

If a lookup matches nothing (or too many things), the plan fails with an error, which is usually what you want.

Data sources run at plan time Terraform reads them during plan, so their results can change between plans. most_recent = true on an image lookup means a new image can cause a replacement on your next apply. Pin the image, or add a lifecycle rule, if that matters.

§3Common Mistakes

MistakeWhat HappensFix
Hard-coding AMI or network IDsCode works in one region or account onlyLook them up with a data source and filters
Confusing data.x.y with x.y"Reference to undeclared resource" errorsRemember that data sources always carry the data. prefix
Using most_recent on production instancesSurprise replacement when a new image appearsPin the image or ignore changes to it deliberately
Practice
  1. Use aws_caller_identity and aws_region to build an output string like account-region.
  2. Look up an AMI with filters and print its ID. What happens if your filter matches nothing?
Key takeaways
  • Data sources read existing information; they never create or modify anything.
  • Reference them with the data. prefix.
  • Lookups happen at plan time, so results can change between runs.
