Built-In Functions & Type Conversions

Built-in functions replace repetition and manual conversion. You can try every one of them interactively before using it.

§1Trying Functions in the Console

terraform console opens a prompt where you can evaluate expressions against your configuration. It is the fastest way to learn a function.

$ terraform console
> upper("web")
"WEB"
> length(["a", "b", "c"])
3
> cidrsubnet("10.0.0.0/16", 8, 2)
"10.0.2.0/24"

Functions are grouped by purpose: string (format, join, split, replace), collection (length, merge, concat, lookup, keys, flatten), numeric, encoding (jsonencode, base64encode), filesystem (file, templatefile), and network (cidrsubnet).

§2Useful Everyday Patterns

locals {
  tags       = merge(var.base_tags, { Name = "web" })       # combine maps
  all_cidrs  = concat(var.office_cidrs, var.vpn_cidrs)      # join lists
  subnet     = cidrsubnet(var.vpc_cidr, 8, 1)               # carve a subnet
  policy     = jsonencode({ Version = "2012-10-17", Statement = [] })
  script     = templatefile("${path.module}/init.sh.tpl", { name = var.name })
  port       = try(var.settings.port, 8080)                 # fall back if missing
}

jsonencode is safer than writing JSON by hand inside a heredoc. try returns the first expression that does not error, which is handy for optional values.

§3Type Conversion

Terraform converts between compatible types automatically (the string "5" becomes the number 5), but when it cannot, use tostring, tonumber, tolist, toset, and tomap. toset also removes duplicates, which you will use heavily with for_each.

No user-defined functions Terraform has no way to write your own functions in HCL. If an expression grows hard to read, move it into a locals block with a descriptive name, split it, or put the logic in a module.

§4Common Mistakes

MistakeWhat HappensFix
Writing JSON policies as raw stringsQuoting errors and formatting driftUse jsonencode on an HCL object
Passing a list where a set is expectedType error from for_each or an argumentConvert with toset() or tolist()
Building complex expressions inlineUnreadable, hard to debugTest in terraform console and split into named locals
Practice
  1. In terraform console, compute four /24 subnets from 10.1.0.0/16 using cidrsubnet.
  2. Use merge to combine default tags with per-resource tags, where per-resource values win.
Key takeaways
  • terraform console is the best place to learn and debug functions.
  • jsonencode, merge, concat, cidrsubnet, and try cover a large share of real needs.
  • Convert types explicitly when automatic conversion is not enough.
