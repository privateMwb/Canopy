Interactive Rebase & Squashing

Interactive rebase lets you reorder, reword, combine, and drop commits so your branch tells a clear story before review.

§1Starting It

git rebase -i HEAD~5             # edit the last five commits
git rebase -i origin/main        # edit everything on this branch

Git opens a list, oldest first, with a command in front of each commit.

pick a1b2c3d Add login form
pick b2c3d4e Fix typo
pick c3d4e5f Add validation
pick d4e5f6a WIP
pick e5f6a7b Fix validation bug

§2Commands

  • pick: keep as is.
  • reword: keep the changes, edit the message.
  • squash: combine into the previous commit, merging messages.
  • fixup: combine into the previous commit, discarding this message.
  • drop: delete the commit.

Reorder lines to reorder commits. Save and close the editor to run it.

pick a1b2c3d Add login form
fixup b2c3d4e Fix typo
pick c3d4e5f Add validation
fixup e5f6a7b Fix validation bug
drop d4e5f6a WIP

§3Fixups Without Opening the Editor

git commit --fixup a1b2c3d       # mark a commit as a fix to an earlier one
git rebase -i --autosquash origin/main   # reorders and squashes automatically

§4Guard Rails

Do this only on unpublished commits. If it goes wrong, git rebase --abort returns you to the start, and the reflog (Lesson 4) can recover anything.

The key insight Commit freely while working, then clean up with interactive rebase. The history you share should read like a story, not a diary.

§5Common Mistakes

MistakeWhat HappensFix
Squashing everything into one commit by habitYou lose useful steps for debuggingSquash noise, keep meaningful separate commits
Rewriting commits others pulledDuplicate commits and conflictsOnly clean up before sharing
Deleting a line in the todo listThe commit is silently droppedUse drop deliberately and double-check
Practice
  1. Make six messy commits and use interactive rebase to leave three clear ones.
  2. Use --fixup and --autosquash to fold a late fix into the right commit.
Key takeaways
  • pick, reword, squash, fixup, and drop reshape history.
  • Use --fixup and --autosquash for quick corrections.
  • Clean up before sharing, never after.
