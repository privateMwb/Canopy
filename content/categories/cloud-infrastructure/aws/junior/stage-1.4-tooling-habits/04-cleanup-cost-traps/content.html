Cleanup & Cost Traps

Many surprise bills come from resources that are idle but still billed, so knowing the usual suspects and how to find them is a core habit.

§1The Usual Suspects

ResourceWhy it surprises
NAT gatewaysHourly charge plus per-GB, even if idle
Unattached EBS volumes and old snapshotsBilled per GB-month forever
Elastic IPs and public IPv4 addressesHourly charge, including when unused
Load balancers with no trafficHourly charge continues
Stopped instances' volumesCompute stops but storage is billed
Log groups without retentionGrowing storage
Forgotten RDS instances and snapshotsInstances bill continuously; snapshots outlive them

§2Finding Them

aws ec2 describe-volumes --filters Name=status,Values=available \
  --query 'Volumes[].[VolumeId,Size]'
aws ec2 describe-addresses \
  --query 'Addresses[?AssociationId==`null`].PublicIp'
aws ec2 describe-nat-gateways --filter Name=state,Values=available

Cost Explorer grouped by service and by usage type points quickly at what is growing. Trusted Advisor and Cost Optimization Hub also flag idle resources.

§3Cleaning Up Safely

  • Prefer deleting a CloudFormation stack to deleting resources one by one.
  • Snapshot or export anything you might need before deleting.
  • Check for dependencies: a VPC will not delete while it has network interfaces, endpoints, or gateways.
  • Leave a recovery window: stop first, then delete after a week of no complaints.
Delete by stack The cleanest cleanup is the one you can do in a single command. Resources created through one stack disappear together, with nothing orphaned.

§4Common Mistakes

MistakeWhat HappensFix
Deleting things without checking ownershipBreaking a teammate's systemCheck tags and ask the owner first
Forgetting a lab environment over the weekendSeveral days of unnecessary chargesTag with an expiry and schedule cleanup
Assuming 'stopped' means freeStorage and IPs still billTerminate, or delete volumes and release IPs
Practice
  1. Run the commands above in a test account and list what you find.
  2. Create a stack with a NAT gateway and note its cost per day before deleting the stack.
Key takeaways
  • Idle resources such as NAT gateways, volumes, and IPs keep billing.
  • Use Cost Explorer and CLI queries to hunt them down.
  • Delete through the stack that created them and check dependencies first.
