Network Security: WAF, Shield & Firewall Manager

Public endpoints need layered protection against web exploits and floods, and organizations need to enforce that protection consistently across accounts.

§1AWS WAF

AWS WAF inspects HTTP requests at CloudFront, ALB, API Gateway, and other endpoints. A web ACL holds rules that allow, block, count, or challenge requests.

  • Managed rule groups cover common attacks such as SQL injection, cross-site scripting, and known bad inputs.
  • Rate-based rules throttle abusive IPs.
  • Custom rules match headers, paths, geography, or IP sets.
  • Start new rules in Count mode, review logs, then switch to Block to avoid false positives.

§2AWS Shield

TierProtection
Shield StandardAutomatic protection against common network and transport layer DDoS attacks, at no extra charge
Shield AdvancedPaid tier: enhanced detection, DDoS response team access, cost protection for scaling during attacks, application-layer help with WAF

Architecture matters: CloudFront and Route 53 absorb large volumes at the edge, and hiding origins behind them reduces what attackers can hit directly.

§3Firewall Manager and Network Firewall

Firewall Manager applies WAF rules, security group policies, Shield Advanced, and Network Firewall rules across accounts in an organization, and flags non-compliant resources. AWS Network Firewall adds stateful inspection and filtering inside VPCs, such as egress domain allow-lists and intrusion prevention.

Layers: Route 53/CloudFront (edge) → Shield → WAF → ALB → security groups → app
Egress : private subnets → Network Firewall (domain allow-list) → NAT → internet
Protect the origin, not just the front door If attackers can reach your load balancer directly, edge protections are bypassed. Restrict the origin so only CloudFront can reach it.

§4Common Mistakes

MistakeWhat HappensFix
Enabling WAF rules directly in Block modeLegitimate traffic blockedCount first, analyze logs, then block
Exposing the origin directlyEdge protections bypassedRestrict origin access to CloudFront
Per-account manual WAF setupInconsistent coverageEnforce with Firewall Manager
Practice
  1. Attach a WAF web ACL in count mode to a test ALB and review matched rules.
  2. Design an egress filtering plan using Network Firewall for a private workload.
Key takeaways
  • WAF filters web requests; Shield mitigates DDoS; Firewall Manager enforces policy at scale.
  • Roll out rules in count mode first.
  • Keep origins reachable only through protective layers.
