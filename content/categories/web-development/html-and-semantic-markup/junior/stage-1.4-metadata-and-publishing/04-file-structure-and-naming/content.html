File Structure & Naming

A small, predictable folder layout and consistent file names keep a hand-built site easy to link, move, and maintain.

§1A Simple Layout

Group files by type, keep pages at the top, and let each section have its own folder with an index.html. A server returns index.html automatically for a folder URL, which gives clean links.

my-site/
├── index.html
├── about/
│   └── index.html
├── blog/
│   ├── index.html
│   └── pruning-tomatoes/
│       └── index.html
├── css/
│   └── site.css
├── img/
│   └── logo.svg
└── js/
    └── site.js

This layout gives you URLs such as /about/ and /blog/pruning-tomatoes/ without file extensions.

§2Naming Rules

  • Use lowercase letters, numbers, and hyphens: team-photo.jpg.
  • No spaces or special characters; spaces turn into %20 in URLs.
  • Be consistent about plural versus singular and about trailing slashes.
  • Prefer descriptive names (pricing-chart.svg) over img1.svg.

Many servers are case-sensitive: Logo.png and logo.png are different files in production even if your laptop treats them alike. Lowercase everywhere avoids this class of bug.

§3Linking Within the Site

Inside a growing site, root-relative links (/css/site.css) keep working wherever a page lives, while relative links (../css/site.css) depend on folder depth.

<link rel="stylesheet" href="/css/site.css">
<img src="/img/logo.svg" alt="Canopy">
<a href="/blog/">Blog</a>

Root-relative paths require the site to live at the domain root. If it is served from a subfolder, such as a GitHub Pages project site at /repo-name/, use relative paths or a <base> tag.

Test on a server Links with a leading / fail when you open a file directly with file://. Test with a local server so you see what production will do.

§4Common Mistakes

MistakeWhat HappensFix
Naming files with spaces or capitalsBroken links when deployed to a case-sensitive serverUse lowercase and hyphens
Putting everything in the root folderHard to find or reuse anythingGroup into css/, img/, and js/
Using root-relative links on a subfolder-hosted siteEverything 404sUse relative paths or set a base path
Practice
  1. Reorganize a messy folder of HTML files into the layout shown, updating all links.
  2. Rename three badly named assets and update the references to them.
Key takeaways
  • Folders with index.html give clean URLs.
  • Name files in lowercase with hyphens and no spaces.
  • Choose root-relative or relative links deliberately and test on a server.
