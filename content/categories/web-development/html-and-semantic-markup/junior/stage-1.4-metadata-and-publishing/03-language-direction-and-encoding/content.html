Language, Direction & Encoding

lang, dir, and UTF-8 are small declarations that decide whether text displays, reads, and is pronounced correctly in any language.

§1Declaring Language

Set lang on <html> with a BCP 47 tag such as en, fr, or pt-BR. Screen readers pick the right voice, browsers offer correct translation, and CSS can use :lang() for typographic rules.

<html lang="en">
  ...
  <p>The French call it <span lang="fr">le sous-sol</span>.</p>
  <blockquote lang="de">Ich bin ein Berliner.</blockquote>

Add lang on any inline element that switches language so a screen reader pronounces it correctly.

§2Text Direction

Arabic and Hebrew read right to left. Setting dir="rtl" flips text flow, punctuation placement, and logical layout. Use dir="auto" for user-generated text whose direction is unknown.

<html lang="ar" dir="rtl">

<p dir="auto">{{ user comment }}</p>

In CSS, prefer logical properties such as margin-inline-start over margin-left, so layouts adapt to either direction.

§3Encoding with UTF-8

A character encoding maps bytes to characters. UTF-8 covers every writing system and is the web's default. Declare it in the file *and* make sure the server's Content-Type agrees.

<meta charset="utf-8">

Content-Type: text/html; charset=utf-8

§4Common Mistakes

MistakeWhat HappensFix
Leaving off langScreen readers may read the page in the wrong accentAlways set lang on <html>
Using dir="rtl" but hard-coding margin-left in CSSLayout looks wrong in RTLUse logical properties
Saving files in a legacy encodingAccented characters corruptSave as UTF-8 and declare it
Practice
  1. Add a French phrase with its own lang to an English page and check it with a screen reader if you have one.
  2. Create a small page in Arabic or Hebrew with dir="rtl" and observe how the layout flips.
Key takeaways
  • lang on <html>, plus on inline switches of language.
  • Use dir for RTL languages and dir="auto" for unknown user text.
  • Use UTF-8 everywhere, declared in file and header.
