Social & Search Metadata

Open Graph and similar tags control the card shown when a link is shared; good descriptions and structured titles control what search results show.

§1Open Graph and Social Cards

When someone pastes your link into a chat or social app, the app fetches your page and reads og: tags to build a preview. Without them, it guesses, often badly.

<meta property="og:type" content="article">
<meta property="og:title" content="Pruning Tomatoes for Bigger Harvests">
<meta property="og:description" content="When and how to prune each type of tomato plant.">
<meta property="og:url" content="https://example.com/pruning-tomatoes/">
<meta property="og:image" content="https://example.com/img/pruning-1200x630.jpg">
<meta property="og:image:alt" content="Hands pruning a tomato plant">

<meta name="twitter:card" content="summary_large_image">

og:image should be an absolute URL, commonly around 1200×630 pixels. The twitter:card tag selects the layout on X; other fields fall back to the Open Graph values.

§2What Search Engines Use

Search engines read the visible content first. The <title> and meta description influence the snippet, and a clear <h1> and descriptive link text help them understand the page.

  • Match the <title> to what the page is actually about.
  • Write the description for a person deciding whether to click.
  • Use one <h1> and meaningful headings.
  • Add <meta name="robots" content="noindex"> to keep a page out of search results, such as a thank-you page.

Search engines may rewrite your description if they find a better excerpt, so don't treat it as guaranteed.

§3Test Before You Share

Social platforms cache previews, so a mistake can linger. Check your tags with a preview tool or the platform's debugger, and fix them before the first real share.

Share-ready means absolute URLs Crawlers fetch your tags out of context, so relative paths like /img/card.jpg often fail. Use full https:// URLs for og:image and og:url.

§4Common Mistakes

MistakeWhat HappensFix
Setting no og:imageLinks show up as plain text with no previewProvide a properly sized image with og:image:alt
Using a relative path for og:imageThe crawler can't resolve itUse an absolute https:// URL
Never rechecking after editsPlatforms keep serving the old cached cardUse the platform's debugger to refresh the cache
Practice
  1. Add Open Graph and Twitter card tags to one of your pages and preview the result.
  2. Write two meta descriptions for the same page, one vague and one specific, and compare which you'd click.
Key takeaways
  • og: tags decide how a shared link looks.
  • Use absolute URLs and a 1200×630-style image for cards.
  • Titles and descriptions are written for people, not for keyword lists.
