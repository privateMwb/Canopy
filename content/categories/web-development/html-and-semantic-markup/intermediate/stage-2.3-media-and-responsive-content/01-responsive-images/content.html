Responsive Images

srcset, sizes, and picture let the browser choose the right file for each screen, so phones don't download desktop-sized images.

§1Resolution Switching with srcset and sizes

Provide several widths of the same image and tell the browser how wide it will be displayed. The browser then picks the best candidate for the viewport and the device's pixel density.

<img
  src="hero-800.jpg"
  srcset="hero-400.jpg 400w,
          hero-800.jpg 800w,
          hero-1600.jpg 1600w"
  sizes="(min-width: 960px) 800px, 100vw"
  width="1600" height="900"
  alt="Mist rising over a forest canopy">

The w descriptor is the file's real pixel width. sizes describes the layout width the image will occupy: 800px on wide screens, full viewport width otherwise. It is evaluated before CSS loads, so it must describe your layout, not reference it.

§2Density Switching with x Descriptors

For fixed-size images, such as a logo that is always 120px wide, give 1x, 2x, and 3x versions.

<img src="logo-120.png"
     srcset="logo-120.png 1x, logo-240.png 2x, logo-360.png 3x"
     width="120" height="40" alt="Canopy">

Use either w descriptors with sizes, or x descriptors; don't mix them in one srcset.

§3Art Direction with picture

When you want a different crop or composition per breakpoint rather than just a different size, use <picture>. The browser takes the first <source> whose media matches, and falls back to the <img>.

<picture>
  <source media="(max-width: 600px)" srcset="hero-portrait-600.jpg">
  <source media="(max-width: 1100px)" srcset="hero-square-1000.jpg">
  <img src="hero-wide-1600.jpg" width="1600" height="700"
       alt="Mist rising over a forest canopy">
</picture>

The <img> is required: it carries alt, dimensions, and styling, and is the fallback. Attributes on <source> only supply candidates.

srcset suggests, the browser decides You are giving the browser options, not commands. It may choose a larger file on a high-density screen or a smaller one on a slow connection. Don't rely on a specific file being picked.

§4Common Mistakes

MistakeWhat HappensFix
Using srcset without sizes for fluid imagesThe browser assumes 100vw and over-downloadsDescribe the real layout width with sizes
Using picture just to serve smaller filesMore markup for no benefitUse srcset and sizes unless the crop must change
Forgetting alt and dimensions on the inner imgInaccessible and causes layout shiftPut both on the <img>
Practice
  1. Export three widths of a photo and write the img with srcset and sizes; verify the chosen file in the Network panel at different viewport widths.
  2. Create an art-directed picture with a tighter crop for phones.
Key takeaways
  • srcset with w descriptors plus sizes lets the browser pick by width and density.
  • picture with media is for changing the crop, not merely the size.
  • Always keep alt, width, and height on the img.
