Inline SVG & Icons

Inline SVG makes icons styleable and scriptable, but it needs accessible names or aria-hidden; choose the icon strategy that fits how many you have.

§1Inline SVG Basics

An <svg> element lives in your HTML. Its shapes inherit text color through currentColor, scale with CSS, and respond to hover and focus states.

<svg width="24" height="24" viewBox="0 0 24 24" fill="none"
     stroke="currentColor" stroke-width="2" aria-hidden="true">
  <path d="M5 12h14M13 6l6 6-6 6" />
</svg>

viewBox defines the internal coordinate system, so the icon scales cleanly, and width/height set its default displayed size.

§2Accessible Names for Icons

The accessibility depends on whether the icon is decorative or carries meaning.

<!-- decorative: text already says it -->
<button type="button">
  <svg aria-hidden="true" focusable="false" width="16" height="16">...</svg>
  Save
</button>

<!-- icon-only: the button needs a name -->
<button type="button" aria-label="Search">
  <svg aria-hidden="true" focusable="false" width="20" height="20">...</svg>
</button>

<!-- standalone informative graphic -->
<svg role="img" aria-labelledby="t1" viewBox="0 0 100 40">
  <title id="t1">Sales trend: up 12% this quarter</title>
  ...
</svg>

Name the button, not the icon, and hide the icon from the tree with aria-hidden="true".

§3Choosing an Icon Strategy

ApproachProsCons
Inline <svg>Styleable, no extra requestRepeats in HTML if used many times
<img src="icon.svg">Cached, simpleCan't be restyled with page CSS
SVG sprite with <use>Define once, reuse many timesNeeds a small setup
Icon fontFamiliarPoor accessibility and rendering; avoid
<svg width="20" height="20" aria-hidden="true">
  <use href="/img/sprite.svg#icon-search"></use>
</svg>
currentColor is the secret Setting stroke="currentColor" or fill="currentColor" makes an icon follow the surrounding text color, including hover, focus, and dark-mode changes, with no extra CSS.

§4Common Mistakes

MistakeWhat HappensFix
Leaving an icon-only button without a nameAnnounced just as "button"Add aria-label or visually hidden text
Forgetting viewBoxThe icon won't scale properlyAlways include viewBox
Using an icon font for meaningFails when fonts fail and reads as odd charactersUse SVG with proper names
Practice
  1. Make a toolbar of three icon-only buttons with accessible names and visible focus styles.
  2. Convert repeated inline icons into a sprite that uses <use>.
Key takeaways
  • Inline SVG inherits color with currentColor and scales through viewBox.
  • Hide decorative icons with aria-hidden and name the control instead.
  • Pick inline, <img>, or sprite based on reuse and styling needs.
