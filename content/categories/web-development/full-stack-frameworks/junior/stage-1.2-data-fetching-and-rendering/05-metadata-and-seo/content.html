Metadata & SEO

Titles, Open Graph, sitemaps, and robots.

§1Why Metadata Is Part of the Framework

Search engines and social platforms read your page's <head>: the title, description, canonical URL, and Open Graph tags. The App Router lets you declare these as typed objects instead of hand-writing tags, and it merges them down the layout tree.

§2Static and Dynamic Metadata

// Static: app/layout.tsx
export const metadata = {
  title: { default: "Acme", template: "%s | Acme" },
  description: "Tools for busy teams.",
};

// Dynamic: app/blog/[slug]/page.tsx
export async function generateMetadata({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  const post = await getPost(slug);
  return {
    title: post.title,
    description: post.summary,
    openGraph: { title: post.title, images: [post.coverUrl] },
    alternates: { canonical: `/blog/${slug}` },
  };
}

The title.template in the root layout adds your site name to every child title, so a page that sets title: "Pricing" becomes Pricing | Acme.

§3Sitemaps and robots

Special files generate the crawler-facing documents for you. Export a function from app/sitemap.ts and app/robots.ts and the framework serves /sitemap.xml and /robots.txt.

// app/sitemap.ts
export default async function sitemap() {
  const posts = await getAllPosts();
  return posts.map((p) => ({
    url: `https://acme.com/blog/${p.slug}`,
    lastModified: p.updatedAt,
  }));
}
SEO starts with rendering Metadata only helps if crawlers can see your content. Server-rendered or static HTML gives them real text immediately, which is a quiet advantage of full-stack frameworks over client-only apps.

§4Common Mistakes

MistakeWhat HappensFix
Identical titles and descriptions on every pageWeak search results and poor link previewsUse generateMetadata to make them page-specific
Relative image URLs in Open Graph tagsSocial platforms fail to load the preview imageUse absolute URLs, or set metadataBase
Forgetting a canonical URL on filtered or duplicated pagesSearch engines split ranking across URL variantsSet alternates.canonical to the preferred URL
Practice
  1. Give a blog route dynamic metadata that includes an Open Graph image, and inspect the rendered <head>.
  2. Generate a sitemap that lists every post, then open /sitemap.xml in the browser to check it.
Key takeaways
  • Declare metadata as objects or functions, and let the framework merge and render the tags.
  • Use generateMetadata for per-page titles, descriptions, and Open Graph data.
  • sitemap.ts and robots.ts generate crawler files from code.
