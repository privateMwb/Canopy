Text Size, Spacing & Zoom

People change text size, zoom the page, and adjust spacing to read comfortably. Your layout needs to bend instead of break when they do.

§1Resize Text and Reflow

Two criteria govern zoom. 1.4.4 Resize Text (AA) says text can be resized up to 200% without loss of content or function. 1.4.10 Reflow (AA) says content must work at a width equivalent to 320 CSS pixels (a 400% zoom on a 1280-pixel window) without scrolling in two dimensions.

This is simply responsive design in practice. If your layout adapts to a narrow phone screen, a zoomed desktop window behaves the same way. Exceptions exist for content that truly needs two-dimensional layout, such as data tables, maps, and diagrams.

<!-- Bad: blocks pinch and browser zoom -->
<meta name="viewport" content="width=device-width, user-scalable=no, maximum-scale=1">

<!-- Good -->
<meta name="viewport" content="width=device-width, initial-scale=1">

Never disable zoom. It is one of the most common and most harmful failures on mobile.

§2Use Relative Units

Sizes set in pixels ignore the user's preferred text size. Relative units such as rem and em scale with the browser setting, so people who raised their default font size get what they asked for.

html { font-size: 100%; }         /* respect the user's default */
body { font-size: 1rem; line-height: 1.5; }
h1   { font-size: 2rem; }

.container { max-width: 70ch; padding-inline: 1rem; }

/* Avoid fixed heights that clip text when it grows */
.card { min-height: 8rem; }       /* not height: 120px */

§3Text Spacing

1.4.12 Text Spacing (AA) says a page must keep working when users override spacing with their own stylesheet or extension, using these values:

  • Line height of at least 1.5 times the font size.
  • Spacing after paragraphs of at least 2 times the font size.
  • Letter spacing of at least 0.12 times the font size.
  • Word spacing of at least 0.16 times the font size.

This is a test of robustness: nothing should be clipped, overlap, or disappear. The usual culprits are fixed-height containers, text inside fixed-size buttons, and overflow: hidden.

/* Test: paste this into DevTools to simulate the override */
* {
  line-height: 1.5 !important;
  letter-spacing: 0.12em !important;
  word-spacing: 0.16em !important;
}
p { margin-bottom: 2em !important; }
How to test Zoom the browser to 200%, then 400%. Look for horizontal scrolling, overlapping text, and clipped content. Then raise the browser's default font size and check again.

§4Common Mistakes

MistakeWhat HappensFix
Disabling zoom with user-scalable=noLow-vision users cannot enlarge the pageRemove it, and never set maximum-scale=1
Fixed pixel font sizes and heightsText ignores user settings and clips when enlargedUse rem and em, and min-height instead of height
Horizontal scrolling at 400% zoomReaders must scroll in two directions for every lineUse a responsive layout that reflows at 320 CSS pixels
Practice
  1. Zoom a site you maintain to 400%. Record every place content is cut off or forces horizontal scrolling.
  2. Apply the text-spacing override above in DevTools to a page and fix one component that clips or overlaps.
Key takeaways
  • Text must resize to 200% and reflow at 320 CSS pixels without two-dimensional scrolling.
  • Use rem and em, and never disable zoom in the viewport meta tag.
  • Layouts must survive larger line, paragraph, letter, and word spacing without clipping.
