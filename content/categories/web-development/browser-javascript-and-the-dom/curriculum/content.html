From changing a page with a script to engineering for the browser runtime

Three levels, twelve stages — the DOM, events, and the Web APIs the browser provides, built toward interactive apps that are fast, resilient, and secure. The language itself lives in the JavaScript subject; this one is about the browser around it.

Checkpoints are deliberately unscaffolded. If you can finish one without hints, the stage actually landed, not just the following-along.

Levels aren't strict walls. Asynchronous work arrives at Junior as fetch and promises, returns at Intermediate as the event loop, cancellation, and workers, and comes back at Senior as long tasks, scheduling, and real-user responsiveness. Revisiting a topic at a harder level is expected.

Senior is about judgment as much as mechanism. Knowing how the browser schedules and renders is one skill; deciding what a framework earns you over the platform, and writing that down, is another, and the last stage is built around that gap.
