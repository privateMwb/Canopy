Clipboard, Files & Drag-and-Drop

Browsers can read files the user chooses, receive them from a drag-and-drop, and move text and images through the clipboard. Each of these requires a user gesture and some care with permissions and memory.

§1Reading Files

A file input (or a drop) gives you File objects, which are special Blobs with a name, size, type, and modified date. The File is only a reference; read its contents with the Blob methods or FileReader.

<input type="file" id="picker" accept="image/*,.csv" multiple>

picker.addEventListener("change", async () => {
  for (const file of picker.files) {
    console.log(file.name, file.size, file.type);

    if (file.type.startsWith("image/")) {
      const url = URL.createObjectURL(file);      // cheap preview URL
      preview.src = url;
      preview.onload = () => URL.revokeObjectURL(url);   // free the memory
    } else {
      const text = await file.text();             // also arrayBuffer(), stream()
      console.log(text.split("\n").length, "lines");
    }
  }
});

Prefer URL.createObjectURL for previews over reading the whole file into a base64 string, and always check file.size and file.type before processing. Remember the accept attribute is only a hint: validate again in script and, ultimately, on the server.

§2Drag and Drop

To accept dropped files, listen for dragover and drop on your drop zone. You must call preventDefault() in dragover, or the browser will not treat the element as a valid target, and also in drop, or the browser will navigate to the dropped file.

const zone = document.querySelector("#drop");

zone.addEventListener("dragenter", () => zone.classList.add("over"));
zone.addEventListener("dragleave", () => zone.classList.remove("over"));
zone.addEventListener("dragover", (e) => e.preventDefault());   // required
zone.addEventListener("drop", (e) => {
  e.preventDefault();                                           // do not open the file
  zone.classList.remove("over");
  handleFiles([...e.dataTransfer.files]);
});

// dragging elements within a page
card.draggable = true;
card.addEventListener("dragstart", (e) => e.dataTransfer.setData("text/plain", card.id));

The native drag-and-drop API is awkward for reordering lists and has poor touch support. For complex in-page dragging, pointer events (from the earlier lesson) or a library give you more control. Always provide a keyboard alternative, such as a normal file button next to the drop zone.

§3The Clipboard

The asynchronous Clipboard API (navigator.clipboard) reads and writes text and images. It needs a secure context (HTTPS), and reading requires a user gesture and often a permission prompt, while writing from a click is generally allowed.

copyBtn.addEventListener("click", async () => {
  try {
    await navigator.clipboard.writeText(codeBlock.textContent);
    copyBtn.textContent = "Copied!";
  } catch (err) {
    copyBtn.textContent = "Copy failed";      // permission denied or insecure context
  }
});

// reading (user gesture + permission)
const text = await navigator.clipboard.readText();

// react to the user's own copy/paste
document.addEventListener("paste", (e) => {
  const file = [...e.clipboardData.files].find((f) => f.type.startsWith("image/"));
  if (file) attachImage(file);
});

The paste event is the friendliest way to accept pasted images or text, because the user's paste action is the gesture and permission. Never silently read the clipboard: users do not expect it, and browsers will block it.

User gestures are the permission model File pickers, drops, and pastes hand you data because the user just did something deliberate. Design around those events rather than trying to read files or the clipboard on your own.

§4Common Mistakes

MistakeWhat HappensFix
Not calling preventDefault() in dragoverThe drop event never firesCancel dragover and drop
Reading images into base64 for previewsLarge memory use and slow UIUse URL.createObjectURL, then revokeObjectURL
Trusting accept or file.typeUsers can pick or rename anythingValidate size and type, and re-check on the server
Calling clipboard.readText() outside a gestureRejected promise or permission errorUse the paste event or a click handler
Practice
  1. Build a drop zone that previews dropped images and shows each file's name and size.
  2. Add a copy-to-clipboard button to code blocks with success and failure feedback.
  3. Accept pasted screenshots with the paste event and display them.
Key takeaways
  • File objects come from inputs, drops, or paste; read them with text(), arrayBuffer(), or object URLs.
  • Drop zones must cancel dragover and drop; always offer a keyboard-accessible alternative.
  • The Clipboard API needs HTTPS and user gestures; the paste event is the easy path for input.
