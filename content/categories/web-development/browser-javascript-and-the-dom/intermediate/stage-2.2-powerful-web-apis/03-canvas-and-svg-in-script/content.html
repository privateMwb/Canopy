Canvas & SVG in Script

Canvas and SVG both draw graphics from script, but they work in opposite ways. Knowing which to choose, and the basics of each, covers most charts, games, and visualizations.

§1Canvas: Pixels You Paint

<canvas> is a bitmap. You get a 2D drawing context, issue drawing commands, and the result is pixels. The browser remembers nothing about what you drew, so to change something you clear and redraw.

<canvas id="c" width="400" height="200"></canvas>

const canvas = document.querySelector("#c");
const ctx = canvas.getContext("2d");

ctx.fillStyle = "#15803D";
ctx.fillRect(20, 20, 120, 60);

ctx.strokeStyle = "#1C1F26";
ctx.lineWidth = 2;
ctx.beginPath();
ctx.moveTo(20, 150);
ctx.lineTo(200, 100);
ctx.lineTo(380, 150);
ctx.stroke();

ctx.font = "16px Inter, sans-serif";
ctx.fillText("Hello", 20, 190);

On high-density screens a canvas looks blurry unless you scale its backing store. Set canvas.width/height to the CSS size times devicePixelRatio, set the CSS size separately, and scale the context once. For animation, clear and redraw on each requestAnimationFrame.

const dpr = window.devicePixelRatio || 1;
canvas.style.width = "400px";  canvas.style.height = "200px";
canvas.width = 400 * dpr;      canvas.height = 200 * dpr;
ctx.scale(dpr, dpr);           // now draw in CSS pixels

§2SVG: Elements You Manipulate

SVG is retained mode: each shape is a real element in the DOM, so it can be styled with CSS, targeted by events, and changed by setting attributes. It stays sharp at any zoom. You create SVG elements with createElementNS and the SVG namespace.

const NS = "http://www.w3.org/2000/svg";
const svg = document.createElementNS(NS, "svg");
svg.setAttribute("viewBox", "0 0 400 200");

function bar(x, h) {
  const r = document.createElementNS(NS, "rect");
  r.setAttribute("x", x);
  r.setAttribute("y", 200 - h);
  r.setAttribute("width", 30);
  r.setAttribute("height", h);
  r.addEventListener("pointerenter", () => r.classList.add("hot"));
  return r;
}
[40, 90, 60, 130].forEach((h, i) => svg.append(bar(20 + i * 50, h)));
document.body.append(svg);

Setting viewBox makes the drawing scale to whatever size the <svg> is given in CSS, which is how you get responsive graphics without scripting. Each shape being a DOM node also means accessibility is possible: add role, <title>, and aria-label so that screen readers can describe it.

§3Choosing Between Them

QuestionCanvasSVG
How many objects?Thousands to millionsUp to a few thousand
Interactivity per shapeYou hit-test manuallyNative events and CSS :hover
Scales without blurOnly if you redrawAlways
AccessibilityNeeds a separate text alternativeShapes can carry labels and titles
Typical usesGames, image editing, heatmaps, particlesCharts, icons, diagrams, maps

A bar chart with twenty bars is a natural fit for SVG; a particle simulation with fifty thousand moving dots needs canvas. Libraries such as D3 (SVG-centric) and Chart.js (canvas) build on these two primitives.

Retained vs. immediate SVG keeps a scene graph for you (and pays for it per element). Canvas keeps nothing (and is fast for huge drawings). Pick based on how many things you draw and how much per-thing interaction you need.

§4Common Mistakes

MistakeWhat HappensFix
Sizing a canvas only with CSSStretched, blurry outputSet width/height attributes and handle devicePixelRatio
Creating SVG elements with createElementThey do not renderUse createElementNS with the SVG namespace
Forgetting to clear the canvas between framesTrails of old drawingsctx.clearRect(0, 0, w, h) each frame
Drawing 50,000 SVG nodesDOM becomes slow and heavySwitch to canvas
Practice
  1. Draw a bar chart from an array of numbers twice: once with canvas, once with SVG, and compare the code.
  2. Animate a bouncing ball on canvas with requestAnimationFrame and time-based movement.
  3. Make the SVG chart bars highlight on hover with CSS only, then add <title> elements for accessibility.
Key takeaways
  • Canvas is an immediate-mode bitmap; SVG is a DOM of shapes you can style and listen to.
  • Handle devicePixelRatio on canvas and use viewBox and createElementNS for SVG.
  • Choose by scale and interactivity: many objects favor canvas, accessible and interactive graphics favor SVG.
