Web Fonts Done Right

Custom fonts add personality and cost. Done carelessly they delay text or make it jump, and done well they are almost free.

§1What Fonts Cost

A web font is another file the browser must download, and it is often discovered late, only after the CSS that references it has loaded and been matched to text on the page. While it loads, the browser has to decide what to show.

BehaviorWhat the user sees
FOIT (flash of invisible text)Blank space where text should be
FOUT (flash of unstyled text)Fallback font first, then a swap
Swap with a different sizeText reflows, causing layout shift

Invisible text is the worst outcome, since content the user came for isn't readable. A brief swap is usually acceptable, especially if you minimize the size difference.

§2font-display and Preloading

font-display controls what happens while the font loads.

@font-face {
  font-family: 'Brand';
  src: url('/fonts/brand-latin.woff2') format('woff2');
  font-display: swap;       /* show fallback text immediately, swap when ready */
  font-weight: 400;
}
  • swap shows fallback text at once and swaps when the font arrives. A safe default.
  • optional uses the font only if it is already available or loads very quickly; otherwise the fallback stays. It avoids shift entirely.
  • block hides text for a short period, which risks invisible text. Avoid it for body copy.

To start the download early, preload the one or two fonts used above the fold. Fonts need crossorigin even when same-origin.

<link rel="preload" href="/fonts/brand-latin.woff2" as="font" type="font/woff2" crossorigin>

§3Making Fonts Small

  • Use WOFF2. It is the compressed format supported by all modern browsers.
  • Subset the font to the characters you need, such as Latin only. A full multilingual font can be many times larger than a Latin subset.
  • Limit weights and styles. Each is a separate file unless you use a variable font, which packs a range of weights into one.
  • Tune the fallback. size-adjust and related descriptors make the fallback match the web font's metrics, shrinking the visible jump.
  • Consider system fonts for body text. They cost nothing.
@font-face {
  font-family: 'Brand Fallback';
  src: local('Arial');
  size-adjust: 105%;          /* tune until text barely moves on swap */
  ascent-override: 92%;
}
body { font-family: 'Brand', 'Brand Fallback', sans-serif; }
The key insight Fonts are on the critical path of text. Preload the few that matter, subset aggressively, and pick a font-display value that never leaves the page blank.

§4Common Mistakes

MistakeWhat HappensFix
Loading eight weights of a familyMany requests and a heavy pageUse two or three weights, or a variable font
Omitting crossorigin on a font preloadThe preload is wasted and the font downloads twiceAlways add crossorigin for fonts
Using font-display: block for body textText is invisible while the font loadsUse swap or optional
Practice
  1. Throttle the network and reload a page with custom fonts. Note whether you see invisible text or a swap.
  2. Subset a font to Latin characters with a tool such as pyftsubset and compare the file size to the original.
Key takeaways
  • Fonts are discovered late, so preload the critical ones with crossorigin.
  • Use WOFF2, subset the glyphs, and limit weights, or use a variable font.
  • Set font-display so text is never invisible, and tune the fallback to reduce the swap jump.
