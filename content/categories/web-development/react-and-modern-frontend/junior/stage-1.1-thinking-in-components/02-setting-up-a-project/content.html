Setting Up a Project

Vite gives you a working React project in under a minute: a dev server with instant updates, and a build that produces files you can deploy. Knowing what each file does makes the rest of the course less mysterious.

§1Creating a Project

You need Node.js (a current LTS version) and a terminal. Vite scaffolds a project from a template; pick react (JavaScript) for now, and react-ts once you meet TypeScript later in the path.

npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev          # http://localhost:5173

npm run dev starts a development server. When you save a file, the browser updates in milliseconds, usually without losing your component's state. This is called hot module replacement (HMR). Leave the server running while you work.

CommandWhat it does
npm run devDev server with hot reload
npm run buildOptimized production files in dist/
npm run previewServe the built files locally to check them
npm run lintRun ESLint (if the template includes it)

§2The File Layout

my-app/
  index.html        // the single HTML page; has <div id="root"></div>
  package.json      // dependencies and scripts
  vite.config.js    // build tool settings
  public/           // files served as-is (favicon, robots.txt)
  src/
    main.jsx        // entry point: mounts React into #root
    App.jsx         // your first component
    App.css
    assets/

index.html is nearly empty. It has a <div id="root"> and a script tag pointing at src/main.jsx. React fills that div with your app, which is why this style is called a single-page application.

// src/main.jsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App.jsx";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>
);

createRoot attaches React to the #root element and render draws your top-level <App /> component into it. StrictMode is a development helper that runs some checks twice to expose bugs early. It does nothing in production, so do not be alarmed when you see double logs in development.

§3Your First Edit

Open src/App.jsx, delete the template content, and write the smallest possible component. Components are functions whose names start with a capital letter, and export default makes them importable.

// src/App.jsx
export default function App() {
  return <h1>Hello, React</h1>;
}

Save the file and watch the browser update. Then change the text again. This tight feedback loop is the main reason to use a modern dev server.

  • File extensions: use .jsx (or .tsx) for files containing JSX, since Vite needs to know to transform them.
  • Import with the extension for your own files (./App.jsx) and without it for packages (react).
  • Images and CSS can be imported directly: import "./App.css" and import logo from "./logo.svg".
  • Commit package.json and the lockfile, never the node_modules/ folder.

Other starters exist: Create React App is deprecated, and frameworks like Next.js and React Router's framework mode provide a full application setup. Vite is the simplest way to learn React itself, with no framework decisions in the way.

If something breaks Read the error in the terminal and the browser console. Vite shows the file and line of syntax errors in an overlay. Most first-day problems are a typo in an import path or a lowercase component name.

Practice
  1. Create a new Vite React project, start the dev server, and change the heading in App.jsx.
  2. Run npm run build and look inside dist/. Note the file names and sizes.
  3. Add a second component in its own file, import it into App.jsx, and render it twice.
Key takeaways
  • npm create vite@latest gives you a React project with a fast dev server and HMR.
  • main.jsx mounts the app into #root; App.jsx is your top-level component.
  • Components are capitalized functions that return JSX; use .jsx files.
