Checkpoints are deliberately unscaffolded. If you can finish one without hints, the stage actually landed, not just the following-along.

Levels aren't strict walls. Layout arrives at Junior as the box model and Flexbox, returns at Intermediate as Grid and container-aware components, and comes back at Senior as how the browser computes and paints it all. Revisiting a topic at a harder level is expected.

Senior is about judgment as much as mechanism. Knowing how a layout algorithm resolves sizes is one skill; deciding how a 50,000-line stylesheet should be organized, and making that case to a team, is another, and the last stage is built around that gap.
