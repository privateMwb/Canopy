Naming & Organization

A consistent naming convention and file organization keep a stylesheet understandable as it grows, and BEM is the most widely used convention.

§1Why Conventions Exist

CSS is global: every class name lives in one shared namespace. Without a convention, names collide, selectors become tangled with the HTML structure, and nobody dares to delete anything.

  • Names should say what something is, not how it looks (.alert, not .red-box).
  • Selectors should have low, predictable specificity.
  • A component's styles should be changeable without touching other components.

§2BEM: Block, Element, Modifier

BEM names three kinds of things. A block is a standalone component, an element is a part of it, and a modifier is a variation.

<article class="card card--featured">
  <img class="card__image" src="..." alt="">
  <h2 class="card__title">Pruning tomatoes</h2>
  <a class="card__link" href="#">Read more</a>
</article>

.card            { border: 1px solid var(--line); }
.card--featured  { border-color: var(--accent); }
.card__title     { font-size: 1.25rem; }
.card__link      { text-decoration: none; }

Every selector is a single class, so specificity stays flat. Elements are named block__element even when nested deeper in the DOM; BEM doesn't mirror the HTML hierarchy.

§3Organizing Files

Group by purpose, and keep each component's styles together.

styles/
├── main.css            /* declares @layer order and imports the rest */
├── base/               /* reset, typography, tokens */
├── layout/             /* page frame, grid helpers */
├── components/         /* card.css, button.css, nav.css */
└── utilities/          /* small single-purpose classes */

Other conventions exist, such as SMACSS, ITCSS, and utility-first (next lesson). The best convention is the one your whole team applies consistently and can enforce with a linter.

Name by meaning, not by looks .btn--primary survives a redesign. .btn--green becomes a lie the day the brand color changes.

§4Common Mistakes

MistakeWhat HappensFix
Naming classes after appearance (.big-red-text)Names become wrong after a redesignName by role or meaning
Chaining selectors to mimic HTML (.card .list .item span)Fragile, high specificityGive the target its own BEM class
Mixing conventions in one codebaseNo one knows what to expectChoose one and enforce it
Practice
  1. Rename the classes of one component to BEM and flatten its selectors.
  2. Reorganize a single large stylesheet into base, layout, and component files.
Key takeaways
  • Pick one naming convention and apply it consistently.
  • BEM keeps selectors flat with block, element, and modifier classes.
  • Name by meaning and organize by purpose.
