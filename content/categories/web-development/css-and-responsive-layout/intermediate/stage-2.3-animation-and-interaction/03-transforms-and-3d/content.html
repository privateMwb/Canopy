Transforms & 3D

transform moves, scales, and rotates an element without changing layout, and perspective adds depth.

§12D Transforms

Transforms change how an element is drawn, not where it sits in the layout, so neighbors don't move. Combine functions in one declaration; they apply right to left.

.icon { transform: translate(10px, -4px); }
.zoom { transform: scale(1.1); }
.tilt { transform: rotate(-3deg); }
.combo { transform: translateX(8px) rotate(5deg) scale(1.05); }

/* individual properties (modern browsers) */
.card { translate: 0 -4px; rotate: 2deg; scale: 1.02; }

The individual translate, rotate, and scale properties let you animate one aspect without rewriting the whole transform list.

§2Transform Origin

Transforms happen around the origin, which is the center by default.

.menu { transform-origin: top left; transform: scale(.95); }
.hinge { transform-origin: left center; transform: rotate(-10deg); }

Setting the origin at the point where an element grows from, such as a dropdown's top edge, makes the motion feel connected to its trigger.

§33D and Perspective

Add perspective on a parent to give children depth, then rotate them on the X or Y axis.

.scene { perspective: 800px; }
.card {
  transform-style: preserve-3d;
  transition: transform .6s;
}
.card:hover { transform: rotateY(180deg); }
.card .face { backface-visibility: hidden; }

Smaller perspective values create a stronger effect. Remember: 3D tricks can hurt readability and may trigger motion sensitivity, so keep them subtle and respect prefers-reduced-motion.

Transforms don't affect layout A scaled-up element still occupies its original space and may overlap neighbors. That's the reason they are cheap to animate, and also the reason they can cause overlap.

§4Common Mistakes

MistakeWhat HappensFix
Using margin or top to move an element during animationTriggers layout every frameUse transform: translate()
Expecting a transformed element to push neighborsNeighbors don't movePlan the space, or use layout properties
Rotating text and leaving it hard to readAccessibility and legibility sufferKeep rotation small or for decorative items
Practice
  1. Build a card that lifts with translateY and scales slightly on hover and focus.
  2. Create a two-sided flip card with perspective, preserve-3d, and backface-visibility.
Key takeaways
  • Transforms change drawing, not layout.
  • Set transform-origin where the motion should start.
  • perspective and preserve-3d create depth; use them sparingly.
