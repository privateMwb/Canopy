Keyframe Animations

@keyframes describes a sequence of states, and the animation properties decide how long, how often, and what happens before and after it runs.

§1Defining and Applying

Keyframes name the steps; animation applies them to an element.

@keyframes pulse {
  0%   { transform: scale(1);    opacity: 1; }
  50%  { transform: scale(1.08); opacity: .8; }
  100% { transform: scale(1);    opacity: 1; }
}

.badge {
  animation: pulse 1.5s ease-in-out infinite;
}

from and to are shorthands for 0% and 100%. If you omit a start or end keyframe, the browser uses the element's current value.

§2The animation Properties

PropertyPurposeExample
animation-durationLength of one cycle1.5s
animation-timing-functionEasing between keyframesease-out
animation-delayWait before starting; negative values start partway in.2s
animation-iteration-countHow many times3, infinite
animation-directionForward, reverse, or alternatingalternate
animation-fill-modeWhether styles apply before and afterboth
animation-play-statePause and resumepaused

animation-fill-mode: forwards keeps the final keyframe after the animation ends, and backwards applies the first keyframe during a delay. both does both.

§3Orchestrating Sequences

Stagger items with a custom property and a delay, so each one starts slightly after the previous.

@keyframes rise {
  from { opacity: 0; transform: translateY(12px); }
  to   { opacity: 1; transform: none; }
}
.list > li {
  animation: rise .4s ease-out both;
  animation-delay: calc(var(--i) * 60ms);
}
/* <li style="--i: 0">, <li style="--i: 1">, ... */

Use animations for things that run on their own: loaders, attention cues, and entrance sequences. For responses to a state change, a transition is simpler.

Animation is not decoration for its own sake Motion should explain a change, draw attention to something important, or give feedback. Endless looping motion distracts and can cause problems for some users.

§4Common Mistakes

MistakeWhat HappensFix
Forgetting animation-fill-modeThe element snaps back to its original state at the endUse forwards or both
Infinite animations on important contentDistracting, and hard for some users to readLimit loops, or provide a pause and honor reduced motion
Animating many elements at once with expensive propertiesDropped framesAnimate transform and opacity only
Practice
  1. Create a staggered entrance animation for a list using a custom property delay.
  2. Make a loader with an infinite animation, then add a way to pause it.
Key takeaways
  • @keyframes defines the steps and animation applies them.
  • fill-mode, direction, and iteration-count control behavior before, during, and after.
  • Use transitions for state changes and animations for self-running motion.
