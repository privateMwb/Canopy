Grid Fundamentals

Grid lays out items in rows and columns at the same time, and the fr unit and gap make most layouts a few lines long.

§1Defining Tracks

display: grid makes a grid container. grid-template-columns and grid-template-rows define the tracks (columns and rows), and the lines between them are numbered starting at 1.

.layout {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;   /* fixed, then two flexible */
  grid-template-rows: auto 1fr auto;
  gap: 1rem;                              /* row-gap and column-gap */
}

Children are placed automatically, left to right and top to bottom, into the next free cell. You don't have to place each one.

§2The fr Unit and repeat()

1fr is one share of the leftover space after fixed tracks and gaps are subtracted. repeat() avoids typing the same track many times.

.cols-3   { grid-template-columns: repeat(3, 1fr); }
.sidebar  { grid-template-columns: 16rem 1fr; }
.mixed    { grid-template-columns: 1fr 2fr 1fr; }   /* middle gets twice the share */
.content  { grid-template-columns: minmax(0, 1fr) 20rem; }

Use minmax(0, 1fr) instead of plain 1fr for tracks that may contain long content: 1fr has a minimum of auto, so wide content can blow the column open, just like min-width: auto in Flexbox.

§3Implicit Tracks and Sizing

If there are more items than defined cells, Grid creates implicit rows. Control their size with grid-auto-rows.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 10rem;     /* every extra row is 10rem tall */
  gap: .5rem;
}
Track sizeMeaning
200px, 20rem, 30%Fixed or percentage
1frA share of the free space
autoFits content, and stretches to fill leftover space
min-content / max-contentNarrowest or widest the content wants to be
minmax(a, b)At least a, at most b
Gap is spacing, not margin Use gap between tracks. It applies only between cells, never at the outer edges, and it never collapses.

§4Common Mistakes

MistakeWhat HappensFix
Applying display: grid to the itemsNothing forms a gridPut it on the parent container
Using plain 1fr for tracks with long unbreakable contentThe column grows past its shareUse minmax(0, 1fr)
Counting lines from 0Off-by-one placementGrid lines start at 1
Practice
  1. Build a three-column layout with a fixed 16rem sidebar, and two flexible columns, plus a gap.
  2. Make a gallery with grid-auto-rows and add more items than the template has cells.
Key takeaways
  • grid-template-columns and rows define tracks; items auto-place into cells.
  • fr shares leftover space; repeat() and minmax() keep definitions short and safe.
  • Use gap for spacing and grid-auto-rows for implicit rows.
