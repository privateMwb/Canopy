Grid vs. Flexbox

Flexbox arranges items along one axis and lets content drive size; Grid defines a layout in two dimensions, and the best pages use both.

§1One Dimension vs. Two

The short rule: Flexbox for rows or columns of things; Grid for layouts of rows and columns. Flexbox distributes space along one axis and then wraps lines independently. Grid aligns items to shared tracks in both directions.

FlexboxGrid
DimensionOne at a timeTwo at once
Sizing driven byContent (items push the layout)Layout (tracks define the layout)
Alignment across rowsNo; each line is independentYes; items share track lines
Best forNavbars, toolbars, button groups, centering, small componentsPage layouts, card grids, dashboards, forms
OverlapAwkwardEasy: place items in the same cell

§2A Decision Test

  1. Do I care about alignment across rows *and* columns? → Grid.
  2. Is it a single row or column of items that should wrap naturally? → Flexbox.
  3. Do I know the layout shape and want content to fit it? → Grid.
  4. Do I want the content to decide how much room each item takes? → Flexbox.
  5. Is it a whole page frame? → Grid, with Flexbox inside the components.

If you reach for Flexbox with wrapping and then try to make columns line up across the wrapped lines, switch to Grid.

§3Using Both Together

They are not rivals. A typical page uses Grid for the frame and Flexbox inside each piece.

.page   { display: grid; grid-template-columns: 14rem 1fr; gap: 2rem; }
.toolbar { display: flex; justify-content: space-between; align-items: center; }
.cards  { display: grid; grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr)); gap: 1rem; }
.card   { display: flex; flex-direction: column; }
.card .actions { margin-top: auto; }   /* pins buttons to the card bottom */

Any grid item can itself be a flex container, and any flex item can be a grid container.

Not a competition Choose per component. A single page often has a Grid frame, Grid card lists, Flexbox toolbars, and Flexbox card internals.

§4Common Mistakes

MistakeWhat HappensFix
Using Flexbox for a two-dimensional page layout and fighting widthsColumns don't align and percentages need hacksUse Grid for the layout
Using Grid for a simple horizontal group of buttonsMore code than neededUse Flexbox
Forcing one tool to do everythingVerbose, brittle CSSCombine them where each is strongest
Practice
  1. Take one page and label each region as Grid or Flexbox, and write one sentence on why.
  2. Rebuild a wrapped Flexbox card layout using Grid and compare the alignment of the last row.
Key takeaways
  • Flexbox is one-dimensional and content-driven; Grid is two-dimensional and layout-driven.
  • Use Grid for page and card layouts, and Flexbox for components and groups.
  • Nest them freely.
