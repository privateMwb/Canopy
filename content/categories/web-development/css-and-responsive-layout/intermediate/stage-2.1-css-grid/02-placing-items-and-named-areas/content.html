Placing Items & Named Areas

When auto-placement isn't enough, place items by line numbers and spans, or draw the layout with named areas.

§1Line-Based Placement

Each item can say which lines it starts and ends at, using grid-column and grid-row.

.hero    { grid-column: 1 / -1; }          /* from first line to last line: full width */
.feature { grid-column: 2 / 4; }           /* lines 2 to 4: two columns */
.tall    { grid-row: 1 / span 2; }         /* start at 1, span 2 rows */
.wide    { grid-column: span 2; }          /* span 2 from wherever it lands */

Negative numbers count from the end, so -1 is the last line of the explicit grid, which makes 1 / -1 a reliable way to span everything.

§2Named Template Areas

grid-template-areas lets you draw the layout as text. Each string is a row; repeating a name makes the area span those cells; a . is an empty cell.

.page {
  display: grid;
  grid-template-columns: 14rem 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100dvh;
}
.page > header  { grid-area: header; }
.page > aside   { grid-area: sidebar; }
.page > main    { grid-area: main; }
.page > footer  { grid-area: footer; }

Named areas must form rectangles. Reshaping the layout for narrow screens is then just a new grid-template-areas inside a media query.

§3Rearranging at Breakpoints

.page {
  grid-template-columns: 1fr;
  grid-template-areas: "header" "main" "sidebar" "footer";
}
@media (min-width: 48em) {
  .page {
    grid-template-columns: 14rem 1fr;
    grid-template-areas:
      "header  header"
      "sidebar main"
      "footer  footer";
  }
}

As with Flexbox, changing where things appear does not change the keyboard or reading order, which follows the HTML. Keep the source order meaningful.

Draw it, then name it For page-level layouts, grid-template-areas is the most readable option. For components with many repeated items, auto-placement with spans is usually simpler.

§4Common Mistakes

MistakeWhat HappensFix
Making a non-rectangular area in grid-template-areasThe whole declaration is invalidEach named area must be a rectangle
Using grid-column: 1 / -1 on an implicit grid-1 refers to the explicit grid's end onlyDefine explicit columns, or use grid-column: 1 / span N
Reordering visually in ways that break reading orderConfusing tab and screen reader orderKeep DOM order logical
Practice
  1. Build the classic header, sidebar, main, and footer layout with grid-template-areas.
  2. Rearrange that layout into a single column on phones using only a different grid-template-areas.
Key takeaways
  • Place items with line numbers, span, and -1.
  • grid-template-areas makes page layouts readable and easy to rearrange.
  • Visual reordering must not break the logical source order.
