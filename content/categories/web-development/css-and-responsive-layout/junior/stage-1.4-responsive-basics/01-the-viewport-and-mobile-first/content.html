The Viewport & Mobile-First

Without the viewport meta tag, phones pretend to be desktops; with it, you can design small-screen first and add complexity as space grows.

§1The Viewport Meta Tag

Mobile browsers historically render pages at about 980px wide and then shrink them to fit. The viewport meta tag turns that off so your CSS pixels match the device's width.

<meta name="viewport" content="width=device-width, initial-scale=1">

Don't add user-scalable=no or maximum-scale=1; they block pinch-to-zoom, which many people rely on.

§2Mobile-First Thinking

Write your base CSS for the smallest screen, a single comfortable column, and then add rules as the screen gets wider. Small screens force you to decide what matters most, and the base styles are the simplest and fastest.

/* base: phones */
.layout { display: grid; gap: 1rem; }
.nav    { display: flex; flex-direction: column; }

/* wider screens add, rather than undo */
@media (min-width: 48em) {
  .layout { grid-template-columns: 1fr 2fr; }
  .nav    { flex-direction: row; }
}

Compare this with desktop-first, where you write the complex layout and then use max-width queries to strip it back down for phones. That tends to need more overrides.

§3Design for Content, Touch, and Conditions

  • Touch targets — aim for at least 44px by 44px (WCAG recommends a minimum of 24px) with spacing around them.
  • Readable text — don't shrink body text below about 16px.
  • Slow networks — mobile-first also means lean assets and fewer blocking resources.
  • Orientation — layouts should survive both portrait and landscape.
  • Input methods — hover doesn't exist on touch, so don't hide essential content behind it.

You'll test these properly in the last lesson of this stage.

Base styles should work alone If the media queries all failed to load, the page should still be a usable single column. That is a mobile-first page.

§4Common Mistakes

MistakeWhat HappensFix
Omitting the viewport meta tagPhones show a tiny zoomed-out desktop pageAdd width=device-width, initial-scale=1
Disabling zoomBlocks users who need to enlarge textNever set user-scalable=no
Hiding key content on small screensMobile users miss functionalityReorganize it rather than removing it
Practice
  1. Take a desktop-only page, add the viewport tag, and compare it on a phone or in device emulation.
  2. Rewrite a max-width query based stylesheet as mobile-first with min-width queries.
Key takeaways
  • The viewport meta tag makes CSS pixels match the device width.
  • Write the single-column base first and add rules at wider widths.
  • Make touch targets large and text readable by default.
