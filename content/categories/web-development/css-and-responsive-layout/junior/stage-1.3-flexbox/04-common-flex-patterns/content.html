Common Flex Patterns

A handful of Flexbox recipes cover most real pages: the navbar, a wrapping card row, a sticky footer, and the media object.

§1Navbar

.nav {
  display: flex;
  align-items: center;
  gap: 1rem;
  padding: .75rem 1rem;
}
.nav .logo   { margin-right: auto; }   /* pushes the rest to the right */
.nav a       { padding: .5rem .75rem; }

margin-left: auto or margin-right: auto on a flex item absorbs all the free space on that side, which is a neat way to split a group in two.

§2Wrapping Card Row

.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 1.5rem;
}
.card {
  flex: 1 1 16rem;     /* at least ~16rem, then share the space */
  max-width: 24rem;
}

Cards wrap to a new line as space runs out, with no media query. The last row may have fewer cards, which Grid handles more tidily; you'll see that in the Intermediate level.

§3Sticky Footer

Keep the footer at the bottom of the viewport even when the page content is short.

body {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
  margin: 0;
}
main { flex: 1; }   /* grows to fill the space between header and footer */

Using 100dvh instead of 100vh accounts for mobile browser toolbars in browsers that support it.

§4Media Object

An image beside a block of text, a pattern behind comments, notifications, and list items.

.media { display: flex; gap: 1rem; align-items: flex-start; }
.media img { flex: none; width: 3rem; height: 3rem; border-radius: 50%; }
.media .body { flex: 1; min-width: 0; }

flex: none stops the image from shrinking, and min-width: 0 lets long text wrap rather than push the layout wider; see the next lesson.

Auto margins are powerful In a flex container, margin: auto on an item consumes free space before justify-content runs. Use it for "push this one away from the others" without extra wrappers.

§5Common Mistakes

MistakeWhat HappensFix
Building page layout with fixed widths on flex itemsBreaks on small screensUse flex-basis, min(), and wrapping
Forgetting flex: none on an avatar or iconIt shrinks into an ovalSet flex: none or flex-shrink: 0
Using height: 100vh for the sticky footer bodyContent taller than the viewport overflowsUse min-height
Practice
  1. Build a navbar with the logo at the left, links in the middle, and a button at the far right.
  2. Create a comment list with an avatar and text using the media object, with long text and a missing avatar.
Key takeaways
  • Auto margins split flex groups; flex: 1 on main makes a sticky footer.
  • flex: 1 1 <size> with wrap gives responsive card rows.
  • Protect avatars and icons with flex: none.
