Flex Items: Grow, Shrink & Basis

flex-grow, flex-shrink, and flex-basis decide how items claim, give up, and start with space along the main axis.

§1The Three Properties

PropertyQuestion it answersDefault
flex-basisHow big is the item before free space is distributed?auto (use width, or content size)
flex-growIf there is spare space, what share does it get?0 (don't grow)
flex-shrinkIf there isn't enough space, how much should it shrink?1 (shrink)

Free space is positive when the items are smaller than the container, and negative when they're larger. Grow handles the first and shrink handles the second.

§2The flex Shorthand

.item { flex: 1; }          /* grow 1, shrink 1, basis 0 — equal shares */
.item { flex: 0 0 200px; }  /* fixed 200px: no grow, no shrink */
.item { flex: 1 1 auto; }   /* grow and shrink from content size */
.item { flex: none; }       /* 0 0 auto: rigid */

flex: 1 on every item gives equal widths regardless of content, because the basis is 0. flex: 1 1 auto starts from the content size, so larger content stays larger.

§3Growing in Proportion

Grow values are ratios of the leftover space, not of the total width.

.sidebar { flex: 0 0 16rem; }   /* fixed */
.content { flex: 1; }           /* takes all the rest */

.a { flex: 1; }
.b { flex: 2; }   /* gets twice the free space of .a */

A common layout is a fixed sidebar with a flexible main area. Using flex-basis with a min and max is also a robust way to build rows that wrap.

.card { flex: 1 1 18rem; max-width: 30rem; }   /* wraps as space runs out */
flex: 1 is not a width flex: 1 means "share the leftover space equally". If items hold different content, remember that padding and borders are added outside the basis unless you use border-box.

§4Common Mistakes

MistakeWhat HappensFix
Expecting flex: 1 to produce equal widths with flex-basis: autoContent size affects the resultUse flex: 1 1 0 for equal shares
Setting both width and flex-basisflex-basis wins, so width seems ignoredChoose one; prefer flex-basis in flex layouts
Using flex: 0 0 33% with gapsItems overflow by the gap sizeUse calc() or let flex-grow absorb the gaps
Practice
  1. Build a layout with a 16rem sidebar and a main area that fills the rest, then narrow the window.
  2. Make three cards in a row where one grows twice as much as the others.
Key takeaways
  • Basis sets the starting size, grow shares spare space, and shrink absorbs a shortage.
  • flex: 1 gives equal shares; flex: none makes an item rigid.
  • Prefer flex-basis over width in a flex row.
