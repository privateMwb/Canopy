Backgrounds, Borders & Shadows

Backgrounds, borders, radius, and shadows give surfaces shape and depth, and layering several of them produces most modern card and button looks.

§1Backgrounds and Gradients

background is a shorthand for color, image, position, size, and repeat. Gradients are generated images, so they go in background-image, and you can stack several, with the first on top.

.hero {
  background-color: #0f766e;
  background-image: linear-gradient(135deg, #0f766e, #34d399);
  background-size: cover;
}

.photo {
  background: url("/img/forest.jpg") center / cover no-repeat;
}

.glow {
  background:
    radial-gradient(circle at 20% 20%, rgb(255 255 255 / .25), transparent 40%),
    linear-gradient(#0f766e, #064e3b);
}

Always set a background-color underneath an image or gradient as a fallback, and to guarantee text contrast if the image fails to load.

§2Borders and Radius

.btn {
  border: 1px solid #15803d;
  border-radius: 8px;       /* each corner */
}
.avatar { border-radius: 50%; }       /* circle on a square element */
.pill   { border-radius: 999px; }     /* fully rounded ends */
.tab    { border-bottom: 3px solid currentColor; }

Use outline for focus rings: it doesn't affect layout, and outline-offset can pull it away from the edge. Never remove an outline without replacing it.

§3Shadows

box-shadow takes offset-x, offset-y, blur, spread, and color. Subtle, layered shadows look more natural than one heavy one.

.card {
  box-shadow:
    0 1px 2px rgb(0 0 0 / .08),
    0 8px 24px rgb(0 0 0 / .08);
}
.card:focus-within { box-shadow: 0 0 0 3px rgb(21 128 61 / .4); }   /* ring effect */

Shadows follow the box and its border-radius. For shaped content like a transparent PNG, filter: drop-shadow() follows the visible outline instead.

Subtle beats heavy Low-opacity, multi-layer shadows and soft borders read as depth. A single dark, sharp shadow looks dated and draws attention to itself.

§4Common Mistakes

MistakeWhat HappensFix
Using a background image with no background-colorUnreadable text while it loadsAdd a matching color underneath
Removing outline for looksKeyboard users lose their placeReplace it with a visible custom focus style
Large blur shadows on many elementsCostly to paint on low-end devicesKeep them modest and few
Practice
  1. Create a card with a gradient header, a rounded border, and a layered shadow.
  2. Add a visible, custom :focus-visible outline to buttons and links.
Key takeaways
  • Use gradients as background images, with a color fallback.
  • border-radius shapes boxes; outline is for focus rings.
  • Layer low-opacity shadows for natural depth.
