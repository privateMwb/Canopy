Margin Collapsing & Spacing

Adjacent vertical margins combine into one, which surprises almost everyone; a consistent spacing strategy sidesteps the problem.

§1What Margin Collapsing Is

When two block-level boxes' vertical margins touch, they collapse into a single margin equal to the larger one, not the sum. A margin-bottom: 30px followed by a margin-top: 20px gives 30px, not 50px.

h2 { margin-bottom: 30px; }
p  { margin-top: 20px; }
/* gap between them: 30px */

Margins can also collapse through a parent and its first or last child, and through an empty block. Horizontal margins never collapse.

§2When Margins Do Not Collapse

  • Between flex or grid items.
  • When there is padding, a border, or a gap between them (for a parent and child).
  • On elements with overflow other than visible, or that establish a new formatting context such as display: flow-root.
  • On floated or absolutely positioned elements.
.container { display: flow-root; }   /* stops child margins from collapsing through the parent */

§3Spacing Strategies That Avoid Surprises

Pick one direction and stay consistent. Two good habits are an owner-controlled gap and a lobotomized owl selector.

/* 1. Only set margin-top: the parent owns the space between children */
.stack > * + * { margin-top: 1rem; }

/* 2. Use gap in flex and grid; it never collapses */
.cards { display: flex; flex-direction: column; gap: 1rem; }

/* 3. Keep spacing values on a scale */
:root { --space-1: .25rem; --space-2: .5rem; --space-3: 1rem; --space-4: 2rem; }

Components should not set their own outer margin. Let the layout that contains them decide the spacing, so the same component works anywhere.

Use gap when you can gap in Flexbox and Grid applies space only *between* items, never collapses, and needs no first-child or last-child exceptions.

§4Common Mistakes

MistakeWhat HappensFix
Adding margins on both sides of every elementSpacing doubles or collapses unpredictablyChoose one direction, or use gap
Expecting margin-top on the first child to push inside the parentIt collapses through and moves the parentUse padding on the parent, or display: flow-root
Using random spacing numbersInconsistent rhythmUse a small scale of spacing tokens
Practice
  1. Reproduce margin collapsing between a heading and a paragraph, then fix it with a stack rule.
  2. Build a vertical list of cards spaced with gap and compare to the margin approach.
Key takeaways
  • Adjacent vertical margins collapse to the larger one.
  • Flex and grid containers, and flow-root, stop collapsing.
  • Use one spacing direction or gap, from a defined scale.
