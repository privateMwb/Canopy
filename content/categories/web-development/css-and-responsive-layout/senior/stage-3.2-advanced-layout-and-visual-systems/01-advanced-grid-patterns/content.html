Advanced Grid Patterns

Overlap, intrinsic sizing, and a few named patterns turn Grid from a column tool into a layout language for editorial pages and dashboards.

§1Overlap and Layering

Unlike Flexbox, Grid lets several items occupy the same cells, which replaces many position: absolute hacks.

.hero { display: grid; }
.hero > * { grid-area: 1 / 1; }          /* everything in one cell */
.hero img { width: 100%; height: 100%; object-fit: cover; }
.hero .caption { align-self: end; padding: 1.5rem; z-index: 1; }

Because both items remain in flow, the cell grows to fit the larger one, and no height needs to be hard-coded.

§2Full-Bleed Layouts and the Content Track

A classic pattern gives content a comfortable column while letting some elements span edge to edge.

.article {
  display: grid;
  grid-template-columns:
    [full-start] minmax(1rem, 1fr)
    [content-start] minmax(0, 65ch) [content-end]
    minmax(1rem, 1fr) [full-end];
}
.article > * { grid-column: content; }
.article > .full-bleed { grid-column: full; }

Named lines (content-start, content-end) create implicit named areas called content and full, so you can write grid-column: full. Adding more tracks gives "wide" breakouts too.

§3Intrinsic, Dashboard, and Holy-Grail Patterns

/* sidebar that collapses on its own: no media query */
.with-sidebar { display: grid; grid-template-columns: repeat(auto-fit, minmax(min(100%, 18rem), 1fr)); }

/* dashboard tiles with different spans */
.dash { display: grid; grid-template-columns: repeat(12, 1fr); gap: 1rem; grid-auto-flow: dense; }
.tile-a { grid-column: span 8; }
.tile-b { grid-column: span 4; }
.tile-c { grid-column: span 6; }

/* sticky sidebar inside a grid */
.sidebar { position: sticky; top: 1rem; align-self: start; }

align-self: start is essential for sticky grid items: the default stretch makes the item as tall as its cell, leaving nothing to stick against.

Layout from the content out The strongest Grid layouts combine intrinsic sizing (auto-fit, minmax, fit-content) with a few named lines. The result needs few media queries and survives unexpected content.

§4Common Mistakes

MistakeWhat HappensFix
Stretching a sticky grid itemIt is as tall as the row, so there's no room to stickAdd align-self: start
Using absolute positioning to overlap itemsParent height collapses and content overflowsPlace items in the same grid cell
Fixing every track with px widthsNo adaptation to content or screenUse minmax() and flexible tracks
Practice
  1. Build a hero with an image and an overlapping caption using only Grid placement.
  2. Create an article layout with a readable content column, a wide breakout, and a full-bleed image.
Key takeaways
  • Grid items can overlap in the same cell without taking out of flow.
  • Named lines make full-bleed layouts readable.
  • Sticky grid items need align-self: start.
