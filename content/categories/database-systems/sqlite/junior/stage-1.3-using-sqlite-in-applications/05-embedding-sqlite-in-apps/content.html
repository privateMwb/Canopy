Embedding SQLite in Apps

SQLite is often embedded in a mobile, desktop, or command-line program, and where you keep the file decides how well it behaves.

§1Where the File Lives

Store it in the platform's per-user application data directory, not next to the program and not in a temp folder.

macOS     ~/Library/Application Support/MyApp/app.db
Windows   %APPDATA%\MyApp\app.db
Linux     ~/.local/share/myapp/app.db
iOS/Android  the app's private storage directory

Create the directory if it is missing, and set restrictive permissions if the data is private.

§2Keep the Right Things Together

The database file may have -wal and -shm files next to it in WAL mode, so keep them in the same directory and never copy only the main file while the app is running.

§3Common Uses

  • Mobile apps: local storage, caches, and offline data, with a sync layer if needed.
  • Desktop apps: documents, settings, and history.
  • CLI tools: a queryable store for a tool's state, such as a task list or an index.
  • Servers: a single-machine service with modest write rates.

§4Opening Safely

con = sqlite3.connect(path, timeout=5)        # wait up to 5 seconds on a lock
con.execute("PRAGMA foreign_keys = ON")
con.execute("PRAGMA journal_mode = WAL")
migrate(con)

Run migrations on startup before the rest of the app uses the database.

The key insight The database file is user data. Treat its location, permissions, and upgrade path as carefully as you would a document.

§5Common Mistakes

MistakeWhat HappensFix
Writing the database next to the executableThe directory may be read-only or replaced on updateUse the app data directory
Leaving out -wal files when copyingA backup is missing recent commitsUse a proper backup method
Not creating the directory firstThe first run crashesCreate it with correct permissions
Practice
  1. Write a function that finds the right data directory on your operating system and opens a database there with migrations applied.
  2. List which files appear next to the database in WAL mode and describe what happens if one is deleted.
Key takeaways
  • Keep the file in the platform's app data directory with suitable permissions.
  • WAL mode adds sidecar files that must stay with the database.
  • Run migrations on startup, and enable foreign keys on each connection.
