Import & Export

SQLite can read and write CSV and SQL text, which makes it a convenient staging area for moving data between systems.

§1CSV Import and Export

.mode csv
.import --skip 1 products.csv product      -- load into an existing table, skipping the header
.headers on
.mode csv
.once report.csv
SELECT * FROM product;                       -- writes the result to report.csv

If the table does not exist, .import creates it using the header row as column names, with all columns as text. Create the table first when you need proper types.

§2SQL Dumps

.output dump.sql
.dump                                  -- the whole database as SQL statements
.output stdout
.read dump.sql                         -- load it into another database
sqlite3 app.db .dump | sqlite3 copy.db
sqlite3 app.db ".dump product" > product.sql     -- one table

A dump is portable text, useful for version control and moving to other engines, though other databases may need syntax adjustments.

§3Other Formats

.mode json
SELECT * FROM product;
.mode markdown
sqlite3 -json app.db "SELECT * FROM product" > product.json

§4Cleaning During Import

Import into a staging table, then use SQL to clean and insert into the final table.

INSERT INTO product (name, price_cents)
SELECT trim(name), CAST(round(price * 100) AS INTEGER) FROM staging WHERE price IS NOT NULL;
The key insight Load first, transform with SQL second. It is easier to fix data you can query.

§5Common Mistakes

MistakeWhat HappensFix
Importing into a table created from the headerEvery column is textCreate the typed table before .import
Forgetting --skip 1The header row becomes dataSkip it or use an auto-created table
Assuming a dump loads cleanly into another engineTypes and syntax differTest and adjust, or use CSV
Practice
  1. Export a table to CSV and import it into a new database with a typed schema.
  2. Dump a database, edit one row in the SQL file, and restore it into a new file.
Key takeaways
  • .import loads CSV, and .once or .output writes results to files.
  • .dump produces a portable SQL text representation.
  • Import into a staging table and clean the data with SQL.
