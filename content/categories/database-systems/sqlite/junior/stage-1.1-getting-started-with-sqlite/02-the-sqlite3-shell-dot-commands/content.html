The sqlite3 Shell & Dot Commands

The sqlite3 shell lets you run SQL and a set of dot commands that inspect and configure the database.

§1Opening a Database

sqlite3 shop.db         # opens or creates the file
sqlite3                 # an in-memory database that disappears on exit
sqlite3 shop.db "SELECT count(*) FROM orders;"    # run one statement and exit

SQL statements end with a semicolon. Dot commands do not, and they are only understood by the shell, not by SQLite itself.

§2Dot Commands

.help                    -- list all dot commands
.tables                  -- list tables
.schema orders           -- show the CREATE statement for a table
.headers on              -- show column names
.mode column             -- align output; also csv, json, box, table
.read setup.sql          -- run a file of statements
.open other.db           -- switch databases
.quit

.mode and .headers change how results are displayed, which makes exploring much easier.

§3Handy Settings

Put your preferred settings in ~/.sqliterc so they apply every time.

.headers on
.mode box
.timer on                -- print how long each query took

§4Looking at What Exists

SELECT name, type FROM sqlite_schema;     -- tables, indexes, views, triggers
.dbinfo                                   -- page size, encoding, and other file details
The key insight sqlite_schema is an ordinary table that stores the definition of every object in the database, which is how .tables and .schema work.

§5Common Mistakes

MistakeWhat HappensFix
Adding a semicolon after a dot commandThe shell may show an error or ignore itDot commands end at the end of the line
Forgetting the statement terminator on SQLThe shell waits with a continuation promptEnd SQL with a semicolon
Working in an unnamed in-memory database by accidentEverything disappears when the shell closesPass a file name when you want data to persist
Practice
  1. Open a new database, create a table, and use .tables, .schema, and .mode box to inspect it.
  2. Put .headers on and .mode column in ~/.sqliterc and confirm they take effect.
Key takeaways
  • The shell runs SQL statements and dot commands that begin with a period.
  • .tables, .schema, .headers, .mode, and .read cover most daily use.
  • sqlite_schema stores the definition of every object in the database.
