Full-Text Search with FTS5

FTS5 is SQLite's built-in full-text search engine, giving ranked word and phrase search from a specialized virtual table.

§1Creating a Search Index

CREATE VIRTUAL TABLE doc_fts USING fts5(title, body, tokenize = 'porter unicode61');
INSERT INTO doc_fts (title, body) VALUES ('Intro', 'SQLite is a small, fast database');

SELECT title FROM doc_fts WHERE doc_fts MATCH 'database';
SELECT title FROM doc_fts WHERE doc_fts MATCH 'title:intro AND fast';
SELECT title FROM doc_fts WHERE doc_fts MATCH '"small fast"' ;      -- phrase
SELECT title FROM doc_fts WHERE doc_fts MATCH 'data*';              -- prefix

The porter tokenizer stems words, so a search for running also finds run.

§2Ranking and Highlighting

SELECT title, bm25(doc_fts) AS score, snippet(doc_fts, 1, '<b>', '</b>', '…', 12) AS excerpt
FROM doc_fts WHERE doc_fts MATCH 'database' ORDER BY score;

bm25 returns a score where lower is better, so order ascending.

§3Keeping It in Sync With Real Tables

An external content table stores the index without duplicating the text. Triggers keep it up to date.

CREATE VIRTUAL TABLE note_fts USING fts5(body, content = 'note', content_rowid = 'id');
CREATE TRIGGER note_ai AFTER INSERT ON note BEGIN
  INSERT INTO note_fts (rowid, body) VALUES (new.id, new.body);
END;
CREATE TRIGGER note_ad AFTER DELETE ON note BEGIN
  INSERT INTO note_fts (note_fts, rowid, body) VALUES ('delete', old.id, old.body);
END;
CREATE TRIGGER note_au AFTER UPDATE ON note BEGIN
  INSERT INTO note_fts (note_fts, rowid, body) VALUES ('delete', old.id, old.body);
  INSERT INTO note_fts (rowid, body) VALUES (new.id, new.body);
END;

§4Maintenance

INSERT INTO note_fts (note_fts) VALUES ('rebuild');       -- rebuild from the content table
INSERT INTO note_fts (note_fts) VALUES ('optimize');      -- merge segments
The key insight The search index is a derived structure. Keep it synchronized with triggers, and know how to rebuild it.

§5Common Mistakes

MistakeWhat HappensFix
Using LIKE '%word%' for searchFull scans and no rankingUse an FTS5 table
Forgetting the delete and update triggers on external contentThe index returns stale or ghost resultsAdd all three triggers
Sorting bm25 descendingWorst matches come firstOrder ascending
Practice
  1. Index 10,000 notes with FTS5 and compare the speed and results with a LIKE query.
  2. Add triggers so edits to a note update the index, then test an update and a delete.
Key takeaways
  • FTS5 virtual tables support MATCH, phrases, prefixes, and bm25 ranking.
  • External content tables with triggers avoid duplicating text.
  • Lower bm25 scores are better matches.
