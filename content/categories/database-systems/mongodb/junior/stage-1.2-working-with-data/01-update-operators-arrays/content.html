Update Operators & Arrays

Update operators change specific fields in place, and a handful of array operators let you add, remove, and edit list items without rewriting the document.

§1Field Operators

An update document is a map from operator to fields. Each operator touches only the fields it names, and everything else stays as it was.

db.products.updateOne({ sku: "NB-1" }, {
  $set:   { price: 4.75, "dims.width": 21 },   // set or add fields
  $inc:   { stock: -1, sold: 1 },              // add to a number (atomic)
  $unset: { legacyCode: "" },                  // remove a field
  $rename: { desc: "description" },
  $currentDate: { updatedAt: true },
  $min:   { lowestPrice: 4.25 },               // set only if smaller
  $max:   { highScore: 99 }                    // set only if larger
})

$inc is atomic: two clients decrementing stock at the same time both take effect. Doing the same with a read, an arithmetic step in code, and a write can lose one of them.

§2Array Operators

db.users.updateOne({ _id: 1 }, { $push: { tags: "vip" } })              // append
db.users.updateOne({ _id: 1 }, { $addToSet: { tags: "vip" } })          // append only if absent
db.users.updateOne({ _id: 1 }, { $pull: { tags: "trial" } })            // remove matching values
db.users.updateOne({ _id: 1 }, { $pop: { tags: 1 } })                   // remove last (-1 for first)
db.users.updateOne({ _id: 1 }, {
  $push: { recent: { $each: ["a", "b"], $slice: -10 } }                 // keep only the last 10
})

$push with $slice is the standard way to keep a bounded "most recent N" array.

§3Updating Elements Inside Arrays

The positional operators reach into array elements.

// order: { items: [ { sku: "NB-1", qty: 2 }, { sku: "PN-3", qty: 1 } ] }
db.orders.updateOne({ _id: 7, "items.sku": "PN-3" }, { $set: { "items.$.qty": 5 } })     // first match
db.orders.updateOne({ _id: 7 }, { $inc: { "items.$[].qty": 1 } })                        // every element
db.orders.updateOne({ _id: 7 }, { $set: { "items.$[i].qty": 0 } }, { arrayFilters: [{ "i.sku": "NB-1" }] })
The key insight Prefer targeted operators over reading a document, editing it in code, and saving it back. Operators are atomic and need no extra round trip.

§4Common Mistakes

MistakeWhat HappensFix
Using $push for a set of unique valuesDuplicates pile upUse $addToSet
$ positional operator without the array in the filterError, or the wrong element is updatedInclude the array field in the query, or use arrayFilters
Read-modify-write in application codeConcurrent updates overwrite each otherUse $inc, $push, and friends
Practice
  1. Give each user a loginCount and a recentLogins array capped at five entries, then update both in one updateOne.
  2. For an order with several items, double the quantity of only the items whose sku starts with NB.
Key takeaways
  • Operators such as $set, $inc, and $unset change only the fields they name, atomically.
  • $push, $addToSet, $pull, and $slice manage arrays without rewriting them.
  • Positional operators and arrayFilters update specific elements inside an array.
