Querying Nested Documents & Arrays

Dot notation reaches into nested documents, and array queries have specific rules that surprise people until they learn them.

§1Dot Notation

To match a field inside an embedded document, use a dotted path in quotes.

// { name: "Ada", address: { city: "London", zip: "N1" } }
db.users.find({ "address.city": "London" })          // matches
db.users.find({ address: { city: "London" } })       // does NOT match: exact subdocument required

Matching a whole subdocument requires every field, in the same order. For nearly all queries, dot notation is what you want.

§2Querying Arrays

A query on an array field matches if any element satisfies it.

// { title: "Dune", tags: ["scifi", "classic"], ratings: [4, 5, 3] }
db.books.find({ tags: "scifi" })                     // array contains "scifi"
db.books.find({ tags: ["scifi", "classic"] })        // exact array, same order
db.books.find({ tags: { $all: ["classic", "scifi"] } })   // contains both, any order
db.books.find({ tags: { $size: 2 } })                // exactly two elements
db.books.find({ "tags.0": "scifi" })                 // by position

§3The Array Trap and $elemMatch

When an array holds subdocuments, conditions on separate fields may be satisfied by different elements.

// { _id: 1, items: [ { sku: "A", qty: 1 }, { sku: "B", qty: 9 } ] }
db.orders.find({ "items.sku": "A", "items.qty": { $gt: 5 } })
// matches _id 1! "A" came from element 0, qty 9 from element 1

db.orders.find({ items: { $elemMatch: { sku: "A", qty: { $gt: 5 } } } })
// no match: one element must satisfy both conditions

Likewise { ratings: { $gt: 3, $lt: 5 } } can match [2, 6], because one element passes $gt and another passes $lt. Use $elemMatch when all conditions must hold for the same element.

The key insight When you query several fields of an array of subdocuments, ask yourself whether they must come from the same element. If yes, use $elemMatch.

§4Common Mistakes

MistakeWhat HappensFix
{ address: { city: "London" } } for a nested matchNo match, because the subdocument must be identicalUse "address.city"
Two conditions on items.* without $elemMatchFalse matches from different elementsWrap the conditions in $elemMatch
Forgetting that dotted paths need quotesSyntax errorWrite "a.b" in quotes
Practice
  1. Create orders with item arrays and write the query for "orders containing an item with sku A and qty above 5", first wrongly and then correctly.
  2. Use $all, $size, and "tags.0" against a tags array and compare what each one means.
Key takeaways
  • Use dot notation to query nested fields, because matching a whole subdocument is exact.
  • A condition on an array matches if any element matches.
  • Use $elemMatch when several conditions must apply to one array element.
