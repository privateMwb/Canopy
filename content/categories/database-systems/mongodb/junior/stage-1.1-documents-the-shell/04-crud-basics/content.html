CRUD Basics

Create, read, update, and delete each have a one-document and a many-document form, and each returns a result that tells you what happened.

§1Creating Documents

db.products.insertOne({ sku: "NB-1", name: "Notebook", price: 4.5, stock: 120 })
db.products.insertMany([
  { sku: "PN-3", name: "Pen", price: 1.2, stock: 500 },
  { sku: "MK-7", name: "Marker", price: 2.0, stock: 80 }
])
// { acknowledged: true, insertedIds: { '0': ObjectId(...), '1': ObjectId(...) } }

insertMany is ordered by default: it stops at the first error. Pass { ordered: false } to keep going past failures.

§2Reading Documents

find takes a filter document and returns a cursor. findOne returns the first match, or null.

db.products.find()                        // everything
db.products.find({ sku: "NB-1" })         // equality match
db.products.findOne({ name: "Pen" })      // one document or null
db.products.countDocuments({ price: { $lt: 3 } })

An empty filter {} matches all documents. A filter with several fields means AND.

§3Updating and Deleting

Update takes a filter plus an update document that uses operators such as $set. Without an operator the call is rejected, which protects you from replacing a document by accident.

db.products.updateOne({ sku: "NB-1" }, { $set: { price: 4.75 } })
db.products.updateMany({ stock: { $lt: 100 } }, { $set: { lowStock: true } })
// { matchedCount: 2, modifiedCount: 2, ... }

db.products.updateOne({ sku: "ZZ-9" }, { $set: { name: "New" } }, { upsert: true })   // insert if no match

db.products.replaceOne({ sku: "MK-7" }, { sku: "MK-7", name: "Marker v2" })   // replaces everything except _id
db.products.deleteOne({ sku: "PN-3" })
db.products.deleteMany({ lowStock: true })
The key insight Read the result object. matchedCount: 0 means your filter found nothing, which is not an error but is usually a bug.

§4Common Mistakes

MistakeWhat HappensFix
deleteMany({}) or updateMany({}, ...) with an empty filterEvery document is affectedRun the same filter with find first and check the count
Using replaceOne when you meant $setFields you did not mention are erasedUse updateOne with $set for partial changes
Ignoring matchedCountA wrong filter fails silentlyCheck the result in code and handle zero matches
Practice
  1. Insert five products, raise the price of one by 10%, mark all with stock under 100 as lowStock, and delete one by sku.
  2. Run an updateOne with upsert: true twice and inspect the two result objects.
Key takeaways
  • Every CRUD operation has a one and a many form: insertOne/insertMany, updateOne/updateMany, and so on.
  • Updates use operators such as $set, and replaceOne swaps the whole document.
  • Result objects report matchedCount and modifiedCount, so check them.
