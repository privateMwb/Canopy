Lambdas

A lambda is an unnamed function object written in place, and its capture list controls which local variables it can see and how.

§1Syntax

auto square = [](int x) { return x * x; };
std::cout << square(6) << '\n';          // 36

auto add = [](int a, int b) -> int { return a + b; };    // explicit return type

A lambda is an object of a unique compiler-generated type, so auto is the natural way to hold one. It is typically as fast as a hand-written function because the compiler can inline it.

§2Captures

The square brackets list the enclosing variables the lambda may use. Without a capture, it can see no locals.

int factor{3};
auto byValue = [factor](int x) { return x * factor; };   // copies factor
auto byRef   = [&factor](int x) { return x * factor; };  // refers to the original
factor = 10;
byValue(2);    // 6, uses the copy made at creation
byRef(2);      // 20, sees the current value

auto all = [=]() { /* copies of everything used */ };
auto allRef = [&]() { /* references to everything used */ };

Copies are made when the lambda is created. By-value captures are const inside the body unless the lambda is marked mutable.

int calls{0};
auto counter = [calls]() mutable { return ++calls; };    // modifies its own copy

§3Lambdas as Arguments

Passing a lambda to an algorithm is its main use.

std::vector<std::string> names{"Grace", "Al", "Ada"};
std::sort(names.begin(), names.end(),
          [](const std::string& a, const std::string& b) { return a.size() < b.size(); });

int threshold{4};
auto n = std::count_if(names.begin(), names.end(),
                       [threshold](const std::string& s) { return s.size() > threshold; });

To store a lambda that must have a fixed type, such as a callback member, use std::function<void(int)>, which can hold any callable at a small cost.

§4The Dangling-Capture Trap

A by-reference capture does not keep the variable alive. Returning such a lambda, or storing it for a later thread, is a use-after-scope bug.

auto makeAdder(int n) {
    return [&n](int x) { return x + n; };    // BUG: n dies when makeAdder returns
}
auto makeAdderOk(int n) {
    return [n](int x) { return x + n; };     // copy: safe
}
The key insight Capture by reference when the lambda is used immediately (inside an algorithm call). Capture by value when the lambda might outlive the current scope.

§5Common Mistakes

MistakeWhat HappensFix
Returning a lambda that captures locals by referenceDangling references; undefined behaviorCapture by value
Expecting a by-value capture to track later changesIt holds the value from creation timeCapture by reference if you want live values
Using [=] inside a member function and assuming it copies membersIt captures this implicitly, which danglesCapture the needed members by value explicitly
Practice
  1. Sort a vector of structs by two keys with a lambda comparator.
  2. Write makeCounter() returning a lambda that returns 1, 2, 3, ... on successive calls.
Key takeaways
  • A lambda is an inline function object whose captures are copied or referenced when it is created.
  • Use by-reference captures only for short-lived lambdas; use by-value if it can escape.
  • std::function stores any callable of a given signature, with some overhead.
