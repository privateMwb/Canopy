Iterators & <algorithm>

Iterators are a uniform way to point into any container, and the algorithm library uses them to replace hand-written loops with named operations.

§1Iterators

An iterator points at an element and supports *it (access) and ++it (advance). Containers expose a half-open range: begin() points at the first element and end() points one past the last, and must never be dereferenced.

std::vector<int> v{3, 1, 2};
for (auto it = v.begin(); it != v.end(); ++it)
    std::cout << *it << ' ';
for (int x : v) std::cout << x << ' ';     // range-for does the same thing

Iterator power varies by container: vectors give random access (it + 5), lists only step forward and backward. Algorithms state which kind they need.

§2The Core Algorithms

<algorithm> and <numeric> provide named operations over [first, last) ranges.

#include <algorithm>
#include <numeric>
std::vector<int> v{5, 2, 9, 1};
std::sort(v.begin(), v.end());                       // 1 2 5 9
auto it = std::find(v.begin(), v.end(), 5);          // iterator, or end() if absent
bool any = std::any_of(v.begin(), v.end(), [](int x) { return x > 8; });
int n = std::count_if(v.begin(), v.end(), [](int x) { return x % 2; });
int sum = std::accumulate(v.begin(), v.end(), 0);

std::vector<int> sq(v.size());
std::transform(v.begin(), v.end(), sq.begin(), [](int x) { return x * x; });

Each call says *what* is done ("count the odd ones"), while a loop makes the reader work out the intent. Binary search (std::lower_bound) requires sorted input.

§3Erase-Remove and the C++20 Range Versions

std::remove_if only shuffles kept elements forward and returns the new logical end; the container must then erase the tail.

v.erase(std::remove_if(v.begin(), v.end(), isOdd), v.end());

C++20 range versions drop the iterator pair: std::ranges::sort(v) and std::ranges::find(v, 5).

§4Writing Output Safely

Algorithms never change a container's size. Writing into an output iterator requires space to exist already, or an inserter that grows the container.

std::vector<int> out;
std::copy_if(v.begin(), v.end(), std::back_inserter(out), isEven);   // grows out
The key insight An algorithm plus a lambda is a sentence. std::count_if(v.begin(), v.end(), isOdd) can be read in one glance, and a hand-written loop must be reverse-engineered.

§5Common Mistakes

MistakeWhat HappensFix
Dereferencing end()Undefined behaviorCompare the result of find against end() first
Calling remove_if without eraseThe container keeps its size, and the tail holds unspecified valuesUse erase-remove or std::erase_if
Writing with transform into an empty vector's begin()Writes past the endSize the output first or use std::back_inserter
Practice
  1. Given a vector of ints, use algorithms only (no loops) to print the sorted unique values.
  2. Use std::accumulate to join a vector of strings with commas.
  3. Find the first element greater than 10 and print its index with std::distance.
Key takeaways
  • Ranges are half-open: end() is one past the last element and is never dereferenced.
  • Prefer named algorithms to loops; they state intent and avoid index bugs.
  • Algorithms don't resize containers; use inserters or erase after remove_if.
