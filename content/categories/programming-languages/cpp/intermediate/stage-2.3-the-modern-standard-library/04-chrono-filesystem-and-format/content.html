chrono, filesystem & format

Three standard libraries handle time, files, and text formatting, so most code that once needed platform-specific calls or printf no longer does.

§1std::chrono

<chrono> represents durations and time points with units in the type, so you can't confuse seconds with milliseconds.

#include <chrono>
using namespace std::chrono_literals;
auto timeout = 2s + 500ms;                                     // 2500 ms
auto start = std::chrono::steady_clock::now();
doWork();
auto elapsed = std::chrono::steady_clock::now() - start;
auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(elapsed);
std::cout << ms.count() << " ms\n";

Use steady_clock for measuring intervals because it never goes backwards. Use system_clock for wall-clock dates. A std::chrono::duration converts to coarser units only explicitly, since that loses information, and finer conversions are implicit. C++20 adds calendar types and time zones.

§2std::filesystem

<filesystem> models paths and the directory tree, portably across platforms.

#include <filesystem>
namespace fs = std::filesystem;
fs::path p = fs::path{"data"} / "logs" / "app.txt";        // / joins path parts
if (fs::exists(p)) std::cout << fs::file_size(p) << " bytes\n";
fs::create_directories("out/reports");
for (const auto& entry : fs::recursive_directory_iterator{"src"})
    if (entry.path().extension() == ".cpp") std::cout << entry.path().filename() << '\n';

Most functions throw fs::filesystem_error on failure, and each has an overload taking an std::error_code& for non-throwing use. Remember that files can change between a check and a use (a race), so prefer to just try the operation and handle failure.

§3std::format

C++20's std::format gives type-safe, Python-style formatting. Placeholders are {} with an optional format spec after :.

#include <format>
std::string s = std::format("{} scored {:.1f} ({:>5})", "Ada", 93.456, 42);
// "Ada scored 93.5 (   42)"
std::format("{:08.3f}", 3.14159);       // "0003.142"
std::format("{:#x} {:b}", 255, 5);      // "0xff 101"
std::format("{0} {1} {0}", "a", "b");   // indexed arguments
std::println("{} items", n);            // C++23: print with newline

Format strings are checked at compile time, so std::format("{}") with a missing argument doesn't build. Support your own type by specializing std::formatter.

The key insight Use the type system for units and paths. std::chrono makes sleep(5) mean "5 of what?" impossible, and fs::path handles separators for each platform.

§4Common Mistakes

MistakeWhat HappensFix
Measuring time with system_clockThe clock can jump (NTP, daylight changes)Use steady_clock
Building paths with string concatenation and "/"Wrong separators, and quirks on other platformsUse fs::path with /
Check-then-act with fs::existsThe file may change in betweenTry the operation and handle the error
Practice
  1. Time a function with steady_clock and print the result in microseconds and milliseconds.
  2. Write a program that lists every file under a directory larger than 1 MB, formatted with std::format.
Key takeaways
  • std::chrono carries units in types, and steady_clock is for measuring intervals.
  • std::filesystem::path and its operations replace hand-built paths.
  • std::format is type-safe and checked at compile time.
