Functions & Arrow Functions

Functions are values you can store, pass, and return, and arrow functions are a shorter syntax with different rules about this and arguments.

§1Declarations and Expressions

A declaration is hoisted, so you can call it before it appears in the file. A function expression assigns a function to a variable and is only usable after that line runs.

sayHi("Ana");                        // works — hoisted
function sayHi(name) { return "Hi " + name; }

// double(2);                         // ReferenceError (TDZ)
const double = function (n) { return n * 2; };

const triple = (n) => n * 3;          // arrow, implicit return
const make = (a, b) => ({ a, b });    // wrap object literals in ()
const log = (x) => { console.log(x); }; // block body needs return

§2Parameters: Defaults and Rest

Parameters can have defaults, evaluated at call time when the argument is undefined. A rest parameter collects the remaining arguments into a real array, replacing the old arguments object.

function greet(name = "friend", punctuation = "!") {
  return `Hello, ${name}${punctuation}`;
}
greet();             // "Hello, friend!"
greet("Ana", "?");   // "Hello, Ana?"

function sum(first, ...rest) {
  return rest.reduce((a, b) => a + b, first);
}
sum(1, 2, 3, 4);     // 10

const nums = [3, 1, 2];
Math.max(...nums);   // spread turns the array into arguments

§3Functions Are Values

Because functions are ordinary values, you can pass them to other functions (callbacks) and return them. Functions that take or return functions are higher-order functions.

const nums = [1, 2, 3];
const doubled = nums.map((n) => n * 2);   // pass a function in

function multiplier(factor) {
  return (n) => n * factor;               // return a function
}
const times5 = multiplier(5);
times5(4);                                // 20

Arrow functions have no own this or arguments and cannot be used with new. Use them for short callbacks; use a regular function when you need those behaviors (covered in the this lesson).

A subtle one A function with no return returns undefined. And return followed by a newline returns undefined too — always start the returned expression on the same line as return.

§4Common Mistakes

MistakeWhat HappensFix

Forgetting return in a block-bodied arrowResult is undefinedAdd return, or drop the braces for an implicit return
Calling fn() when passing a callbackThe function runs immediately; its result is passedPass the reference: button.onclick = fn

  2. Write sum(...nums) with a rest parameter, then call it with an array using spread.
Key takeaways
  • Declarations hoist; function expressions and arrows don't.
  • Use default parameters and rest parameters instead of arguments and manual checks.
  • Functions are values — passing and returning them is the basis of callbacks and closures.
