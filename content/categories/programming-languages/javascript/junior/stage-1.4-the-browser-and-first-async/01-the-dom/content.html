The DOM

The DOM is the browser's live, tree-shaped model of your page, and JavaScript reads and changes the page by reading and changing that tree.

§1What the DOM Is

When the browser parses HTML it builds a tree of nodes. Elements, text, and comments are all nodes. document is the root. The DOM is not your HTML source — it's a live object model that JavaScript can modify, and the page updates to match.

document.title = "New title";
document.body;                       // the <body> element
document.documentElement;            // the <html> element

const el = document.querySelector("#app");
el.parentElement;
el.children;                         // child elements only
el.firstElementChild;
el.nextElementSibling;

§2Selecting Elements

querySelector returns the first match (or null); querySelectorAll returns a static NodeList of all matches. Both take any CSS selector. Convert the list to an array when you want map or filter.

const title = document.querySelector("h1");
const links = document.querySelectorAll("nav a");
const byId = document.getElementById("app");

[...links].map((a) => a.href);
links.forEach((a) => a.classList.add("seen"));   // NodeList has forEach

const input = document.querySelector("input[name=email]");
if (!input) throw new Error("input missing");

§3Changing the Page

Create elements with createElement, set content with textContent, and attach them with append. Toggle styling with classList rather than editing styles by hand. Use textContent for text; innerHTML parses its input as HTML and is dangerous with untrusted strings.

const li = document.createElement("li");
li.textContent = "Buy milk";           // safe: treated as text
li.classList.add("todo");
li.dataset.id = "42";                  // data-id="42"
li.setAttribute("title", "Due today");
document.querySelector("ul").append(li);

li.classList.toggle("done");
li.remove();

// Build many nodes, then insert once
const frag = document.createDocumentFragment();
["a", "b", "c"].forEach((t) => {
  const x = document.createElement("li"); x.textContent = t; frag.append(x);
});
list.append(frag);

Run your script after the elements exist: use defer, type="module", or listen for DOMContentLoaded.

Keep in mind Every DOM write can force the browser to recalculate layout. Batch your changes (a fragment, or one innerHTML-free update) rather than interleaving reads and writes in a loop.

§4Common Mistakes

MistakeWhat HappensFix
Calling querySelector before the element existsReturns null; later code throwsDefer the script or wait for DOMContentLoaded
Assigning user text to innerHTMLXSS: user input can run as scriptUse textContent or build elements
Treating a NodeList as an arraymap/filter are not defined on itUse [...nodeList] or Array.from
Practice
  1. Write code that turns an array of strings into a <ul> of <li> elements appended to the page.
  2. Select every external link on a page (one whose href starts with http) and add target="_blank" and a CSS class to each.
Key takeaways
  • The DOM is a live tree of nodes that JavaScript can read and change.
  • Use querySelector(All) to find elements, textContent and classList to change them.
  • Never put untrusted text through innerHTML; make sure the elements exist before you select them.
