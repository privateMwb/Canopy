Modules: ESM & CommonJS

JavaScript has two module systems — ES modules and CommonJS — and you will meet both, so you need to know how they differ.

§1ES Modules

ESM is the standard: static import and export statements, analyzed before the code runs. That lets tools find unused code and lets browsers load files in parallel. Modules are always in strict mode, run once, and are cached.

// util.js
export function slugify(s) { return s.toLowerCase().replace(/\s+/g, "-"); }
export const VERSION = "1.0";
export default class Logger {}          // at most one default per module

// main.js
import Logger, { slugify, VERSION as v } from "./util.js";
import * as util from "./util.js";      // namespace object
const { sleep } = await import("./sleep.js");   // dynamic import, returns a Promise

§2Default vs. Named Exports

Named exports must be imported by their exact name (renameable with as), which makes refactoring and autocomplete reliable. A default export can be imported under any name, which is convenient but inconsistent across a codebase.

export { a, b };               // list exports at the bottom
export { x as y };             // rename on the way out
export * from "./other.js";    // re-export everything (a barrel file)

// Imports are live read-only views, not copies
// counter.js:  export let n = 0; export function inc() { n++; }
// main.js:     import { n, inc } from "./counter.js"; inc(); console.log(n); // 1

§3CommonJS

CommonJS is Node's original system: require() is a normal function call that runs synchronously, and module.exports is what a file gives back. You'll find it in older packages and config files.

// math.cjs
function add(a, b) { return a + b; }
module.exports = { add };

// main.cjs
const { add } = require("./math.cjs");
const fs = require("node:fs");

In Node, .mjs files (or "type": "module" in package.json) are ESM; .cjs files are CommonJS. ESM can import CommonJS packages easily; require of an ES module has historically been limited, so check your Node version.

Heads up ESM import is hoisted and static — you can't put it inside an if. For conditional or lazy loading, use await import(). Also, require, module, __dirname don't exist in ESM; use import.meta.url instead.

Practice
  1. Split a 30-line script into two modules: a utils.js with named exports and a main.js that imports them.
  2. Convert one CommonJS file with module.exports into ESM and list every change you needed to make.
Key takeaways
  • ESM uses static import/export; CommonJS uses require/module.exports.
  • Prefer named exports; imports are live, read-only views of the exporting module.
  • Use await import() for lazy or conditional loading.
