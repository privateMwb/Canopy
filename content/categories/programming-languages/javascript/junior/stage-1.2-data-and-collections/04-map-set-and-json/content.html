Map, Set & JSON

Map and Set are purpose-built collections that fix the sharp edges of using plain objects for lookup, and JSON is how data leaves your program.

§1Map

A Map holds key-value pairs where keys can be any value, insertion order is preserved, and .size is built in. Plain objects only allow string and symbol keys and inherit extra properties like toString.

const scores = new Map();
scores.set("ana", 10).set("bo", 7);
scores.get("ana");          // 10
scores.has("cy");           // false
scores.size;                // 2
scores.delete("bo");

const byObject = new Map();
const key = { id: 1 };
byObject.set(key, "meta");  // an object as a key — impossible with {}

for (const [name, score] of scores) console.log(name, score);
const obj = Object.fromEntries(scores);   // Map -> object
const m = new Map(Object.entries(obj));   // object -> Map

§2Set

A Set stores unique values and tests membership in constant time on average. It is the right tool for de-duplication and "have I seen this before?".

const seen = new Set([1, 2, 2, 3]);
seen.size;                  // 3
seen.add(4);
seen.has(2);                // true

const unique = [...new Set(["a", "b", "a"])];   // ["a", "b"]

const a = new Set([1, 2, 3]), b = new Set([2, 3, 4]);
const both = [...a].filter((x) => b.has(x));    // [2, 3] intersection

§3JSON

JSON is a text format with a strict syntax: double-quoted keys and strings, no comments, no trailing commas. JSON.stringify and JSON.parse convert between values and text. Data that JSON can't represent is dropped or changed.

const text = JSON.stringify({ name: "Ana", tags: ["a", "b"] });
// '{"name":"Ana","tags":["a","b"]}'
JSON.stringify(data, null, 2);       // pretty-printed, 2-space indent

JSON.parse('{"ok":true}');           // { ok: true }
try { JSON.parse("{bad json}"); }
catch (e) { console.log(e.name); }   // SyntaxError

JSON.stringify({ a: undefined, b: () => 1, c: new Date(0), d: NaN });
// '{"c":"1970-01-01T00:00:00.000Z","d":null}'  — undefined and functions vanish

Maps and Sets stringify as {}. Convert them first: JSON.stringify([...map]) or [...set].

Choosing Use an object for fixed, known fields (a record). Use a Map when keys are dynamic, user-supplied, or not strings. Use a Set for uniqueness and membership.

§4Common Mistakes

MistakeWhat HappensFix
Using a plain object as a dictionary of user-supplied keysKeys like __proto__ or constructor cause odd behaviorUse a Map, or Object.create(null)
JSON.parse on untrusted input without try/catchA SyntaxError crashes the flowWrap in try/catch and handle failure
Expecting JSON.stringify to keep Dates, Maps, or undefinedDates become strings; Maps become {}; undefined is droppedConvert explicitly before and after
Practice
  1. Use a Map to count word frequencies in a sentence, then print the top three.
  2. Round-trip an object through JSON.stringify and JSON.parse and list every property type that does not survive.
Key takeaways
  • Map allows any key type, keeps order, and has .size; Set stores unique values.
  • JSON is strict text: double quotes only, and it drops functions and undefined.
  • Always guard JSON.parse with try/catch when the input isn't trusted.
