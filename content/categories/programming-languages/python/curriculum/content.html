Checkpoints are deliberately unscaffolded. If you can finish one without hints, the stage actually landed, not just the following-along.

Levels aren't strict walls. Types arrive at Junior as plain values, return at Intermediate as hints and static checking, and come back at Senior as API design and library contracts. Concurrency follows the same arc: the GIL and threads, then asyncio, then production behavior under load. Revisiting a topic at a harder level is expected.

Senior is about judgment as much as mechanism. Senior is about what's under the language and what's around it. Knowing how CPython manages memory or how an asyncio cancellation propagates is one skill; deciding whether Python should be in the system at all, and writing that down, is another, and the last stage is built around that gap.
