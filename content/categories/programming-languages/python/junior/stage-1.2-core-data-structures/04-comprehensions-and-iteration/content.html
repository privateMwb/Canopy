Comprehensions & Iteration

Comprehensions build lists, dicts, and sets in one expression, and enumerate, zip, and sorted replace most index juggling.

§1List Comprehensions

A comprehension is a loop that builds a collection. The shape is [expression for item in iterable if condition].

squares = [n * n for n in range(5)]            # [0, 1, 4, 9, 16]
evens = [n for n in range(10) if n % 2 == 0]   # [0, 2, 4, 6, 8]
labels = ["big" if n > 2 else "small" for n in range(5)]
pairs = [(a, b) for a in "ab" for b in (1, 2)] # nested loops, left to right

The if at the end filters; the x if cond else y at the front transforms. Don't confuse the two positions.

§2Dict and Set Comprehensions

words = ["apple", "fig", "kiwi"]
lengths = {w: len(w) for w in words}      # {'apple': 5, 'fig': 3, 'kiwi': 4}
initials = {w[0] for w in words}          # {'a', 'f', 'k'}
inverted = {v: k for k, v in lengths.items()}

§3enumerate, zip, sorted, and Friends

names = ["ana", "bo", "cy"]
scores = [90, 85, 70]

for i, name in enumerate(names, start=1):
    print(i, name)                          # 1 ana, 2 bo, 3 cy

for name, score in zip(names, scores):      # pairs up; stops at the shortest
    print(name, score)

ranking = sorted(zip(scores, names), reverse=True)
print(ranking[0])                           # (90, 'ana')

print(sum(scores), min(scores), max(scores))
print(any(s < 75 for s in scores))          # True
print(all(s >= 70 for s in scores))         # True

reversed(seq), range(start, stop, step), and dict(zip(keys, values)) round out the everyday toolkit.

§4When Not to Use One

A comprehension is for building a collection from a simple loop. If it needs multiple nested conditions, side effects like printing, or more than one readable line, write a regular for loop. Clear beats clever.

The key insight any(...) and all(...) with a generator expression (no square brackets) stop as soon as the answer is known, so you don't need to build a list first.

§5Common Mistakes

Using a comprehension for side effects like [print(x) for x in xs]Builds a throwaway list of NoneUse a plain for loop
Practice
  1. Turn [" Ann ", "bob", " CY"] into cleaned, capitalized names with one comprehension.
  2. Given two lists, keys and values, build a dict with zip, then build the inverse mapping with a comprehension.
Key takeaways
  • A comprehension combines a loop, optional filter, and expression into one collection-building line.
  • enumerate gives indexes, zip pairs sequences, sorted returns a new ordered list.
  • Switch to a regular loop when a comprehension stops being easy to read.
