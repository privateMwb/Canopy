Strings & Formatting

Strings are immutable sequences of Unicode characters, and f-strings are the cleanest way to build text from values.

§1Indexing and Slicing

A str is a sequence: s[0] is the first character, s[-1] the last. Slices s[start:stop:step] include start and exclude stop, and never raise IndexError for out-of-range bounds.

s = "python"
print(s[0], s[-1])     # p n
print(s[1:4])          # yth
print(s[:2], s[2:])    # py thon
print(s[::-1])         # nohtyp  (reversed)

Strings are immutable: s[0] = "P" raises TypeError. To "change" a string, build a new one.

§2Useful Methods

Methods return new strings; they never modify the original.

line = "  Hello, World  "
print(line.strip())                 # 'Hello, World'
print(line.lower().split(","))      # ['  hello', ' world  ']
print("-".join(["a", "b", "c"]))    # a-b-c
print("banana".replace("a", "o"))   # bonono
print("py" in "python")             # True
print("a,b,,c".split(","))          # ['a', 'b', '', 'c']
print("Hello".startswith("He"))     # True

split() with no argument splits on any run of whitespace and drops empty pieces, which is usually what you want for text.

§3f-strings and Format Specs

Prefix a string with f and put expressions in braces. After a colon you can give a format spec for width, alignment, and precision.

name, price, qty = "tea", 3.5, 12
print(f"{name} costs {price:.2f}")       # tea costs 3.50
print(f"{qty:>5}|{name:<6}|{name:^7}|")  # right, left, center
print(f"{1234567:,}")                     # 1,234,567
print(f"{0.256:.1%}")                     # 25.6%
print(f"{price=}")                        # price=3.5

§4Unicode and Bytes

Python 3 strings hold Unicode code points; len("é") is 1 whether or not it displays with an accent. Bytes are a separate type: str.encode("utf-8") produces bytes, and bytes.decode("utf-8") goes back.

print(len("héllo"))                  # 5
data = "héllo".encode("utf-8")
print(len(data), data)               # 6 b'h\xc3\xa9llo'
print(data.decode("utf-8"))          # héllo
The key insight Never build a big string with += in a loop. Collect the pieces in a list and call "".join(parts) once; it's both clearer and faster.

§5Common Mistakes

MistakeWhat HappensFix
Trying to assign s[0] = "X"TypeError: 'str' object does not support item assignmentBuild a new string: "X" + s[1:]
Calling s.upper() without using the resultThe original is unchangedAssign it: s = s.upper()
Mixing str and bytesTypeError or garbled textDecode bytes to str at the boundary and encode only on output
Practice
  1. Write a function that returns True if a string reads the same forwards and backwards, ignoring case and spaces.
  2. Print a three-column table of names, quantities, and prices with aligned columns using format specs.
Key takeaways
  • Strings are immutable sequences; slicing never raises for out-of-range bounds.
  • String methods return new strings, so assign the result.
  • Use f-strings with format specs for output, and keep str and bytes separate.
