Reading & Writing Files

open() inside a with block reads and writes files safely, and pathlib makes paths and small file jobs painless.

§1open() and the with Statement

open(path, mode, encoding=...) returns a file object. Modes: "r" read (default), "w" write (truncates!), "a" append, "x" create-only, with "b" added for bytes. Use with so the file is closed even if an error occurs.

with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("first line\n")
    f.write("second line\n")

with open("notes.txt", encoding="utf-8") as f:
    text = f.read()            # whole file as one string

with open("notes.txt", encoding="utf-8") as f:
    for line in f:             # lazy: one line at a time, any file size
        print(line.rstrip("\n"))

Always pass encoding="utf-8" for text files. The default depends on the platform, which is a classic source of "works on my machine" bugs.

§2pathlib

pathlib.Path represents paths as objects, with / to join and handy methods.

from pathlib import Path

base = Path("data")
path = base / "reports" / "2026.txt"
print(path.name, path.suffix, path.parent)   # 2026.txt .txt data/reports

path.parent.mkdir(parents=True, exist_ok=True)
path.write_text("hello\n", encoding="utf-8")
print(path.read_text(encoding="utf-8"))
print(path.exists(), path.is_file())

for p in base.glob("**/*.txt"):              # recursive search
    print(p)

§3Binary Files and Cleanup

Use "rb" and "wb" for images, archives, and anything that isn't text. Reading and writing bytes does no encoding or newline translation.

data = Path("logo.png").read_bytes()
Path("copy.png").write_bytes(data)

import os
os.remove("notes.txt")        # or Path("notes.txt").unlink()

Relative paths resolve against the current working directory, not the script's location. To find files next to your script use Path(__file__).parent.

The key insight Opening with "w" empties the file immediately, before you write a byte. If the data matters, write to a temporary file and rename it into place, or open with "x" to refuse to overwrite.

Practice
  1. Write a script that copies a text file to a new file with every line numbered.
  2. Use pathlib to list every .py file under the current directory with its size in bytes.
Key takeaways
  • Use with open(...) so files always close, and specify encoding="utf-8" for text.
  • Iterating over a file reads lazily, one line at a time.
  • pathlib.Path makes joining, reading, writing, and searching paths cleaner than string handling.
