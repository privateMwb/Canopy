JSON, CSV & a Standard Library Tour

Python ships with modules for data formats, dates, counting, and randomness, so you can do a lot before installing anything.

§1json

json.dumps / json.loads convert between Python objects and JSON strings; dump / load work with files. Dicts, lists, strings, numbers, booleans, and None map to their JSON counterparts (None becomes null).

import json

record = {"name": "Ana", "scores": [90, 85], "active": True}
text = json.dumps(record, indent=2)
back = json.loads(text)

with open("record.json", "w", encoding="utf-8") as f:
    json.dump(record, f, indent=2)

with open("record.json", encoding="utf-8") as f:
    data = json.load(f)

JSON has no tuples, sets, or dates; tuples come back as lists, and other types raise TypeError unless you convert them.

§2csv

Use the csv module rather than line.split(","), because real fields contain quoted commas and newlines. Open with newline="".

import csv

with open("people.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):        # each row is a dict keyed by header
        print(row["name"], int(row["age"]))

with open("out.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "age"])
    writer.writeheader()
    writer.writerow({"name": "Ana", "age": 31})

Every CSV value is a string, so convert numbers and dates yourself.

§3datetime, collections, random

from datetime import datetime, timedelta, date
from collections import Counter, defaultdict
import random

now = datetime.now()
deadline = now + timedelta(days=7)
print(deadline.strftime("%Y-%m-%d"))
d = datetime.strptime("2026-03-05", "%Y-%m-%d")
print((date(2026, 12, 25) - date.today()).days)   # days until Christmas

words = "a b a c b a".split()
print(Counter(words).most_common(2))     # [('a', 3), ('b', 2)]

groups = defaultdict(list)
for w in words:
    groups[w].append(len(groups[w]))     # missing keys start as []

print(random.choice(["red", "green"]), random.randint(1, 6))
random.seed(42)                          # reproducible sequence

random is not suitable for security; use secrets for tokens and passwords.

The key insight Before installing a package for a small task, check the standard library. json, csv, datetime, collections, pathlib, argparse, and sqlite3 solve a surprising share of real problems.

§4Common Mistakes

MistakeWhat HappensFix
Splitting CSV lines with split(",")Quoted fields containing commas break the parseUse csv.reader or csv.DictReader
Opening CSV files without newline=""Blank rows or mangled line endings on some platformsPass newline="" to open
Using random for passwordsOutput is predictableUse the secrets module
Practice
  1. Read a CSV of names and ages, and write a JSON file with the average age and the list of names sorted alphabetically.
  2. Use Counter to find the three most common words in a paragraph of text.
Key takeaways
  • json and csv handle serialization; values from CSV are always strings.
  • datetime, timedelta, and strftime/strptime cover everyday date handling.
  • Counter and defaultdict remove most hand-written counting and grouping loops.
