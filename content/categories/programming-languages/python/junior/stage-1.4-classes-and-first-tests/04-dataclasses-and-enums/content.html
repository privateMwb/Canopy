Dataclasses & Enums

@dataclass generates the boilerplate for data-holding classes, and Enum gives names to a fixed set of choices.

§1Dataclasses

A class that mainly holds data needs __init__, __repr__, and __eq__. @dataclass writes them from annotated fields.

from dataclasses import dataclass, field

@dataclass
class Item:
    name: str
    price: float
    qty: int = 1
    tags: list[str] = field(default_factory=list)   # safe mutable default

i = Item("pen", 1.5)
print(i)                       # Item(name='pen', price=1.5, qty=1, tags=[])
print(i == Item("pen", 1.5))   # True

Fields with defaults must come after fields without. For mutable defaults, use field(default_factory=...); a plain = [] raises an error.

§2Useful Options

@dataclass(frozen=True)        # immutable and hashable
class Coord:
    lat: float
    lon: float

@dataclass(order=True)         # adds <, <=, >, >= comparing fields in order
class Version:
    major: int
    minor: int

@dataclass
class Order:
    id: int
    total: float = 0.0

    def __post_init__(self):   # runs after the generated __init__
        if self.total < 0:
            raise ValueError("total cannot be negative")

dataclasses.asdict(obj) converts an instance to a dict, and dataclasses.replace(obj, qty=5) makes a modified copy.

§3Enums

An Enum defines a closed set of named values, which prevents typos in strings like "actve".

from enum import Enum, auto

class Status(Enum):
    ACTIVE = "active"
    SUSPENDED = "suspended"
    CLOSED = "closed"

class Color(Enum):
    RED = auto()
    GREEN = auto()

s = Status("active")            # look up by value
print(s, s.name, s.value)       # Status.ACTIVE ACTIVE active
print(s is Status.ACTIVE)       # True
for member in Status:
    print(member.name)

Compare enum members with is or ==. Python's type annotations are not enforced at runtime, so @dataclass won't reject Item("pen", "cheap") unless you add checks yourself.

The key insight Dataclasses don't add features so much as remove repetition. When a class is mostly fields, a dataclass makes the intent obvious and eliminates a whole class of hand-written bugs.

§4Common Mistakes

MistakeWhat HappensFix
Using tags: list = [] in a dataclassValueError: mutable defaultUse field(default_factory=list)
Expecting annotations to validate types at runtimeWrong types are silently acceptedValidate in __post_init__, or use a type checker
Comparing enum members to raw strings (status == "active")Always FalseCompare to Status.ACTIVE, or convert with Status(value)
Practice
  1. Convert a hand-written Employee class with __init__, __repr__, and __eq__ into a dataclass.
  2. Define a Priority enum (LOW, MEDIUM, HIGH) and a Task dataclass that uses it, and sort tasks by priority.
Key takeaways
  • @dataclass generates __init__, __repr__, and __eq__ from annotated fields.
  • Use field(default_factory=...) for mutable defaults and frozen=True for immutability.
  • Enum names a fixed set of choices so typos become errors instead of silent bugs.
