Descriptors, Attribute Lookup & __slots__

Every obj.attr runs a defined lookup algorithm built on descriptors, the mechanism behind properties, methods, and much of the language.

§1The Descriptor Protocol

A descriptor is an object, stored as a class attribute, that defines __get__, and optionally __set__ or __delete__. When attribute access finds a descriptor on the class, Python calls its methods instead of returning it directly.

class Positive:
    def __set_name__(self, owner, name):
        self.name = "_" + name                  # called when the class is created

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self                          # accessed on the class
        return getattr(obj, self.name)

    def __set__(self, obj, value):
        if value <= 0:
            raise ValueError(f"{self.name[1:]} must be positive")
        setattr(obj, self.name, value)

class Product:
    price = Positive()
    qty = Positive()

    def __init__(self, price, qty):
        self.price = price                       # goes through Positive.__set__
        self.qty = qty

p = Product(5, 2)
p.price = -1       # ValueError: price must be positive

§2The Lookup Order

For obj.attr, type(obj).__getattribute__ roughly does:

  • Find attr on the class and its parents, following the MRO.
  • If it's a data descriptor (defines __set__ or __delete__), call its __get__. This beats the instance dictionary.
  • Otherwise, look in the instance's __dict__ (or slots).
  • Otherwise, if the class attribute is a non-data descriptor (only __get__) call it; if it's a plain value, return it.
  • If nothing is found, call __getattr__ if defined, else raise AttributeError.

This order explains why assigning to an instance attribute can hide a method (a function is a non-data descriptor), and why a property can't be overridden by the instance dict (it's a data descriptor).

§3Properties and Methods Are Descriptors

property is a data descriptor implemented in C. Functions are non-data descriptors whose __get__ returns a bound method, which is how self gets supplied.

class C:
    def f(self): ...

c = C()
print(C.f)                     # <function C.f ...>
print(c.f)                     # <bound method C.f of ...>
print(C.f.__get__(c) == c.f)   # True: __get__ does the binding

classmethod, staticmethod, functools.cached_property, and many ORM fields are descriptors as well.

§4__slots__

By default each instance has a __dict__ for attributes. Declaring __slots__ replaces it with fixed storage.

class Point:
    __slots__ = ("x", "y")
    def __init__(self, x, y):
        self.x, self.y = x, y

p = Point(1, 2)
p.z = 3        # AttributeError: no __dict__ and 'z' not in __slots__

Slots reduce per-instance memory (often notably when you hold millions of small objects) and can speed attribute access slightly. Trade-offs: no dynamic attributes, no __weakref__ unless you list it, and inheritance needs care (a subclass without its own __slots__ gets a __dict__ again). @dataclass(slots=True) (3.10+) generates this for you.

The key insight "Data descriptor beats instance dict beats non-data descriptor." Once you know this single rule, property behavior, method binding, and __slots__ stop being magic.

§5Common Mistakes

MistakeWhat HappensFix
Storing a descriptor's value on the descriptor itselfAll instances share one valueStore per-instance data in the instance, using __set_name__ for the key
Adding __slots__ to save memory without measuringLost flexibility for a negligible gainMeasure with tracemalloc first; it matters at large object counts
Forgetting that __getattr__ is only a fallbackIt's never called for attributes that existUse __getattribute__ (carefully) to intercept all access
Practice
  1. Implement a Typed(expected_type) descriptor that validates assignments, and use it in a class with two fields.
  2. Create 1,000,000 instances of a class with and without __slots__, and compare memory with tracemalloc.
Key takeaways
  • Descriptors (__get__, __set__) control attribute access; properties and methods are descriptors.
  • Lookup precedence: data descriptors, then the instance dict, then non-data descriptors and class attributes.
  • __slots__ trades flexibility for lower per-instance memory.
